# DP.FM.453 — «Перенести как есть» неявно предрешает архитектурную развилку и умалчивает про хранение

## Тезис и механизм ошибки

Предложение по логике тарифов было полно по бизнес-правилам и пусто по хранению: ни слова о том, откуда читает и куда пишет смена тарифа. Формулировка «переместить как есть» выглядит нейтрально-технической, но на деле неявно предрешает открытую архитектурную развилку — где после переноса живут данные и оба тарифа — не называя это решением и не выставляя его на обсуждение. Пилот задал вопрос про базу данных уже после того, как три участника пир-сессии пришли к консенсусу по бизнес-правилам; напарники вопрос не подняли, писатель проверил смежные карточки и нашёл, что предложение конфликтует с уже известным блокером: по принятому архитектурному решению единственный источник правды по подписке — `subscription.contract`, параллельное хранение в БД сервиса платежей запрещено.

## Диагностический принцип

Фраза «перенести/сделать как есть» в предложении, меняющем существующую логику, — не техническая деталь, а точка, где реальная развилка (архитектурная, не бизнес-правило) уходит из виду ревью, потому что формулировка звучит так, будто выбора не было. Общий детектор для ревью предложений «переносим/делаем как есть»: (1) какую открытую развилку эта фраза закрывает молча; (2) где после переноса живёт источник правды по данным, и совпадает ли это с принятым ADR.

## Границы

Различение не требует, чтобы каждое предложение по умолчанию подозревалось в сокрытии развилки — оно применимо там, где предложение меняет СОСТОЯНИЕ существующей сущности (подписка, право, конфигурация) и не называет явно, откуда читает и куда пишет. Предложения, ограниченные чистой бизнес-логикой без изменения модели хранения, вне области действия этого диагностического принципа.

## Проверка

Для предложения, меняющего логику работы с уже существующей сущностью: явно спросить (1) «какую развилку эта формулировка закрывает молча?» и (2) «где источник правды по затронутым данным после переноса, и совпадает ли это с принятым ADR?» Оба вопроса не имеют явного ответа в тексте предложения → воспроизведён DP.FM.453.
