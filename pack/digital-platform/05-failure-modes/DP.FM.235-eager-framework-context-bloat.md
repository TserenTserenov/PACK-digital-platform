# DP.FM.235 — Eager framework context bloat

## Паттерн

Служебный каркас агентного фреймворка (правила, память, инструкции, роли) грузится **eager** — целиком в каждую сессию, независимо от того, понадобится ли он. Контекстное окно забивается инфраструктурой раньше, чем доходит до полезной работы пользователя. Хуже всего при «пустом» состоянии: знания пользователя ещё нет, а каркас уже съел бюджет.

## Пример (IWE, замер 2026-06-26)

Только правила + память + два CLAUDE.md (без скиллов, без хуков) = **~118 000 токенов** на каждую сессию при почти пустом экзокортексе.

| Потребитель (все eager) | Объём |
|-------------------------|-------|
| MEMORY.md | ~45K (452 строки) |
| distinctions.md | ~41K (147 различений) |
| IWE/CLAUDE.md | ~18K |
| role-prefixes.md | ~7.5K |

Нарушены собственные правила фреймворка: «slim-ядро: триггеры + правила, детали → lazy» и «HOT ≤150 строк».

## Механизм

1. Каркасный компонент подключён eager (всегда в контексте), хотя нужен лишь в части сессий.
2. Объём растёт по мере накопления правил/различений/памяти — без обратного давления.
3. Контекст-бюджет тратится до первого полезного действия → дорогая подписка выгорает на open/close дня без задачи.

## Симптомы

- Жалоба пользователя: «2/3 дневной нормы дешёвой подписки уходит на открытие/закрытие дня без задачи» (триггер WP-445, Денис П., DevOps).
- HOT-файлы превышают собственный лимит строк.
- Каждая сессия стартует с одинаковым крупным фиксированным префиксом.

## Тест обнаружения

«Грузит ли фреймворк в контекст компонент, который данная сессия не использует?»
- Да + компонент имеет детерминированный лексический триггер → кандидат на lazy-load (DP.METHOD.146).
- Да + триггера нет → кандидат на split hot/warm (различение «Compression ≠ Lazy», DP.D.219).

## Лечение

1. **DP.METHOD.146** (activate-on-prefix lazy load) — для компонентов с лексическим advance-signal.
2. **Split hot/warm** (DP.D.219 «Compression ≠ Lazy») — для компонентов без advance-signal (например, distinctions).
3. **DP.D.220** (режим отказа = деградация, не блокировка) — чтобы lazy не вернул eager-стоимость при отказе.
