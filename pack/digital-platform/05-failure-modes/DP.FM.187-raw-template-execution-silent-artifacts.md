# DP.FM.187 — Запуск сырого шаблона с нераскрытыми плейсхолдерами создаёт артефакты с литеральными именами

## Описание

Исполняемый файл-шаблон с `{{PLACEHOLDER}}`-подстановками технически запускается без инстанциации. Плейсхолдеры молча становятся литеральными строками и создают артефакты (директории, логи) с именами вида `{{HOME_DIR}}/`. Нет явного падения — есть побочный артефакт в нестандартном месте.

**Область применения:** любая система template→instantiate: dotfiles, IaC-шаблоны, scaffold-генераторы.

## Пример

FMT-exocortex-template: скрипт с `{{HOME_DIR}}` был запущен без подстановки. В корне репо появилась директория `{{HOME_DIR}}/` с лог-файлами внутри.

## Тест обнаружения

«Что произойдёт при запуске этого скрипта без предварительной подстановки?» Тихое создание артефактов → guard отсутствует.

## Инвариант

Исполняемый шаблон без guard на нераскрытые плейсхолдеры содержит скрытое предположение «запускается только после инстанциации» — техническая защита этого предположения отсутствует.

## Митигация

Guard на старте скрипта:

```bash
grep -q '{{' "$0" && { echo "raw template — run instantiate first" >&2; exit 1; }
```
