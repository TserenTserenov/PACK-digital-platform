# DP.FM.379 — маркер исключения, сам содержащий шаблон секрета

## Паттерн

Маркер, добавляемый в файл для явного исключения строки из сканирования на секреты (например, комментарий-аннотация с примером формата ключа), при наивной реализации сканера секретов сам совпадает с паттерном обнаружения секрета — сканер, обрабатывающий маркер как обычный текст, создаёт себе собственное исключение из проверки того самого содержимого, которое маркер должен был лишь аннотировать.

## Механизм

1. Маркер исключения содержит образец формата секрета (для иллюстрации, что именно исключается)
2. Сканер секретов, ищущий паттерн секрета по regex, совпадает и с самим маркером
3. В зависимости от логики обработки исключений, это может либо ложно исключить реальный секрет рядом, либо создать петлю самоисключения

## Почему опасен

Механизм защиты (сканер секретов) содержит слепое пятно в собственном метаязыке разметки исключений — сложно обнаружить без специального тестирования именно этого граничного случая.

## Лечение

Формат маркера исключения проектируется так, чтобы синтаксически не совпадать с паттернами обнаружения секретов (например, обфусцированный образец вместо буквального формата), либо сканер явно исключает из анализа сам текст маркера отдельно от механизма exemption.
