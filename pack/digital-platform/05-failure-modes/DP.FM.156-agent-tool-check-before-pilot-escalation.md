# DP.FM.156 — Agent manual escalation before tool check

## Краткое описание

Агент, не проверив доступные инструменты, просит пилота выполнить действие вручную: «сделай авторизацию», «пройди через UI», «дай доступ», «авторизуйся». Нарушение принципа «исчерпай инструменты, потом эскалируй человеку».

## Симптомы

- Пилот получает запрос на ручное действие, хотя MCP-инструмент для этого существует.
- Агент ссылается на UI или ручную авторизацию до попытки вызова инструмента.
- Типичные фразы: «сделай вручную», «пройди авторизацию», «дай доступ», «через UI».

## Контекст

Поведенческая ось B1 в детекторе ответа агента IWE. Детектор намеренно сужен до обращений к пилоту (не к упоминанию JWT/OAuth в тексте) — широкий паттерн «авторизац» давал ложные срабатывания на техдокументацию. Счётчик рецидивов, не блокирует.

## Механика

1. Агент видит задачу, требующую авторизации или UI-взаимодействия.
2. Вместо вызова инструмента (MCP-tool, health-check, status) — просит пилота сделать вручную.
3. Пилот тратит время на ручную задачу, которую агент мог решить сам.

## Решение

Перед просьбой к пилоту: (1) перечислить доступные инструменты; (2) вызвать каждый релевантный; (3) только после исчерпания — эскалировать с объяснением причины.
