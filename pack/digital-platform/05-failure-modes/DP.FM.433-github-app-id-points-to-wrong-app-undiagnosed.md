# DP.FM.433 — Идентификатор GitHub App в конфиге указывает на чужое приложение без диагностики принадлежности

## Тезис и механизм

Идентификатор внешнего приложения в конфигурации может указывать на другую интеграцию и давать внешне обычные ошибки подключения. Формальная корректность идентификатора не подтверждает, что это ожидаемое приложение.

На значимом пути использования фактическая идентичность приложения и принадлежность установки сверяются с доверенным ожидаемым значением, независимым от проверяемой конфигурации. Если обе стороны проверки берутся из одного ошибочно скопированного значения, принадлежность целевой интеграции не проверяется.

## Границы

Перечень известных чужих ID ускоряет обнаружение известных ошибок, но не заменяет положительную проверку. Неизвестное чужое приложение тоже должно быть отклонено. Невозможность обязательной сверки не считается подтверждённой принадлежностью и не разрешает сохранять неподтверждённую установку.

Проверка при старте полезна для диагностики, но не заменяет проверку на пути, где результат подключения становится действующим. Источник доверенного ожидаемого значения и права его изменения определяются отдельно.

## Проверка

Подставной API возвращает сведения об ожидаемом приложении, о чужом приложении вне запретительного списка и об установке другого приложения. Только согласованная пара ожидаемого приложения и принадлежащей ему установки принимается.

При недоступности обязательной сверки запись подключения не создаётся. Ожидаемая идентичность задаётся в независимой фикстуре, результат проверяется по фактическому сохранению установки.
