# DP.FM.370 — молчаливая потеря строк в производном виде

## Паттерн

Скрипт, строящий производный вид из строк с разделителем (`split('|', ...)` по последнему вхождению вместо первого), молча теряет часть строк, когда формат исходного контента содержит альтернативные (`|`-разделённые внутри значения) паттерны — split ломается тихо, без явной ошибки, просто теряя данные из результирующего вида.

## Механизм

1. Парсинг строки использует `split` с предположением о позиции разделителя (например, «последний `|` в строке»)
2. Формат данных допускает дополнительные `|` внутри значения (alternation-паттерны)
3. При наличии такого паттерна split разбивает строку не там, где ожидалось — часть контента теряется или искажается без ошибки исполнения

## Почему опасен

Отсутствие явной ошибки маскирует потерю данных — производный вид выглядит валидным (не падает), но неполным.

## Лечение

Split по первому разделителю (`split on first`, не `last`) там, где формат допускает разделитель внутри значения; в общем случае — использовать формальный парсер вместо позиционного split, если формат допускает вложенные разделители.
