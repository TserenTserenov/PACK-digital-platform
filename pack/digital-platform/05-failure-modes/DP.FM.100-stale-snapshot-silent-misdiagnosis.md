# DP.FM.100 — Snapshot stale → неверный диагноз без сигнала

## Описание

Аналитический запрос или отчёт строится на снимке данных, устаревшем без явного сигнала об устаревании. Вывод о состоянии системы / когорты выглядит валидным, но отражает прошлое.

## Симптом

Диагноз «X из N без репо» — на самом деле снимок от даты ранее текущей. Актуальный запрос показывает другую картину. Решение принято на основе устаревшего снимка.

## Контекст возникновения

- Снимок создан для одного анализа
- Прошло время (дни/недели)
- Снимок повторно используется без проверки даты

## Паттерн

Перед принятием решения на основе снимка данных — явно проверить дату снимка vs дату принятия решения. Если delta > SLA анализа → обновить снимок.

## Детектор

«Когда последний раз обновлялся этот снимок?» Если неизвестно → ответ «устарел».

## Решение

Добавить timestamp к каждому снимку. При использовании снимка — отображать разницу дат. При delta > порога → refresh обязателен.
