# DP.FM.395: Смена подключения источника — чтение сразу после переключения возвращает данные старого источника

## Симптом

Пилот переключает подключение внешнего источника (например, GitHub-репозиторий) внутри ОДНОГО и того же аккаунта. Сразу после переключения читающие эндпойнты возвращают данные СТАРОГО подключения — реальные записи из прежнего репозитория, хотя на стороне нового источника к этому моменту уже другое состояние (в наблюдавшемся случае — пусто).

## Корневая причина

Переключение источника подтверждается как успешное немедленно, но фактически запускает асинхронный переиндекс. Читающий путь не содержит проверки «переиндекс для этого источника завершён?» — отдаёт текущее проиндексированное состояние без разбора, к старому или новому источнику оно относится. Результат неотличим от валидного ответа: нет ошибки, нет статуса «переиндексация идёт», только правдоподобные, но устаревшие данные.

## Антипаттерн → Паттерн

- **Антипаттерн:** операция переключения источника считается завершённой по факту своего успешного ответа; читающие эндпойнты ничего не знают о фоновом переиндексе и отдают текущее состояние индекса как есть.
- **Паттерн:** переключение источника публикует проверяемый маркер версии/поколения источника; читающий путь либо блокируется до завершения переиндекса с явным статусом «переиндексация идёт», либо сверяет маркер перед отдачей результата.

## Тест обнаружения

Переключить источник внутри одного аккаунта и немедленно (без паузы) прочитать через все read-эндпойнты, зависящие от индекса. Если ответ содержит данные старого источника без пометки о неактуальности — паттерн подтверждён. В наблюдавшемся случае (WP-527 Ф7, тестовый аккаунт) — не межпользовательская утечка (один и тот же логин), но тот же механизм в сценарии с разными владельцами источников отдал бы данные чужого источника вместо ошибки/ожидания.

## Связанные документы

- **DP.FM.253** (инструмент читает legacy-источник после переезда source of truth) — смежный класс «читает не тот источник», но постоянный (инструмент не обновлён навсегда), не временное окно гонки при штатном переключении.
- **DP.FM.375** (два каталога с общим ID-пространством) — смежный класс устаревания без сигнала; там причина — историческое совпадение номерных пространств, здесь — незавершённый асинхронный переиндекс.
- **DP.FM.236** (преждевременная инвалидация кеша до promote) — зеркальный по направлению гонки: там сброс кеша опережает подтверждение операции, здесь подтверждение переключения опережает готовность читающего пути.
