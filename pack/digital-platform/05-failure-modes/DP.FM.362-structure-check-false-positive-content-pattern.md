# DP.FM.362 — false positive в проверке структуры таблицы

## Паттерн

Автоматическая проверка «содержит ли таблица приоритетов ссылки на РП» искала совпадение по паттерну (например, `**WP-NNN**`) без разбора, где именно этот паттерн встречен — включая содержимое обычных ячеек таблицы, никак не связанных со структурной колонкой, которую проверка на самом деле должна была валидировать.

## Механизм

1. Проверка ищет паттерн текстовым grep/regex по всей таблице целиком
2. Жирный текст вида `**WP-123**` может встретиться внутри произвольной ячейки (например, в описании), а не только в предназначенной для этого колонке
3. Совпадение засчитывается как «структура присутствует», хотя реальная структурная колонка могла отсутствовать

## Почему опасен

Даёт ложное ощущение, что автоматическая проверка гарантирует корректность структуры — на деле она подтверждает только наличие похожего текста где-то в документе, включая контент, не относящийся к проверяемому инварианту.

## Лечение

Проверка структуры должна парсить таблицу по колонкам (например, через markdown table parser) и искать паттерн только в целевой колонке, а не по всему тексту документа/таблицы.
