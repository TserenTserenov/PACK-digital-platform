# DP.FM.171 — UI-видимость принята за код-доступность

## Описание

Структура меню / UI-раскладка используется как источник истины о тир-гейтинге (доступе по тиру пользователя) без проверки кода проверки прав.

## Пример

Черновик описания прав T4-пользователя опирался на таблицу меню бота. Факт-чек по `core/platform_features.py` опроверг довод: «Клуб» доступен с T2, не T4. Меню и гейтинг реализованы независимо — расхождение типично.

## Тест обнаружения

«Этот довод о доступе основан на меню или на коде проверки прав?»
- Меню → проверить `platform_features.py` (или эквивалент) до публикации
- Код → принять как источник истины

## Инвариант

Source-of-truth доступности = код проверки прав, не UI-проекция (меню, dashboard, документация).

Дополняет «Видимость в меню ≠ фактическая доступность» из distinctions.md (Tier-C): конкретный failure mode с тестом обнаружения и инвариантом.
