# DP.FM.485 — Синк ждал от инструмента-проверки побочного эффекта, которого у него нет

## Тезис и механизм ошибки

Ночной синк расширений вызывал `iwe-safe-pull.sh` на общую каноническую копию `~/IWE`, а затем сверял, насколько она отстаёт от origin. Расчёт держался на негласном допущении: если safe-pull сможет, он сам продвинет HEAD. Каноническая копия — общая рабочая копия нескольких живых сессий, а защитный `iwe-safe-pull` по контракту только проверяет её и никогда не двигает HEAD (при реальном расхождении честно отказывает без стэша и не мутирует дерево).

После перехода части сессий на публикацию через изолированные worktree с cherry-pick общая копия перестала гарантированно обгонять этим путём. Safe-pull её не продвигал, поэтому тик синка стабильно видел «источник отстаёт» и молча пропускал доставку — навсегда после первого push из изолированной worktree.

## Диагностический принцип

Функция с контрактом «только проверка, без мутации» не может быть местом, где вызывающий код неявно рассчитывает на побочный эффект мутации. Контракт читают буквально, а не по прежде наблюдавшемуся поведению. Починка отказалась от допущения целиком: на каждый тик отдельный `git clone --depth 1` свежего `origin/main` во временный каталог, без изменений общей копии.

## Границы

Ошибка относится к конвейерам, читающим общий живой чекаут нескольких сессий и связывающим успех доставки с продвижением его HEAD. Смежные карточки описывают другие механизмы на том же субстрате: `DP.FM.450` — гейт «отказать на грязной копии» никогда не выполняется; `DP.FM.384` — канонический путь ломается под worktree-изоляцией; `AR.006` (Pull-on-Touch) задаёт контракт отказа `iwe-safe-pull` без мутации при расхождении; свойство «не продвигает HEAD» взято из коммита 623e28a7 для вызова из синка.

## Проверка

«Есть ли в конвейере шаг, который ждёт продвижения HEAD от инструмента, чей контракт — только проверка? Читает ли синк источник из свежего клона, а не из общей копии, которую никто не обязан продвигать?» Есть ожидание побочного эффекта → воспроизведён DP.FM.485: доставка молча блокируется, как только общая копия перестаёт обгонять origin.
