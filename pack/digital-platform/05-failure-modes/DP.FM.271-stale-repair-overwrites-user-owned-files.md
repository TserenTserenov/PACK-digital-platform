# DP.FM.271 — Авто-ремонт перезаписывает файлы с owner:user

## Суть

Агент-репаратор (stale-repair) обнаруживает «устаревшие» записи в memory-файлах пользователя и перезаписывает их шаблоном или удаляет. Файлы с `owner: user` — авторитетный контент пользователя, не кэш: они не устаревают, они изменяются целенаправленно. Автоматическая перезапись owner:user файлов — баг.

## Инцидент

FMT #229/#228 (commits 7ae267a, bdb2c9b): automated stale-repair перезаписывал memory-файлы пользователя «свежим» шаблоном.

## Fix

Явный guard до любой авто-модификации файла: `if owner == "user": skip_repair()`.
Принцип: поле `owner` определяет, кто имеет право изменять файл. `owner: system` → автоматика допустима; `owner: user` → только явное действие пользователя.

## Паттерн

**Тест:** «Агент может перезаписать этот файл без явного запроса пользователя?» Да + `owner: user` → bug.

Применимо к любой системе с файловым хранилищем и полем `owner`: email-агенты, wiki-боты, системы синхронизации.
