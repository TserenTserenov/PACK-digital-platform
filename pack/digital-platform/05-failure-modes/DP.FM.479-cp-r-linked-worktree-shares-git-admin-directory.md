# DP.FM.479 — `cp -r` линкованного worktree делит с оригиналом административное состояние git

## Тезис и механизм ошибки

Одноразовую копию для живого прогона сделали файловой копией worktree вместо `git clone` или `git worktree add`. В линкованном worktree `.git` — не каталог, а файл `gitdir: …/.git/worktrees/<name>`, указывающий на общий административный каталог главного репозитория. Поэтому «копия» разделяет с оригиналом remote, HEAD и индекс. Команда `git remote set-url origin <неверный-путь>`, выполненная внутри «копии», переписала origin-URL всего репозитория — включая канонический чекаут и worktree параллельных сессий.

Ошибка обнаружилась сразу: публикация следующего коммита упала с «does not appear to be a git repository». Побочный эффект того же класса: пустой маркер-коммит оркестратора из «копии» попал в общую историю ветки; на origin он не ушёл только потому, что публикация идёт cherry-pick'ом конкретного коммита. Окно для параллельных сессий было реальным; исправлено в ту же минуту, проверено `git fetch` и списком всех worktree.

## Диагностический принцип

Изолированная копия для разрушительных экспериментов должна быть автономной: только `git clone` (при необходимости от локального bare-репозитория) или новый `git worktree add`, и тогда границы общего состояния известны. После любой ошибки в «копии» проверять у оригинала `git remote -v` и `git worktree list`.

## Границы

Карточка про файловое копирование именно линкованного worktree, у которого `.git` — файл-указатель, а не каталог. Прочие дефекты worktree-изоляции — detached HEAD при добавлении из remote-ветки (DP.FM.226), запрет открыть одну ветку дважды (DP.FM.358), путь канонического репозитория (DP.FM.384) — другие механизмы. Не привязана к конкретной IWE-платформе: универсальный git-факт.

## Проверка

«Изолированная копия для разрушительной проверки создана через `git clone` или `git worktree add`, а не файловым копированием каталога с `.git`-указателем?» Нет → воспроизведён DP.FM.479: любая правка конфигурации репозитория в «копии» меняет общий оригинал.
