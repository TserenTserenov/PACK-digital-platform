# DP.FM.372 — автокоммит обновления уносит секреты в публичный форк

## Паттерн

Конвейер автоматического обновления шаблона делает коммит от имени пользователя без явного review содержимого — если пользовательский конфигурационный файл с ключом ИИ (или другим секретом) не исключён из индексируемых файлов, автокоммит уносит его в историю репозитория, который может быть публичным форком шаблона.

## Механизм

1. Update-конвейер коммитит изменения автоматически, без паузы на ручной review diff
2. Пользовательский конфиг с секретом лежит в директории, не покрытой `.gitignore` копии
3. Коммит публикуется (push) в форк пользователя, который может быть публичным — секрет попадает в публичную git-историю

## Почему опасен

Секрет в публичной git-истории компрометирован необратимо (даже последующее удаление файла не убирает его из истории коммитов) — требует ротации ключа, не просто удаления файла.

## Лечение

Обязательный `.gitignore` внутри вендоренной/шаблонной копии, покрывающий типовые пути пользовательских секретов, поставляется как часть шаблона по умолчанию — не полагается на то, что каждый пользователь добавит исключение сам.
