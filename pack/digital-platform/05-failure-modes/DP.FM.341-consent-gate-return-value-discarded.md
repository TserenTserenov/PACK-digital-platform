# DP.FM.341 — Шлюз согласия с отброшенным возвращаемым значением

## Паттерн

Функция-гейт (`check_activation()` и аналоги) возвращает булев вердикт (разрешено/запрещено), но вызывающий код не проверяет возвращаемое значение — следующий шаг (`get_rcs_profile()` и аналоги) выполняется безусловно, независимо от denied/revoked статуса.

## Следствие

Гейт присутствует в коде, выглядит вызванным, но фактически ничего не гейтирует — согласие/безопасность проверяется синтаксически, но не влияет на исполнение.

## Профилактика

Любой gate-вызов (consent, permission, activation) → возвращаемое значение обязано влиять на control flow (early return / raise / conditional branch). Ревью кода с гейтом безопасности — явно проверять, что возврат используется, не только что функция вызвана.
