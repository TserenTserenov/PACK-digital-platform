# DP.FM.436 — Одновременные отказы кронов — диагностический сигнал для проверки общей причины

## Тезис и механизм ошибки

Одновременный одинаковый отказ нескольких периодических заданий — повод проверить общую зависимость. Само совпадение времени и кода ошибки не устанавливает причину.

Ошибка диагностики возникает, когда такое совпадение объявляют доказательством исчерпания общего лимита. Даже разные расписания не доказывают независимости заданий; общий исходящий адрес, ключ или квота требуют отдельного подтверждения.

## Диагностический принцип

Перед повторным запросом ответ классифицируется по документированным сигналам провайдера. При подтверждённом ограничении запросов повтор откладывается согласно указанному сроку ожидания. При недостатке сигналов причина остаётся неустановленной.

Для GitHub проверяются предусмотренные контрактом ответа сведения о лимите и сроке повтора; одного HTTP 403 недостаточно для установления именно этой причины. См. [официальный контракт ограничений REST API](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api).

## Границы

Фактические заголовки исходного инцидента и общая квота в рассмотренном захвате не предъявлены; этот документ не утверждает подтверждённый диагноз того инцидента. Он также не обещает, что любой сетевой отказ допускает безопасный повтор: учитываются идемпотентность операции и её контракт.

DP.FM.106 описывает конкретный предел использования Anthropic API. Его коды и способы распознавания нельзя переносить на другого провайдера как универсальный детектор.

## Проверка

Подставной клиент и управляемые часы получают заранее заданные ответы. При подтверждённом ограничении с будущим сроком ожидания до этого срока новых запросов нет. Явный отказ в доступе без признаков ограничения не классифицируется как исчерпание квоты.

Два одновременных одинаковых ответа без диагностических признаков сохраняют неизвестную причину. Эталон классификации задаётся контрактом API и подготовленными ответами; повторные вызовы наблюдаются независимо от журнала классификатора.
