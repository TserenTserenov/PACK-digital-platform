# DP.FM.160 — Интерфейс без ядра порождает галлюцинацию данных

## Описание

Интерфейсный агент (бот, chatbot, voice UI), не подключённый к источнику данных через tool-вызов, на запрос о фактах пилота не отвечает ошибкой — генерирует правдоподобный ответ из параметров модели. Симптом галлюцинации неотличим от правильного ответа без независимой сверки.

## Механизм возникновения

1. Пилот задаёт вопрос о своих фактах («какие мои РП», «когда я последний раз закрыл задачу»)
2. Интерфейсный агент НЕ имеет tool для доступа к SoT (WP-REGISTRY, knowledge-base, ЦД)
3. LLM получает запрос без контекста данных → генерирует ответ из параметров модели
4. Ответ выглядит правдоподобно: имена проектов, даты, формулировки — все «звучат как настоящие»
5. Пилот без сверки воспринимает как факт → теряет доверие, когда обнаруживает галлюцинацию

## Конкретные эпизоды (WP-411)

| Эпизод | Что было запрошено | Что вернула галлюцинация | Реальность |
|--------|--------------------|--------------------------|------------|
| Ф1 | Контекст пилота через Hermes-runtime | «Инфрейм», «стартап-студия», «оправы» | Ноль реальных данных пилота |
| Ф5 | Вход без Ory | Любой email принимался | Аккаунта в Ory не существовало |
| Ф7 | Список РП | Выдуманные WP-имена | Реестр в WP-REGISTRY никогда не читался |

## Диагностика

«Если убрать tool-вызов к SoT — что вернёт агент?» Если правдоподобный ответ → галлюцинация-риск активен. Если hard-fail или явный «не знаю» → защита работает.

## Решения

| Уровень | Решение | Применимость |
|---------|---------|--------------|
| **(1) Hard-fail** | При отсутствии tool — отказ ответить | Если SoT критичен (личные факты, регистрация, биллинг) |
| **(2) Explicit disclaimer** | Префикс «без доступа к данным, общий ответ» | Если ответ может быть полезен без SoT (общие советы) |
| **(3) Tool-injection** | Подключить MCP-инструмент к SoT перед обработкой запроса | Когда tool технически доступен — fix архитектуры |

Текущий фикс в IWE: вариант (3) — обязательная маршрутизация интерфейсных агентов через ядро (см. различение «суть ≠ интерфейс», WP-392).

## Тест защищённости

«Подключён ли интерфейсный агент к каждому SoT, о котором его могут спросить?» Нет → класс DP.FM.160 активен для тех доменов. Сделать explicit disclaimer обязательным, пока tool не добавлен.
