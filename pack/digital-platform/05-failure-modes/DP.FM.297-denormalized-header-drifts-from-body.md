# DP.FM.297 — Денормализованный счётчик/enum в шапке молча дрейфует от тела

## Паттерн

Денормализованная выжимка в шапке артефакта (счётчик, enum, список значений) не обновляется вместе с телом-источником → **молчаливый дрейф** без ошибки, без предупреждения.

## Примеры

- `frontmatter.summary` с количеством элементов отстаёт от реального количества в таблице тела (накопилось +4 строки с 08.07)
- `argument-hint` в SKILL.md перечисляет типы без нового значения, которое уже есть в таблице типов внутри скилла

Оба дрейфа найдены не автором правки, а сторонней проверкой (факт-чек WP-465, dry-run WP-474).

## Диагностика

```bash
# Пример: сравнить count в summary с реальным count строк таблицы
grep "^| P-" artifact.md | wc -l   # реальный count
grep "summary:" artifact.md         # declared count
```

## Fix-стратегии

(а) Генерировать шапку **скриптом из тела** (нет возможности дрейфа);
(б) Чек в верификаторе/линте «summary = факт»;
(в) Правило: правишь таблицу → в **том же коммите** правишь шапку.

## Правило

Денормализованная шапка без детектора дрейфа = накапливающийся технический долг.
