# DP.FM.353 — Ошибочный путь env-var маскируется локальной копией

## Паттерн

Переменная окружения указывает на путь к скрипту, который на первый взгляд кажется неверным (не соответствует ожидаемой структуре репозитория). При проверке выясняется, что по этому «неверному» пути реально лежит отдельная, самостоятельно версионируемая копия скрипта — исправление пути не требуется, потому что установка де-факто работает через локальную копию.

## Механизм

1. Обнаружен путь в env-var, не совпадающий с ожидаемым каноническим расположением
2. Первая гипотеза: путь ошибочен, нужен фикс
3. Проверка обнаруживает: по этому пути реально лежит рабочая, независимо версионируемая копия — не ошибка, а альтернативная валидная установка

## Почему опасен

- Без проверки фактического содержимого по указанному пути легко «исправить» рабочую конфигурацию, сломав её
- Локальная копия может расходиться с каноническим скриптом — расхождение остаётся незамеченным, пока кто-то не проверит специально

## Лечение

1. Перед правкой «неверного» пути в env-var — проверить, что реально лежит по этому пути
2. Если это рабочая независимая копия — не чинить путь, а явно задокументировать существование параллельной копии и её причину
3. Отдельно оценить риск расхождения локальной копии с каноническим скриптом

## Связи

- Смежный принцип: не чинить симптом раньше, чем понята его причина (root-cause verify-before-trust)
