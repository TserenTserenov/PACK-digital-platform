# DP.FM.259 — Метрика зеленеет, обучающая ценность падает

## Суть

При достижении количественного критерия (90% пунктов ревью) метрика объявляется зелёной. Пользователь перестаёт проверять качество. Параллельно инструмент чинит только форму (пункты чеклиста), не содержание. Метрика зеленеет → фокус пользователя переключается → содержательная деградация остаётся невидимой.

## Инцидент

WP-149 (2026-07-10): Система оценки руководства достигла 90% по формату. Пилот перестал проверять текст. Параллельно контур работал только с форматом (недобор объёма). Процент открытий руководства начал падать.

## Fix

1. Добавить контрметрику: если X зеленеет, а Y падает → alert
2. Раскрыть компоненты: не просто 90%, а форма:95%, содержание:70%, влияние:45%
3. Требовать зеленения нескольких ортогональных индикаторов, не одного
