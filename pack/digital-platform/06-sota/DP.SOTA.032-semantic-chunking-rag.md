# DP.SOTA.032 — Семантическая нарезка чанков обученной моделью (RAG)

## Феномен

Нарезка текста на чанки специально обученной нейросетью (semantic chunking) даёт заметно
более релевантный поиск, чем фиксированная нарезка по символам / предложениям / абзацам —
на тех же запросах. Модель небольшая, запускается локально. Подтверждено внешним
исследованием (Андрей, Оперативка ИТ 25 июня 2026).

## Значение для IWE

Качество любого retrieval-процесса ограничено качеством чанков на входе
(«garbage chunks → garbage retrieval»). Затрагивает knowledge_search, граф понятий (ingest),
персональный поиск. Дополняет приоритетную тройку SOTA (Context Engineering, DP.SOTA.002):
хороший контекст начинается с хорошей сегментации источника.

## Инструменты-кандидаты

- chonkie
- semantic-chunker
- llm-chunker

(локальный запуск, небольшая модель — приватность сохраняется)

## Ограничения

- Конкретный выигрыш зависит от домена и типа документов — требует A/B-замера на нашем
  корпусе перед внедрением
- «Обученная модель сегментации» — общий класс, не один стандарт; выбор инструмента —
  отдельное решение

## Оспаривается (2026-09-21, РП-170)

Тезис карточки («нарезка обученной моделью даёт заметно более релевантный поиск, чем фиксированная») оспаривается сводкой исследования в сессии `MC-sessions:2026-09/18/2026-09-18-06-wp579-chunking-research` (WP-579 Ф1, Claude + Kimi + Codex, консенсус; фоновый агент собрал 47 источников). Числа этой сводки в самой сессии помечены «при принятии решений сверять с первоисточником»; ни агентами, ни пилотом они не перепроверены.

Что утверждает сводка:
1. По четырём независимым измерениям 2024-2026 годов (Vectara/NAACL 2025, arXiv 2410.13070; Chroma 2024; arXiv 2606.00881; arXiv 2607.01852) разница «умный против простого чанкера» составляет 0,5-2 п.п. на реальных документах при стоимости выше в 100-15 000 раз.
2. Semantic chunking выигрывает только на «сшитых» документах, на естественных даёт ноль или минус (Vectara, HotpotQA: 87,4 против 90,6 в пользу фиксированной нарезки).
3. Большие измеренные приросты дают другие рычаги: reranker (+12…+17 п.п. Recall@5, T2-RAGBench, arXiv 2604.01733), гибрид BM25 и dense (+18 % относительно по Recall@5; для русского BM25 сильный базлайн, RusBEIR), контекстные заголовки чанка (Anthropic: −35 % отказов от одного контекста).
4. Для нейро-чанкера (chonky, chonkie) опубликованных retrieval-бенчмарков нет, есть только метрика границ секций.

Оговорка сессии (Kimi): «±2 п.п.» получены в диапазоне 200-1000 токенов на чанк, а текущий потолок конвейера (10 000 символов, 2,5-4 тысячи токенов) вне этого диапазона, поэтому переносить цифры на него без собственного замера некорректно.

Заметка с этим выводом отложена решением РП-170 от 21.09.2026 до проверки пилотом по первоисточникам; до неё не цитировать тезис этой карточки как установленный. Статус `draft` и основной текст карточки не менялись.
