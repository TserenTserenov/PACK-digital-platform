# DP.SOTA.031 — Async Factory: детерминированный конвейер с LLM на точках неопределённости

## Феномен

**Async Factory** — термин Андрея (ИТ-встреча 23 июня 2026) для архитектурного паттерна: детерминированный конвейер работает 24/7, LLM вызывается только в точках неопределённости, результат вызова — команда или код (не свободный текст).

## Соответствие IWE

| Термин Андрея | Термин IWE (WP-423) | Статус |
|---------------|---------------------|--------|
| Async factory | Двухконтурное исполнение | Точное соответствие |
| Детерминированный конвейер | Рефлекс (детерминированный путь) | Точное соответствие |
| ИИ на точках неопределённости | Интеллект (LLM-вызов) | Точное соответствие |
| Результат = команда/код | Structured output (не free text) | Точное соответствие |

## Значение для WP-423

Независимое конвергентное подтверждение (independent convergent validation): два независимых автора, строящих схожие системы, пришли к одному и тому же архитектурному паттерну под разными именами.

**Следствие:** снижает архитектурный риск «изобрели велосипед». Паттерн устойчив и не специфичен для IWE-экосистемы.

## Отраслевые имена паттерна

- **Async Factory** (Андрей, 2026)
- **Agentic Pipeline** (индустриальный термин, см. DP.SOTA.006)
- **Двухконтурное исполнение** / **Рефлекс vs Интеллект** (IWE, WP-423)

## Ограничения

- Термин «async factory» не является широко стандартизированным отраслевым термином (в отличие от «agentic pipeline»)
- Независимость авторов IWE и Андрея подтверждена: термины разные, структура одинаковая
