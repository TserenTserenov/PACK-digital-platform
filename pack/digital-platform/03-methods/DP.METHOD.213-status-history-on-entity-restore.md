# DP.METHOD.213 — сохранение истории статусов при восстановлении сущности

## Суть метода

Если Pack-сущность была ошибочно помечена `status: removed` и затем восстанавливается в `active` — в файл добавляется явная запись истории (дата пометки removed, причина ошибки, дата восстановления), а не просто меняется значение поля `status` без следа предыдущего состояния.

## Обоснование

Молчаливая замена `removed` → `active` без истории стирает след инцидента — при повторном столкновении с той же путаницей (например, другой скрипт снова помечает сущность как removed по той же ошибочной логике) невозможно быстро распознать, что это уже случалось.

## Применение

Восстановление любой Pack-сущности из ошибочного `removed`-статуса.
