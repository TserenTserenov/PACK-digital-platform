# DP.M.405 — Post-write самопроверка в shell-скриптах

## Суть метода

Вместо предположения, что запись прошла успешно, shell-скрипт сразу после операции записи выполняет самопроверку: grep искомой строки по номеру/идентификатору, `exit 1` при отсутствии.

## Проблема

Скрипт может выполнить команду записи (echo, sed, appending) без явной ошибки, но по факту строка не попадёт в файл — из-за неверного пути, гонки, прав доступа или тихого сбоя команды. Без проверки постфактум скрипт продолжает работу с ложным предположением об успехе.

## Алгоритм

1. После операции записи — сразу выполнить `grep` искомой строки/номера в целевом файле
2. Если строка не найдена — `exit 1` с явным сообщением об ошибке
3. Не полагаться на код возврата самой операции записи как единственное подтверждение успеха

## Тест

«Проверяет ли скрипт факт присутствия записанного контента после записи, а не только код возврата команды записи?» Нет — риск тихого пропуска.

## Связи

- Общий принцип: не доверять постфактум-непроверенному результату операции (verify-before-trust)
