# DP.METHOD.176 — N параллельных субагентов с изоляцией контекста как adversarial quality gate

## Определение

Перед закрытием критической фазы: запустить N ≥ 3 субагентов параллельно, каждый с изоляцией контекста (видит только опубликованные артефакты, не ход разработки), с adversarial framing «найди, что сломано». Находка признаётся реальным дефектом только если ≥2 из N указали на неё независимо (winning threshold).

## IPO

- **Вход:** опубликованные артефакты; N промптов «найди что сломано» с изоляцией контекста
- **Процесс:** N параллельных субагентов → дедупликация находок → применение winning threshold ≥2/N
- **Выход:** подтверждённый список дефектов (≥2 голосов); вердикт «пройдено» / «найдено K дефектов»

## Инвариант

**Winning threshold: ≥2 из N.** Единственная находка = возможный шум LLM или артефакт промпта. Две независимые = реальный дефект. Минимальный N = 3 (при N=2 threshold вырождается в «оба согласны» — нет фильтрации).

## Свойства

1. **Adversarial framing:** «найди что сломано», не «проверь соответствие» — другое покрытие дефектов
2. **Context isolation:** каждый субагент читает только внешние факты (паттерн DP.METHOD.173)
3. **Noise filter:** единственная находка отбрасывается; N≥2 → real bug

## Различение с DP.METHOD.173

| Метод | Масштаб | Цель | Framing |
|-------|---------|------|---------|
| DP.METHOD.173 | Один верификатор | Соответствие канону | Neutral |
| DP.METHOD.176 | N параллельных | Найти скрытые дефекты | Adversarial |

DP.METHOD.176 использует N экземпляров паттерна 173, добавляя параллельность, adversarial framing и consensus threshold. Оба метода выросли из одного и того же источника (WP-149, peer-session 2026-07-07) — 176 продолжает генеалогию 173 внутри одного Pack, а не разветвляет её в другой домен.

## Когда применять

- Финальный quality gate перед выпуском критического автоматического процесса
- Когда solo-smoke недостаточен (сложная логика, многофайловые артефакты)
- Перед передачей процесса в production-расписание (ежедневный рендер, автоматический экспорт)

## Источник

WP-149 (генератор персональных руководств): 8 независимых субагентов перед закрытием фазы нашли 4 реальных бага. Solo-smoke до этого пропустил их все.
