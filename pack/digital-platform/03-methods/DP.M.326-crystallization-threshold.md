# DP.M.326 — Порог кристаллизации: 3-5 повторений

## Описание

**Порог кристаллизации** — количественный критерий для принятия решения о кристаллизации повторяющегося решения в правило, код или рефлекс.

Эмпирическое правило: 1-2 повторения = случайность, 3-5 = паттерн → кристаллизовать.

## IPO

| Вход | Обработка | Выход |
|------|-----------|-------|
| Наблюдаемое решение + счётчик повторений | Сравнение счётчика с порогом (3-5) | Да / Нет для кристаллизации |

## Алгоритм

1. Первое наблюдение паттерна → поставить счётчик = 1, НЕ кристаллизовать
2. Каждое повторение в новом контексте → счётчик++
3. Счётчик ≥ 3 → кристаллизовать: создать правило / рефлекс / Pack-запись
4. Счётчик < 3 → не кристаллизовать (риск overfitting к одному случаю)

## Тест корректности

«Видел ли это решение 3+ раза в разных контекстах?» Ключевое слово — **разных**: одно и то же решение в одном репо/сессии не считается.

## Признак нарушения

Кристаллизация после 1-2 наблюдений → premature crystallization. Симптом: правило/рефлекс используется только в одном контексте, выглядит «придуманным под один случай».
