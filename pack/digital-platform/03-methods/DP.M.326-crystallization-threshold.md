# DP.M.326 — Порог кристаллизации: 3-5 повторений

## Описание

**Порог кристаллизации** — количественный критерий для принятия решения о кристаллизации повторяющегося решения в правило, код или рефлекс.

Эмпирическое правило: 1-2 повторения = случайность, 3-5 = паттерн → кристаллизовать.

## Forces

| Force | Tension |
|-------|---------|
| Скорость реакции на паттерн ↔ риск overfitting | Раннее закрепление после 1-2 наблюдений экономит время до появления правила, но рискует зафиксировать случайность как норму |
| Простота единого числового порога ↔ разнородность контекстов | Порог 3-5 универсален для всех типов решений, хотя «разность контекста» у архитектурного паттерна и у bash-идиомы измеряется по-разному |
| Дисциплина ожидания порога ↔ издержки повторного изобретения | Пока счётчик не достиг порога, паттерн каждый раз решается заново вручную — метод осознанно платит эту цену ради избежания premature crystallization |
| Точность подсчёта «разных контекстов» ↔ простота учёта | Строгая проверка контекстной разности (не то же репо/сессия) точнее, но требует ручной сверки; формальный счётчик проще, но может засчитать псевдо-разные случаи |

## IPO

| Вход | Обработка | Выход |
|------|-----------|-------|
| Наблюдаемое решение + счётчик повторений | Сравнение счётчика с порогом (3-5) | Да / Нет для кристаллизации |

## Алгоритм

1. Первое наблюдение паттерна → поставить счётчик = 1, НЕ кристаллизовать
2. Каждое повторение в новом контексте → счётчик++
3. Счётчик ≥ 3 → кристаллизовать: создать правило / рефлекс / Pack-запись
4. Счётчик < 3 → не кристаллизовать (риск overfitting к одному случаю)

## Тест корректности

«Видел ли это решение 3+ раза в разных контекстах?» Ключевое слово — **разных**: одно и то же решение в одном репо/сессии не считается.

## Признак нарушения

Кристаллизация после 1-2 наблюдений → premature crystallization. Симптом: правило/рефлекс используется только в одном контексте, выглядит «придуманным под один случай».

## Bias-Annotation

| Bias | Direction of distortion |
|------|--------------------------|
| «Это явно паттерн, вижу его сразу» | Субъективная убедительность решения на первом-втором наблюдении подменяет фактический счётчик повторений |
| «Похожий контекст = разный контекст» | При подсчёте повторений внимание недооценивает, что похожие, но не различные ситуации (то же репо, та же сессия) не должны засчитываться отдельно |
| «Порог достигнут — кристаллизуй немедленно» | Фокус на факте перехода счётчика через 3, а не на качестве формулировки самого правила/рефлекса в момент кристаллизации |
| «Не кристаллизовал вовремя — упустил момент» | Тревога об пропуске порога смещает внимание к преждевременной фиксации при счётчике 2, лишь бы не «опоздать» |
