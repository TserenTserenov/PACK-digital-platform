# DP.METHOD.254 — составная роль как пересечение существующих

## Суть метода

Проектирование новой специализированной роли выполняется через явное определение как пересечения (⊗) двух уже существующих специализированных ролей, каждая из которых закрывает часть требуемой функции, вместо изобретения роли с нуля. Пересечение фиксируется явно (например, «Наставник ИИ = Диагност ⊗ Навигатор»), а не остаётся implicit-смесью функций без чёткого происхождения.

## Обоснование

Явное определение через пересечение существующих ролей упрощает АрхГейт-оценку новой роли (наследует уже проверенные свойства обеих составляющих) и облегчает понимание её функции для читателя — вместо «роль, делающая непонятно что», получаем «роль на стыке двух известных функций».

## Применение

Проектирование новой роли, функция которой может быть разложена как сочетание уже существующих специализированных ролей платформы.
