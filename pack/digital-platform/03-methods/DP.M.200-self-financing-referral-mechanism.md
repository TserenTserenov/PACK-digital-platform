# DP.M.200 — Самофинансирующийся реферальный механизм

## Описание

Реферальная программа, в которой вознаграждение привязано к % от каждого входящего платежа от приведённого пользователя — без выделенного бюджетного bucket'а.

## Механизм

```
Стандартная модель (с бюджетом):
  Общий бюджет × N% → реферальный фонд
  Фонд depletes → cap → реферер не получает при росте

Самофинансирующаяся модель:
  Входящий платёж от приведённого пользователя × K%
    → вознаграждение рефереру
  Больше приведённых → больше выручки → больше выплат
  Выплаты уже покрыты входящей выручкой
```

## Ключевые свойства

- **Нет верхнего предела** для успешного реферера — вознаграждение растёт пропорционально выручке
- **Самобалансировка** — система не может «потратить больше, чем заработала» на рефералах
- **Исключает failure mode** «реферальный бюджет кончился в середине месяца»

## Применимость

Любые B2C subscription-продукты с реферальной программой. Особенно ценно при непредсказуемом росте когорты рефереров (first-cohort onboarding, growth hack кампании).

## Антипаттерн

Выделенный реферальный бюджет (N% от общего → depletes → cap) — приводит к несправедливому cap для активных рефереров при росте программы.

## Известные примеры реализации

- Dropbox referral program (исходная модель)
- Антипаттерн: Amazon Halo (старая модель с бюджетным cap)
