# DP.METHOD.243 — env-var fallback для переносимости путей

## Суть метода

Shell-скрипт, зависящий от другого скрипта/ресурса платформы, ищет его путь в порядке приоритета: (1) переменная окружения (`IWE_SCRIPTS` и подобные), если задана; (2) относительный путь по умолчанию, вычисляемый от расположения самого скрипта — как fallback, если переменная не задана.

## Обоснование

Относительный путь по умолчанию работает только при стандартной структуре установки. Переменная окружения позволяет переопределить расположение для нестандартных установок (другая корневая директория, тестовое окружение) без правки самого скрипта — при этом сохраняется совместимость «из коробки» через fallback.

## Применение

Любой shell-скрипт платформы, зависящий от расположения других скриптов/ресурсов, которое может отличаться между установками.
