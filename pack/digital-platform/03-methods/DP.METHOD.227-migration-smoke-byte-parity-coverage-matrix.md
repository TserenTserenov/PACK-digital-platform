# DP.METHOD.227 — трёхкомпонентный смок-тест миграции каталога

## Суть метода

Проверка миграции большого каталога данных (например, каталога мемов) состоит из трёх независимых линий доказательства: (1) **байтовый паритет** — старое подмножество данных сверяется побайтово с предыдущей версией, подтверждая отсутствие непреднамеренных изменений; (2) **матрица покрытия** — новые записи проверяются на присутствие во всех ожидаемых сочетаниях классификационных осей (например, все 30 комбинаций «область × ступень»); (3) **живой аргумент выдержки** — система уже эксплуатировалась на реальном трафике (пилотный бот) в течение периода, охватывающего момент миграции, без нареканий.

## Обоснование

Ни один из трёх компонентов сам по себе не даёт полной уверенности: байтовый паритет не проверяет полноту новых данных, матрица покрытия не проверяет, что старые данные не искажены, а живая эксплуатация не гарантирует отсутствие латентных проблем на редких путях. Вместе три линии закрывают разные классы риска миграции.

## Применение

Валидация любой миграции большого структурированного каталога данных, где часть контента переносится без изменений, а часть — расширяется новыми записями.
