# DP.METHOD.231 — опциональный блок ссылок вместо отдельного файла

## Суть метода

Расширение существующего контракта записи (например, добавление контент-брифа к теме) реализуется как опциональный блок внутри уже существующей структуры, хранящий ссылки-идентификаторы (`maps_to`-подобные) на связанные каталоги, а не копии их содержимого, и не как отдельный обязательный файл/поле. Изменения в справочных каталогах, на которые ссылается блок, не требуют каскадного обновления уже записанных единиц — блок продолжает указывать на актуальную версию каталога через идентификатор.

## Обоснование

Хранение ссылки вместо копии избегает дублирования данных и рассинхрона (копия устаревает, ссылка — нет). Опциональность блока (вместо обязательного поля/файла) не ломает существующие записи формата, созданные до появления расширения — контракт остаётся один для всех пишущих процессов, старых и новых.

## Применение

Расширение существующего формата записи новым опциональным содержанием, которое ссылается на другие, отдельно эволюционирующие каталоги/справочники.
