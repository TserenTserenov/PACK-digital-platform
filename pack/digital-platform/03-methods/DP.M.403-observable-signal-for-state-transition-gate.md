# DP.M.403 — Наблюдаемый сигнал для State-Transition Gate

## Суть метода

При объявлении целевого перехода состояния (State-Transition Gate, WP-457) добавляется опциональное поле `signal` — одна строка, описывающая конкретный наблюдаемый признак, по которому можно будет подтвердить, что переход реально произошёл.

## Проблема

Декларация целевого перехода состояния сама по себе не даёт способа проверить, случился ли переход на практике. Без явного наблюдаемого признака подтверждение перехода остаётся субъективным утверждением.

## Пример

`signal: "нет спонтанных полных разлогинов 2 недели подряд"` — конкретный, проверяемый по логам/наблюдению признак вместо общей фразы «пользователь стал реже разлогиниваться».

## Алгоритм

1. При формулировке State-Transition Gate — опционально добавить поле `signal`
2. Сформулировать его как одну конкретную, наблюдаемую и проверяемую фразу (не абстрактное улучшение)
3. При проверке факта перехода — сверяться с этим сигналом, а не с общим впечатлением

## Тест

«Можно ли проверить наступление сигнала внешним наблюдением, не спрашивая мнение агента?» Да — сигнал сформулирован корректно.
