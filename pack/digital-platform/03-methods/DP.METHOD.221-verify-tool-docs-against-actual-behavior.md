# DP.METHOD.221 — верификация документации против фактического поведения

## Суть метода

Формулировка документации инструмента (например, «проверка per-file») сверяется с реальным поведением кода (например, оказавшимся суммарной проверкой, а не per-file) — расхождение исправляется на стороне текста документации, чтобы точно описывать механизм, а не наоборот подгонять код под уже написанный текст без необходимости.

## Обоснование

Документация, написанная в момент проектирования, может разойтись с реализацией к моменту, когда её фактически читают — без явной верификации читатель получает неверную ментальную модель поведения инструмента.

## Применение

Периодическая или триггерная (при обнаружении несостыковки) сверка описаний механизмов в документации с их актуальной реализацией в коде.
