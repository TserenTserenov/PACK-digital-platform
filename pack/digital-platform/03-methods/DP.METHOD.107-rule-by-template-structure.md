# DP.METHOD.107 — Правило структурой шаблона

## Описание

Ограничение кодируется устройством шаблона (именованный слот = единственное допустимое место), а не прозой. Нарушить правило структурно невозможно — другого слота не существует.

## IPO

**Input:** правило с неоднозначным соблюдением или подверженное нарушению

**Process:**
1. Определить функцию ограничиваемого элемента
2. Создать в шаблоне ровно один именованный слот для этой функции
3. Убрать текстовую инструкцию — устройство макета не оставляет агенту выбора

**Output:** шаблон, в котором правило закодировано структурой, не инструкцией

## Пример

WP-149: секция «На практике» — единственный слот для примера из рабочего продукта пилота. Агент физически не может вставить такой пример в другое место шаблона.

## Лестница надёжности enforcement

1. Текстовый запрет (слабо)
2. Правило-по-функции (DP.METHOD.105)
3. Структурный слот шаблона — настоящий (сильно)

## Антипаттерн

Дублировать правило одновременно в структуре и в прозе → при расхождении агент выбирает прозу. Структура должна быть единственным carrier.
