# DP.METHOD.244 — grep-аудит URL перед decommission сервиса

## Суть метода

Перед выводом сервиса из эксплуатации допущение «на него больше никто не ссылается» проверяется явно, а не принимается на веру: (1) grep по всем репозиториям на упоминание URL/адреса сервиса в коде и конфигах, (2) проверка входящего трафика сервиса за последние 7-14 дней, (3) проверка DNS-записей, ссылающихся на сервис. Наличие дублирующего кода в другом месте — повод для отдельного рефакторинга, не аргумент в пользу немедленного decommission без проверки.

## Обоснование

«Ничего не смотрит» — интуитивное допущение, регулярно ошибочное на практике: скрытые потребители (cron-задачи, внешние интеграции, забытые конфиги) не всегда очевидны из беглого просмотра активного кода. Три независимые проверки (код, трафик, DNS) закрывают разные классы скрытых потребителей.

## Применение

Вывод любого сервиса/эндпоинта из эксплуатации, где цена ошибочного decommission (сломанный незамеченный потребитель) выше стоимости проверки.
