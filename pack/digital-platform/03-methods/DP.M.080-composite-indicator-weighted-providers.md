# DP.M.080: Composite indicator — взвешенная сумма провайдеров

## Когда применять

Характеристика системы имеет **слабый сигнал из единственного источника** и требует расширения покрытия без потери проверяемости. Типовые случаи:

- Мировоззренческие/качественные характеристики (cp.wld, cp.agt, bh.awr) — детерминированный счёт по activity даёт низкий recall.
- Качество кода/архитектуры/обучения — single-signal не покрывает все аспекты.
- Multiplier-индикаторы из нескольких событий (IND.3.2.04 day_close multiplier).

## Формула

```
characteristic(final) = Σᵢ wᵢ ⋅ providerᵢ(input)
```

Σ wᵢ = 1; провайдеры:
1. **Activity provider** — детерминированный счёт по `activity_log` (правила FORM.089 §6.1).
2. **Content provider** — LLM-производный proxy по первичному контенту (W-рефлексии, captures, переписка). Реализация: Honcho/Mem0/Hindsight-style memory.
3. **Self-assessment provider** — опрос пользователя (структурированный, рубрики 1-5).
4. **Peer-review provider** — экспертная оценка (R28 Диагност, наставник, peer-агент).

## Контракт верификации

- Калибровка весов wᵢ — на отдельной размеченной выборке (≥30 случаев).
- Целевой критерий: `r > 0.6` с экспертной оценкой как ground truth.
- Каждый провайдер измерим независимо (precision/recall можно посчитать отдельно).
- Веса прозрачны (явная конфигурация, не «магия модели»).

## Пример (cp.wld мировоззрение)

```
cp.wld(final) = 0.3 ⋅ deterministic(activity_log)     # сильный сигнал для cp.rhy/skl/iwe/int, слабый для wld
              + 0.4 ⋅ proxy_world_systems(Honcho)     # семантический поиск признаков «системного взгляда» в captures/W-рефлексиях
              + 0.2 ⋅ self_assessment(survey)         # пилот сам оценивает 1-5 по рубрике
              + 0.1 ⋅ peer_review(R28 Диагност)       # экспертная коррекция
```

## Анти-паттерны

- **Single-source fanaticism** — «детерминированный счёт = единственный честный способ». Игнорирует характеристики, плохо измеримые из activity.
- **Black-box composition** — веса спрятаны в нейросети без эмпирической калибровки. Нарушает прозрачность.
- **Σ wᵢ ≠ 1** — нарушение интерпретируемости (результат не в той же шкале, что провайдеры).

## Применимость

- WP-218 multiplier IND.3.2.04 (та же модель «несколько источников → один показатель»).
- Assessment-функции FORM.089 §6.1.
- ML-метрики качества кода/архитектуры/обучения.
- Любые «мягкие» характеристики системы.

## Различение с DP.M.057 (ML-component-AB-evaluation)

DP.M.057 — про сравнение **разных версий** оценщика. DP.M.061 — про **композицию провайдеров** внутри одной оценки. Можно использовать DP.M.057 для калибровки весов wᵢ в DP.M.061.
