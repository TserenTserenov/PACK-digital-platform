# DP.M.307 — Bootstrap mode метрики по истории класса: hidden / interval / point

## Проблема

Производная метрика (рычаг, множитель, средний результат, коэффициент) требует накопленной истории, чтобы быть надёжной. Показать точечную оценку при N=2 — обман: один выброс качает всё значение, доверие к панели подрывается.

## Метод

Режим показа метрики определяется размером выборки N самого слабого класса периода. Явные пороги:

| Порог | Режим | Что показывается |
|-------|-------|------------------|
| N < BOOTSTRAP_HIDE (напр. 5) | hidden | Метрика скрыта, только сырые тайлы |
| BOOTSTRAP_HIDE ≤ N < BOOTSTRAP_POINT (напр. 5..15) | interval | Интервал с шириной по дисперсии |
| N ≥ BOOTSTRAP_POINT (напр. 15) | point | Точечная оценка |

Пороги — параметр метода-источника (версионируются вместе с формулой, см. frozen formula hash), не магические константы в воркере.

## Применимость

Новые дашборды пользователей, статистика редких событий, A/B-метрики в раннем окне — любые производные метрики с накапливаемой историей.

## Антипаттерн

Единственный режим «показывать точку всегда» с дисклеймером «учитывайте малую выборку» — никто не учитывает, доверие к платформе подрывается целиком.
