# DP.M.358 — Grep существующих слотов планирования до создания новых

## Описание

При интеграции нового процесса с системой планирования IWE (DayPlan / WeekPlan / Strategy) возникает соблазн создать новую секцию в шаблоне. Этот метод говорит: сначала проверь, не существует ли уже слот с нужным назначением.

Нарушение создаёт дрейф OwnerIntegrity: два слота с одним смыслом → планы расходятся, один устаревает.

## Algorithm

### Шаг 1: Grep по шаблонам

Выполнить поиск в шаблонах DayPlan, WeekPlan и Strategy по ключевым словам назначения нового слота.

```bash
grep -r "контент\|video\|план.*публикац" ~/IWE/FMT-exocortex-template/ 2>/dev/null
```

### Шаг 2: Тест применимости

Задать вопрос: «Слот с похожим назначением уже есть?»
- Да → наполнять существующий слот, не создавать новый
- Нет → добавление нового слота обосновано

### Шаг 3: Зарегистрировать связку

Зафиксировать: «процесс X наполняет слот Y в шаблоне Z». Это предотвращает повторное предложение нового слота в следующих итерациях.

## When to use

- При проектировании связки нового процесса с ритмом дня/недели
- При добавлении нового типа контента в существующую систему планирования
- При появлении нового повторяющегося процесса, требующего слота в расписании

## Тест применимости

«Grep возвращает слот с похожим назначением?»
- Да → использовать его, не создавать новый
- Нет → создание нового слота обосновано (задокументировать назначение)
