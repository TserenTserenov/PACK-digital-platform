# DP.M.219 BY-SCRIPT маркер — идемпотентная авто-инжекция в шаблонный файл

## Описание

Паттерн идемпотентной вставки контента скриптом в текстовый файл при периодических запусках: при вставке добавляется явный HTML-комментарий-маркер `<!-- BY-SCRIPT -->` рядом с вставленным блоком; при следующих запусках скрипт проверяет наличие маркера вместо попытки распознать вставленный контент.

## IPO

**Вход:** шаблонный файл (DayPlan.md), периодически запускаемый скрипт (daily trigger), блок контента для вставки (WeekPlan YAML-секция)
**Процесс:**
1. Первый запуск: проверить отсутствие `<!-- BY-SCRIPT -->` в файле → вставить блок контента + маркер
2. Повторный запуск: обнаружить `<!-- BY-SCRIPT -->` → пропустить вставку (idempotent skip)
**Выход:** вставка выполнена ровно один раз, независимо от кратности запусков скрипта

## Реализация (WP-356)

```python
import re, pathlib

MARKER = "<!-- BY-SCRIPT -->"
content = pathlib.Path("DayPlan.md").read_text()

if MARKER not in content:
    injected = weekplan_yaml_block + "\n" + MARKER
    content = re.sub(r"(## Бюджет недели\n)", r"\1" + injected + "\n", content)
    pathlib.Path("DayPlan.md").write_text(content)
```

## Преимущества перед альтернативами

| Альтернатива | Проблема |
|-------------|---------|
| Проверка содержимого | Контент может совпасть с шаблоном, пустая строка = «не вставлено», регрессия при изменении шаблона |
| Timestamp-файл рядом | Внешний state, не атомарен с файлом, не видно в самом файле |
| **BY-SCRIPT маркер** | Явный, невидимый для пользователя (HTML-комментарий), атомарен с файлом, независим от содержимого |

## Тест идемпотентности

«Если запустить скрипт дважды подряд — файл после второго запуска идентичен файлу после первого?» Да с BY-SCRIPT маркером — маркер обнаружен, вставка пропускается.
