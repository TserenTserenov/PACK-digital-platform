# DP.M.225 — Identity-anchor персонаж в семинаре

## Суть

При проектировании семинара для смешанной аудитории выбрать одного главного персонажа — identity-anchor — с которым аудитория идентифицируется и через трансформацию которого проходит. Второй персонаж — контраст/лестница входа, вспомогательный.

## Механизм

1. Определить главного персонажа (identity-anchor): максимально близкий к целевой аудитории по возрасту, опыту, ситуации
2. Определить вспомогательного (контрастный вход): более «понятная» точка входа для части аудитории, лестница к главному
3. Явно обозначить в нарративной структуре: «Семинар в первую очередь про [главного]»
4. Все ключевые блоки семинара строить вокруг трансформации главного персонажа

## Антипаттерн

Два равноправных персонажа создают когнитивный split — аудитория не знает с кем идти.

## Применимость

Любой семинар / вебинар / курс для смешанной аудитории с несколькими сегментами (возраст, опыт, ситуация).

## Примеры

- WP-351: Олег 42 (главный, identity-anchor) + Анна 24 (контрастный вход)
