# DP.M.225 — Identity-anchor персонаж в семинаре

## Суть

При проектировании семинара для смешанной аудитории выбрать одного главного персонажа — identity-anchor — с которым аудитория идентифицируется и через трансформацию которого проходит. Второй персонаж — контраст/лестница входа, вспомогательный.

## Механизм

1. Определить главного персонажа (identity-anchor): максимально близкий к целевой аудитории по возрасту, опыту, ситуации
2. Определить вспомогательного (контрастный вход): более «понятная» точка входа для части аудитории, лестница к главному
3. Явно обозначить в нарративной структуре: «Семинар в первую очередь про [главного]»
4. Все ключевые блоки семинара строить вокруг трансформации главного персонажа

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Идентификация аудитории ↔ охват смешанной аудитории | Главный персонаж должен быть близок целевой аудитории, но если он слишком узкий — часть аудитории отпадает; контрастный вход решает это, но требует чёткой подчинённости |
| Главный персонаж ↔ контрастный вход | Второй персонаж помогает входить в материал, но если он равноправен — аудитория не знает, с кем идти; метод платит иерархией за ясность |
| Трансформация главного ↔ лестница для других | Все блоки строятся вокруг главного, но контрастный вход должен быть достаточно развит, чтобы не казаться декорацией |

## Антипаттерн

Два равноправных персонажа создают когнитивный split — аудитория не знает с кем идти.

## Применимость

Любой семинар / вебинар / курс для смешанной аудитории с несколькими сегментами (возраст, опыт, ситуация).

## Примеры

- WP-351: Олег 42 (главный, identity-anchor) + Анна 24 (контрастный вход)

## Bias-Annotation

_Куда систематически съезжает внимание практикующего._

| Bias | Direction of distortion |
|------|--------------------------|
| Два равноправных персонажа кажутся «справедливыми» | Практикующий боится обидеть часть аудитории и делает двух персонажей равными — аудитория получает когнитивный split и не знает, с кем идти |
| Главный персонаж выбирается по близости к автору, а не к аудитории | Автор проектирует персонажа «как себя», а не по данным целевой аудитории; участники не идентифицируются с ним |
| Контрастный вход превращается в полноценный трек | Второй персонаж получает слишком много времени и блоков, потому что «он тоже важен» — иерархия размывается, семинар распадается на два параллельных |
