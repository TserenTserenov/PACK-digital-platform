# DP.METHOD.122 — Month Close: пересборка стратегического контекста как A1.5

## Описание

После финализации стратегических источников месяца и ДО коммита — обязательный запуск `build-strategic-context.py` (шаг A1.5). Derived-артефакт `current/strategic-context.yaml` собирает: цели R месяца, топ-НЭП, ТОС недели, привязки РП→R, активные проекты. Без пересборки производные системы (персональные руководства, дашборды) работают с устаревшим контекстом.

## IPO

**Input:** финализированные стратегические источники месяца (Strategy.md, WeekPlan, активные РП с привязкой к целям R)

**Process:**
1. Финализировать стратегические источники месяца
2. Запустить: `python3 build-strategic-context.py`
3. Exit 1 = секция не собралась (исправить источник); файл всё равно записывается (best-effort)
4. Закоммитить результат вместе с другими артефактами Month Close

**Output:** `current/strategic-context.yaml` — актуальный контекст для downstream систем

## Два обязательных триггера

| Событие | Причина |
|---------|---------|
| Month Close | Смена целей R месяца |
| Strategy Session при смене фокуса | Цели R изменились внутри месяца |

Один триггер (только Month Close) недостаточен: если фокус меняется на Strategy Session — руководства рендерятся с устаревшим контекстом.

## Тест применимости

«После Month Close — если рендеришь персональное руководство, получаешь актуальные цели месяца?» Нет → шаг A1.5 пропущен или скрипт сломан.

## Антипаттерн

Один триггер вместо двух: пересборка только при Month Close, но не при изменении стратегического фокуса внутри месяца.
