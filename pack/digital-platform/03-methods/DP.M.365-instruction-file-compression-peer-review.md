# DP.M.365 — Граница безопасной компрессии инструктивного файла

## Описание

При срезании контекстного бюджета инструктивного файла (CLAUDE.md, SKILL.md, protocol-*.md)
возникает соблазн заменить развёрнутые правила ссылками «смотри [файл]». Это безопасно
только для правил-указателей. Правила с исполняемыми шагами нельзя сжимать до ссылки —
агент не выполнит шаги в нужный момент.

## IPO

**Вход:** кандидат на компрессию (правило/раздел инструктивного файла)
**Процесс:** peer-review задаёт тест: «если убрать inline содержимое, агент всё равно выполнит нужные шаги?»
**Выход:** решение compress (ссылка) / keep-inline (исполняемый чек-лист)

## Алгоритм (инвариант peer-review при компрессии)

1. Идентифицировать тип правила: **указатель** (ссылается на внешний артефакт) или **исполняемый чек-лист** (содержит конкретные шаги для выполнения в момент действия).
2. **Тест:** «Если убрать inline содержимое, агент всё равно выполнит нужные шаги?»
   - **Да** → указатель; безопасно заменить ссылкой.
   - **Нет** → исполняемый чек-лист; оставить inline.
3. **Дополнительный критерий:** правило-ссылка безопасна только если inline ≤ 1 строки-резюме без перечисленных шагов.

## Примеры

| Тип | Пример | Решение |
|-----|--------|---------|
| Указатель (безопасно) | «WP Gate — см. protocol-open.md» | compress → ссылка |
| Исполняемый (небезопасно) | IntegrationGate (4 шага: обещание → сценарии → роль → реализация) | keep-inline |
| Исполняемый (небезопасно) | drift-guard (конкретные условия блокировки + exemption-tag) | keep-inline |
