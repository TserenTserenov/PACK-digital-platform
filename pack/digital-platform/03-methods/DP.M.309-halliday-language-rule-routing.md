# DP.M.309 — Маршрутизация правил языка по осям Холлидея

## Обещание

Однозначно определяет хранилище для правила языкового стиля агента, предотвращая копирование правил между Паками и drift при обновлении.

## Три оси (Systemic Functional Linguistics, M.A.K. Халлидей)

| Ось | Вопрос | Маршрут в IWE |
|-----|--------|---------------|
| **Поле (Field)** | ЧТО говорим? (тема, домен, лексика) | → Pack домена (DP, PP, MIM, …) |
| **Отношение (Tenor)** | КТО автор/читатель? (регистр, формальность) | → Pack стилей / риторики |
| **Канал (Mode)** | ЧЕРЕЗ ЧТО? (Telegram, IDE, браузер) | → Слой интерфейса IWE |

## Алгоритм

1. Взять правило языка
2. Определить ось: «ЧТО говорим / КТО говорит / ЧЕРЕЗ ЧТО?»
3. Маршрутизировать в соответствующее хранилище
4. Если правило покрывает 2+ оси → разбить на атомарные части, маршрутизировать раздельно

## Тест

«Если перенести правило в другой Pack/слой — оно будет иметь смысл без изменений?»
- Да → ось определена правильно, правило атомарно
- Нет → разбить или переопределить ось

## Применение в IWE

- Предметная лексика МИМ-домена → PACK-MIM distinctions (field)
- Правила регистра и формальности → Pack стилей (tenor)
- Канальная адаптация Telegram vs claude.ai → config интерфейса (mode)
