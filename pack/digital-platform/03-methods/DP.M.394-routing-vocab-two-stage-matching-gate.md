# DP.M.394 2-ступенчатый гейт совпадения в routing-vocab

## Определение

Маршрутизация фразы к записи routing-vocab не считается решённой по первому текстовому совпадению. Гейт из двух ступеней:

1. **Сбор всех кандидатов** по смыслу ситуации (не первое совпадение подстроки, а полный список записей, релевантных ситуации).
2. **Эскалация**, если кандидатов ≥2 ИЛИ ни один кандидат не бьётся по колонке «Признак ситуации» — решение не принимается автоматически по первому найденному совпадению.

## Отличие от DP.FM.296

`DP.FM.296` — про stale-путь в routing-vocab, молча блокирующий Knowledge Extraction (проблема протухших данных). `DP.M.394` — про логику самого matching-алгоритма (проблема неоднозначности при живых данных). Разные слои одной подсистемы.

## Правило

Routing-vocab lookup с потенциальной неоднозначностью → двухступенчатый гейт (собрать всех кандидатов → эскалировать при ≥2 или 0 уверенных), не первое совпадение.
