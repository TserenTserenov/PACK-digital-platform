# DP.METHOD.217 — трёхфакторное ранжирование триажа фаз

## Суть метода

При выборе порядка обработки набора независимых фаз/пунктов (например, зависших фаз одного каталога) используется ранжирование сразу по трём факторам: (1) насколько пункт связан с текущим активным РП, (2) насколько он важен для приоритетов текущей недели, (3) сколько трудозатрат он требует. Итоговый порядок — компромисс между этими факторами, не сортировка по одному из них.

## Обоснование

Ранжирование по одному фактору (например, только по трудозатратам «сначала простое») систематически откладывает пункты, критичные для текущего РП или недели, если они требуют больше усилий. Трёхфакторная модель не даёт ни одному измерению доминировать безусловно.

## Применение

Триаж набора независимых пунктов/фаз каталога (backlog, зависшие фазы долгоживущего РП) перед выбором порядка их обработки.
