# DP.METHOD.229 — локальный манифест исключений переживает обновление платформы

## Суть метода

Пользовательские исключения путей из автоматического обновления платформы хранятся в отдельном файле, помеченном как «локальный» (`update-manifest.local.json`), к которому основной скрипт обновления (`update.sh`) не имеет доступа на запись — вместо попытки слияния пользовательских исключений с апстримным манифестом (union-merge), которая не позволяет пользователю впоследствии удалить исключение (апстрим не может «раз-исключить» путь, добавленный локально).

## Обоснование

Union-merge с апстримом делает пользовательское исключение необратимым апстримом — если пользователь захочет вернуть путь под управление обновления, апстрим не может отменить то, что сам не добавлял. Отдельный локальный файл, полностью игнорируемый обновлением, даёт пользователю полный контроль над собственными исключениями в обе стороны.

## Применение

Дизайн механизма пользовательской кастомизации, сосуществующего с автоматическим platform-обновлением (шаблонные репозитории, template-sync).
