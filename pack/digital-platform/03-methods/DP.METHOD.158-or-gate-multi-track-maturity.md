# DP.METHOD.158: OR-гейт по двум осям зрелости

## Назначение

Проектирование гейта для продвинутой функции в системе с ≥2 независимыми осями прогресса так, чтобы пользователи, достигшие зрелости через любую из осей, получили доступ.

## Применять когда

- Система имеет ≥2 независимых оси прогресса (учебная ступень, квалификационный уровень, стаж и т.д.)
- Продвинутая функция требует зрелости, но зрелость достижима разными путями
- AND-гейт исключает реальных опытных пользователей, вошедших через альтернативный путь

## Паттерн

```python
STAGE_THRESHOLD = 4   # Дисциплинированный и выше (учебная ось)
QUAL_THRESHOLD = "L2"  # Работник и выше (квалификационная ось)

# OR-gate: доступ при зрелости по любой оси
if stage_raw >= STAGE_THRESHOLD or qual_level >= QUAL_THRESHOLD:
    enable_advanced_feature()
else:
    skip_advanced_feature()  # обе оси ниже порогов
```

Порог на каждой оси задаётся независимо под семантику той оси.

**Тест выбора OR vs AND:**
- «Может ли пользователь достичь нужной зрелости через разные пути?» → **OR**
- «Обе оси ОБЯЗАТЕЛЬНО нужны одновременно, независимо от пути?» → **AND**

## Пример

Гейт для функции «задание-наставник» (WP-149, SKILL.md personal-guide-render):

Первая версия: `stage_raw >= 4` (AND-логика через единственный критерий). Исключала Реформатора (qual_level=L7), у которого stage_raw < 4 — пользователь зрелый, но через другую ось.

Фикс: `stage_raw >= 4 OR qual_level >= L2` — доступ при выполнении любого из условий.
