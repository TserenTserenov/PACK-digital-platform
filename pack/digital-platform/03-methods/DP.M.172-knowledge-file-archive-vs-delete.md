# DP.M.172 — Knowledge-file archive: Variant B (git mv)

## Проблема

При накоплении N knowledge-файлов (feedback_*.md, lessons_*.md) в активной директории:
- **Вариант A (удаление):** теряется исследовательская ценность и git-история.
- **Вариант B (git mv в archive/):** файлы доступны через `git log -p`, но не попадают в context scan агента.

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Чистота hot-directory (файлы не попадают в context scan агента) ↔ сохранение исследовательской ценности и git-истории | `git mv` в archive/ даёт ту же разгрузку контекста, что и удаление (Вариант A), но оставляет файлы доступными через `git log -p` для человеческой ретроспективы — цена: archive/ растёт и требует дисциплины структуры (feedback/, lessons/) |
| Простота «просто оставить файл лежать» ↔ систематическая доступность знаний | Файл в memory/ не требует никаких решений, но принцип разделения требует двух целевых хранилищ: систематически используемое агентом → SQLite (primary, queryable, decaying), ретроспективное человеку → archive/ — каждое дороже инерции, дешевле накопления |

## Решение: Variant B

```bash
git mv memory/feedback_*.md memory/archive/feedback/
git mv memory/lessons_*.md memory/archive/lessons/
git commit -m "archive: move N knowledge files to reduce context pollution"
```

**Принцип разделения:**
- **Агент использует систематически** → SQLite (primary, queryable, decaying)
- **Человеку нужно для ретроспективы** → archive/ (git-accessible, не в hot-directory)

## Когда применять

| Сигнал | Действие |
|--------|---------|
| N > 30 файлов в одной директории | Предложить архивацию на Week Close |
| Файл не открывался > 30 дней | Кандидат на архивацию |
| Файл дублирован в SQLite | Приоритетный кандидат |

## Тест

«Нужен ли файл агенту в текущей сессии?»
- Нет → archive/, не hot-directory.
- Да, систематически → SQLite.

## Связи

- AS.D.018 — Hermes (SQLite = primary после архивации файлов)

## Bias-Annotation

_Куда систематически съезжает внимание практикующего._

| Bias | Direction of distortion |
|------|--------------------------|
| Счётчик файлов затмевает сигналы использования | Триггером архивации становится «N > 30 в директории» как самое видимое число, а проверки «не открывался > 30 дней» и «дублирован в SQLite» пропускаются — под `git mv` попадают файлы, которые агент ещё читает, и наоборот |
| Видимый порядок в hot-directory затмевает невидимую судьбу archive/ | После `git mv` задача считается закрытой; практик не возвращается к вопросу, обращается ли кто-то к archive/ через `git log -p` вообще, — «сохранено» подменяет «используется» |
