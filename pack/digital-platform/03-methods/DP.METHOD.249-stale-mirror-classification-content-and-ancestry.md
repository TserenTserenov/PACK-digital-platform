# DP.METHOD.249 — content + ancestry для классификации stale-mirror

## Суть метода

Прежде чем self-heal механизм выполняет `reset --hard` для устранения предполагаемого «устаревшего зеркала» (stale mirror) — классификация опирается не только на содержимое dirty-файлов (совпадает ли с известным устаревшим паттерном), но и на родословную коммитов (ancestry) — есть ли среди отброшенных изменений реальный непушенный коммит.

## Обоснование

Гейтинг только по содержимому dirty-файлов даёт ложноположительный вердикт «это просто устаревшее зеркало, можно сбросить», если реальный непушенный коммит по случайности совпал по содержимому с известным паттерном stale-mirror. `reset --hard` в таком случае тихо теряет реальную незапушенную работу.

## Применение

Дизайн любого self-heal/автоматического механизма, использующего `git reset --hard` на основе эвристики распознавания «известного мусора» — эвристика должна учитывать commit-graph, не только текстовое содержимое.
