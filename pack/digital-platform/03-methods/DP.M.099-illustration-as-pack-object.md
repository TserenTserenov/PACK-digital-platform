# DP.M.099 Иллюстрации как первоклассные Pack-объекты

## Суть метода

Когда в Pack используются примеры, аналогии или иллюстрации для объяснения концептов — хранить их как формализованные Pack-объекты с frontmatter (audience_level, effect, concept, structural_relation), а не встроенным текстом.

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Переиспользуемость иллюстрации ↔ цена формализации | Pack-объект со ссылкой по ID убирает дублирование примера в разных разделах, но каждая аналогия требует отдельного файла `{PREFIX}.ILL.{NNN}` и заполнения frontmatter вместо быстрой inline-вставки |
| Структурная точность аналогии ↔ её яркость для аудитории | Инвариант structural_relation («можно ли объяснить через иллюстрацию любое следствие концепта?») отсекает поверхностные сравнения, но структурно точная иллюстрация может быть менее доступна для заявленного audience_level, чем яркий поверхностный образ |

## Инвариант

Возвращаемый объект-иллюстрация **сохраняет структурные отношения** концепта (не только поверхностное сходство). Тест: «можно ли объяснить через эту иллюстрацию любое следствие концепта?» Да → структурное, Нет → поверхностное.

## Шаги

1. Определить концепт, для которого нужна иллюстрация
2. Создать файл `{PREFIX}.ILL.{NNN}-{slug}.md` в директории Pack'а
3. Frontmatter: `concept`, `structural_relation` (что именно сохраняется), `audience_level`, `effect`
4. Хранить в Pack, ссылаться из контента по ID

## Тест применимости

«Есть ли примеры/аналогии, которые используются повторно в разных разделах?» Да → Pack-объект, не inline.

## Прецедент

PACK-rhetoric v0.1.0 (WP-340, 2026-05-19): RHE.ILL.001 (Болид), RHE.ILL.002 (Асептика), RHE.ILL.003 (Земмельвейс) как seed illustrations с RHE.SC.001-инвариантом.

## Bias-Annotation

_Куда систематически съезжает внимание практикующего. Epistemic stage карточки — `demonstrated`._

| Bias | Direction of distortion |
|------|--------------------------|
| Яркость образа затмевает структурный тест | Внимание практика выбирает запоминающуюся аналогию и не прогоняет инвариант structural_relation («можно ли объяснить через иллюстрацию любое следствие концепта?») — получается поверхностная иллюстрация, которую тест отсеял бы |
| Inline-вставка по инерции скорости | При написании контента внимание на темпе изложения, и пример встраивается текстом, хотя тест применимости («используется ли повторно в разных разделах?») уже отвечает «да» и требует Pack-объекта `{PREFIX}.ILL.{NNN}` с frontmatter |
