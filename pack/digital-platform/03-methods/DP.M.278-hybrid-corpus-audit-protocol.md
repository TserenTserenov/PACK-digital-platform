# DP.M.278 — Hybrid Corpus Audit Protocol (A-D)

**Назначение:** доказательная верификация качества большого однородного корпуса документов без полного прохода.

## Когда применять

Корпус N≥20 файлов с повторяющейся структурой (гайды, технические документы, обучающие материалы). Полный проход нецелесообразен; нужна достаточная уверенность при приемлемых затратах.

## Протокол (4 фазы)

**A — Автоматический скрипт:**
Запустить машинную проверку по всему корпусу (100% охват). Ловит паттерны, доступные regex/AST: em-dash, форматирование, запрещённые фразы.

**B — Boundary check:**
Первый и последний файл каждого раздела/группы. Написаны в разные моменты времени → выявляет drift между «было» и «стало».

**C — Mid check:**
Средний файл раздела (медиана). Исключает bias «только начало и конец хороши».

**D — Aux structure-only:**
Файлы без нарративного текста (таблицы, вопросы, упражнения) → только фаза A. Тональность и аналогии к aux неприменимы.

## Критерий достаточности

Выборка даёт достаточную уверенность при одновременном выполнении:
1. Фаза A: 100% PASS по всему корпусу
2. Фазы B+C: нет rejection в выборке (≈25-30% корпуса)

При нарушении → переход к полному проходу нарушающего раздела.

## Пример

33 файла гайдов → A: 33/33 PASS → B+C: 9 файлов (27%) → 🟡2 PASS везде → verdict: принято.
