# DP.M.137 — Авто-триггер субагент-ревью при первом подразделе новой секции

## Описание (IPO)

**Вход:** CI-событие — новый файл с паттерном `s{N}.01-*.md` в директории секции, которая ранее была пустой.
**Процесс:** Запуск субагент-ревью (context isolation) для валидации первого подраздела.
**Выход:** Блокирующий отчёт (MUST-FIX) или одобрение (merge allowed).

## Алгоритм

1. CI/pre-commit обнаруживает файл с паттерном `s{N}.01-*.md` в новой директории секции
2. Проверяет: директория ранее была пустой (первый SS)? Если да → запустить субагент
3. Субагент (context isolation) проверяет:
   - Шаблонное соответствие frontmatter (cp_check/bh_check якоря)
   - Наличие мем-снятия (B2/B3 компоненты раздела)
   - Корректность структуры по шаблону секции
4. MUST-FIX найдены → блокировать merge
5. Ревью пройдено → разрешить merge

## Принцип

Первый подраздел задаёт тон всей секции. Исправление шаблона после 1 подраздела требует ~30 мин; после 10 — ~5ч.

## Применимость

Любой курс/руководство с шаблонной структурой контента и CI-пайплайном.
