# DP.M.371 — Байт/5 как прокси токенов при отсутствии API-доступа

## Описание

Метод быстрой оценки размера контекста в токенах без API-вызова: делить суммарный размер файлов в байтах на 5. Применяется для PASS/FAIL проверки бюджетных ограничений (M1 ≤ 20K, M2 ≤ 30K) в среде Claude Code, где `anthropic.messages.count_tokens` без API-ключа недоступен.

## Формула

```
estimated_tokens ≈ total_file_size_bytes / 5
```

Пример: CLAUDE.md 18904 байт → ~3781 токенов прокси. Бюджет M1 ≤ 20K → PASS.

## Алгоритм для нескольких файлов

1. Суммировать байты всех файлов в горячем каркасе
2. Разделить сумму на 5 — результат прокси-токенов
3. Сравнить с пороговым значением бюджета

Не применять MEDIAN_RATIO по каждому файлу отдельно — граничные эффекты BPE вносят смещение.

## Точность и ограничения

| Ситуация | Точность |
|----------|----------|
| ASCII-текст (EN) | ~1 байт/токен → прокси завышает в 5× |
| Кириллица | ~2 байт/токен → прокси завышает в 2.5× |
| Смешанный текст | приближение ≈ ±20% |

- **Применять:** для PASS/FAIL с порогом ≥ 20% запаса
- **Не применять:** когда значение близко к лимиту (±5%) — нужен точный подсчёт
