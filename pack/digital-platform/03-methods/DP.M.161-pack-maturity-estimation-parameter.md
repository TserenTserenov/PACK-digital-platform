# DP.M.161 — Pack-зрелость как параметр оценки трудозатрат

## Суть

При оценке трудозатрат derivative artifact (руководство из Pack, доклад из метода, курс из формализации) сравнивать не только **формат результата**, но и **зрелость source-материалов**. Артефакт того же типа из Pack другой зрелости — другой класс работы.

## Контекст обнаружения

Guide 1-3 ЛР занял ~15h каждый. Писатель экстраполировал: Guide РР ≈15h. Структурный разбор:

| Параметр | Pack ЛР | Pack РР |
|----------|---------|---------|
| Онтология | полная | заглушки |
| Методы | формализованы | 0/5 формализованы |
| RCS / нормативная матрица | есть | отсутствуют |
| Режим написания | «adapt templates» | «synthesis from sources» |
| Реалистичная оценка | 15h | 20h baseline (18-24h range) |

Итого: ×1.3 множитель к baseline из-за gap зрелости.

## Метод

1. **Идентифицировать source-Pack** для derivative artifact.
2. **Оценить зрелость** по чеклисту:
   - Онтология присутствует? (полная / частичная / заглушка)
   - Методы формализованы? (доля от плана)
   - Шаблоны/формы готовы? (да / частично / нет)
3. **Сравнить с прецедентом**:
   - Source-материалы той же зрелости? → применить прецедент 1:1.
   - Source-материалы ниже зрелостью? → множитель ×1.3-2.0 в зависимости от gap.
4. **Записать решение** в WP-context: «оценка 20h (15h baseline + ×1.3 за gap зрелости Pack)».

## Применимость

- Оценка любых derivative artifacts: руководства, доклады, курсы, документация из кода.
- Любая ситуация переиспользования прецедента-времени между задачами.

## Тест применения

«Source-материалы той же зрелости, что в прецеденте?» Нет → оценку умножить.

## Анти-паттерн

«Прошлое руководство заняло 15h, это тоже 15h» — без проверки зрелости source-Pack. Приводит к систематической недооценке (выявлено WP-250 17 мая 2026).
