# DP.METHOD.232 — попарное сравнение intra-batch перед проверкой по индексу

## Суть метода

Перед стандартной проверкой каждого accept-кандидата против существующего Pack-индекса выполняется дополнительный шаг: попарное сравнение кандидатов ОДНОГО ТИПА внутри текущего батча/отчёта между собой. Найденные внутрибатчевые дубли обрабатываются (reject одного / merge) до того, как оба будут записаны как отдельные Pack-сущности.

## Обоснование

Стандартная проверка на дубли сравнивает кандидата с уже существующей базой Pack — на момент этой проверки соседи из ТЕКУЩЕГО отчёта ещё не проиндексированы (они пишутся в Pack только по итогу решения). Без отдельного intra-batch прохода два дублирующих друг друга кандидата одного батча оба благополучно проходят проверку против индекса (оба новые для индекса) и оба записываются как отдельные сущности.

## Применение

Шаг 4г (валидация) любого разбора пакета кандидатов на пополнение Pack, где более одного кандидата одного типа обрабатываются в одном проходе.
