# Предпочтение MD-формата для плотного LLM-контекста (DP.M.032)

## Суть метода

При передаче структурированного контекста в LLM-промпт использовать **Markdown** вместо HTML.

**Данные (WP-5 Ф-13 A/B тест, 2026-05-12):**
- MD: ~1719 токенов
- HTML (с тегами): ~2170 токенов
- Разница: **451 токен (26%)** при **идентичной точности** распознавания Haiku

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Экономия токенов (26%, измерено на структурированном тексте/заголовках/списках) ↔ область применимости результата | Вывод сформулирован как общая рекомендация «использовать MD», но Ограничения явно сужают его: измерение сделано только на Haiku, только вне таблиц, только для структурированного контекста агента — применение результата шире, чем область, где он измерен |
| Краткость алгоритма («структурированный текст → MD, ✅ измерено») ↔ полнота неисследованных случаев | Таблицы (шаг 2), XML-обёртка/llms.txt/lost-in-middle (шаг 3) явно отложены в backlog Ф-14 WP-5, но короткая формулировка метода создаёт соблазн распространить вывод «MD компактнее» и на эти неисследованные случаи |

## Алгоритм применения

1. **Структурированный текст, заголовки, списки** → MD (✅ измерено)
2. **Таблицы** → исследовать HTML отдельно (Ф-14 WP-5, backlog)
3. **XML-обёртка, llms.txt, lost-in-middle тест** → backlog Ф-14

## Ограничения

- Измерение выполнено на Haiku; на Opus/Sonnet эффект может отличаться
- Таблицы исключены из A/B теста
- Применимо к структурированному контексту агента, не к диалоговому промпту

## Bias-Annotation

_Куда систематически съезжает внимание практикующего._

| Bias | Direction of distortion |
|------|--------------------------|
| Обобщение с Haiku на все модели | Внимание съезжает с точной формулировки результата («на Haiku, при идентичной точности») на обобщённое «MD лучше HTML для LLM» — при применении метода к Opus/Sonnet-промптам оговорка Ограничений «на Opus/Sonnet эффект может отличаться» недооценивается, и цифра 26% переносится без переизмерения |
| Таблицы форматируются как обычный текст без проверки | Таблицы систематически выпадают из внимания при применении метода («исследовать HTML отдельно», шаг 2) — практикующий по умолчанию форматирует таблицы в MD так же, как остальной текст, не проверяя, сохраняется ли для табличных данных то же соотношение токенов/точности, измеренное только для не-табличного контента |
