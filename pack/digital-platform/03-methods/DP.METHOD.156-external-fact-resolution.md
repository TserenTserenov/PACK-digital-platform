# DP.METHOD.156: Разрешение спора через единственный внешний факт

## Назначение

Метод экономии ходов peer-сессии: когда два варианта решения детерминируются единственной переменной, недоступной агентам, внутренний «спор» не несёт информации — нужно остановиться и вынести один точечный вопрос.

## Триггер применения

Агент замечает: «мы спорим о A vs B, но выбор зависит от факта X, который ни я, ни напарник не можем установить изнутри контекста».

## Метод

1. **Идентифицировать детерминирующий факт:** единственная внешняя переменная, значение которой однозначно выбирает ветку.
2. **Прекратить внутренний спор:** дальнейшее обсуждение без этого факта = перетягивание, не анализ.
3. **Оформить обе ветки:** каждая ветка — готовый исполняемый план «если факт X → делаем A, иначе → делаем B».
4. **Вынести один вопрос:** точечный вопрос носителю факта (пилоту) с двумя готовыми ветками.

## Почему работает

Без этого метода агенты продолжают «аргументировать» в пользу своей ветки, маскируя недостающий вход под содержательное разногласие. Один вопрос с готовыми ветками снимает ambiguity за один ход вместо N.

## Пример

WP-437: развилка «стартовать 16 июля vs сдвинуть дату» — выглядела как спор о готовности системы. При анализе свелась к одному факту: «обещана ли дата 16 июля кому-то снаружи?». Ни один агент не может это установить. Обе ветки оформлены, вынесен один вопрос пилоту.

## Ограничения

- Применимо только когда спор действительно сводится к одному факту (не к нескольким независимым).
- Если факт вообще недоступен (пилот тоже не знает) — метод не применим; нужна другая стратегия (сценарный анализ, принятие худшего случая).
