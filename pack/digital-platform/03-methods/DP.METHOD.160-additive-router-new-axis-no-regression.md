# DP.METHOD.160: Аддитивный маршрутизатор новой оси без регрессии

## Назначение

Добавить новую ось маршрутизации в систему с существующей осью без изменения поведения для пользователей, не попадающих под новую ось.

## Алгоритм

1. Ставить новую проверку **первой** в цепочке:

   ```
   if new_axis_condition → новый путь
   (fall-through) → старое поведение без изменений
   ```

2. При `null` или несоответствии по новой оси — автоматический fall-through.
3. Не использовать feature-flags и backward-compat патчи.

## Тест корректности

«Если у пользователя нет данных по новой оси (null) — поведение идентично pre-patch?»
- Да → аддитивно (safe to deploy).
- Нет → требует backward-compat слоя.

## Пример применения

Добавление оси `qual_level` (степень квалификации L0-L8) в систему с существующей осью `stage_raw` (учебная ступень 1-5):

```
if qual_level >= L2 → квалификационный путь (новое)
# fall-through: учебный путь (Шаги 2/2a/2b) — без изменений
```

При `qual_level = null` → только учебный путь, идентично pre-patch.

## Применимость

Системы маршрутизации с добавлением оси прогресса/квалификации, где существующие пользовательские сценарии не должны меняться.
