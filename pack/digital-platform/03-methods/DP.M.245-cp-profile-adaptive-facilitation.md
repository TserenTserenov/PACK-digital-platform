# DP.M.245 — CP-Profile Adaptive Facilitation

## Суть

При проектировании LLM-агента сопровождения (Pack Creator, курс, менторство) глубина взаимодействия калибруется по `cp.iwe`-срезу профиля пользователя.

## Трёхуровневая модель

| Уровень | Условие | Режим агента |
|---------|---------|-------------|
| Assembly | `cp.iwe ≤ 2` | Агент предлагает готовые шаблоны из соседних Pack'ов; пользователь выбирает из чеклиста |
| Hybrid | `cp.iwe = 3` | Агент предлагает + пользователь адаптирует под домен |
| Full SPF | `cp.iwe ≥ 4` | Пользователь оригинирует distinction'ы; агент review'ит форму |

## Default при отсутствии профиля

Режим Assembly + CTA: «Пройдите диагностику для точной калибровки» (DP.ROLE.042 — R28 Диагност).

## Принцип

Агент не устанавливает глубину произвольно — она зависит от измеренного профиля. Без профиля — наименее опасный уровень (assembly: агент делает больше, пользователь выбирает из готового).

## Применимость

Любой facilitation-паттерн с неоднородной аудиторией: Pack Creator (R30), курсы, менторство, код-ревью, онбординг.
