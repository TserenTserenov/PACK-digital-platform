# DP.METHOD.250 — snapshot fallback с age-gate для деградированного режима

## Суть метода

Пайплайн, зависящий от живого источника данных (`fetch_stage()`), при сбое live-запроса переключается на локально сохранённый еженедельный снимок — но только если возраст снимка не превышает явный порог (например, 14 дней). Provenance результата честно фиксирует, что данные пришли из кэша снимка (`stage_source: "snapshot_cache"`), а не маскируется под живой результат.

## Обоснование

Fallback без age-gate рискует незаметно выдавать многомесячной давности данные за актуальные при длительном сбое источника. Явная маркировка provenance позволяет потребителям результата принимать информированное решение — доверять ли деградированному ответу для их конкретного случая использования.

## Применение

Дизайн любого пайплайна с деградированным режимом работы при недоступности основного источника данных.
