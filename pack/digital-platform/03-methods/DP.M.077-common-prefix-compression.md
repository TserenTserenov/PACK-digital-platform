# DP.M.077: Common-prefix compression в output путей и циклов

## Определение

Метод форматирования вывода линтеров/анализаторов, эмитящих путь/цикл по графу: вычислить общий префикс всех узлов в пути, вынести в конец как metadata, показать только различающиеся хвосты узлов. Компактно, без потери информации.

## Проблема

Наивный вывод полного пути с FQ-именами быстро становится нечитаемым:

```
PD.GUIDE.1.S1.SS2 → PD.GUIDE.1.S1.SS3 → PD.GUIDE.1.S1.SS2
```

Глаз ищет различающиеся части, тонущие в повторах.

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Компактность вывода (только различающиеся хвосты, `SS2 → SS3 → SS2`) ↔ сохранение контекста | Сжатие даёт выигрыш в читаемости только если суффикс `(length=N, scope=<prefix>)` реально прикладывается (шаг 3); без него компактность превращается в потерю информации о том, к какому дереву относится путь |
| Общность алгоритма (единый common-prefix reduce для любого графа) ↔ применимость только при повторяющемся префиксе | Тест применимости («повторяет ли путь общий префикс?») ограничивает метод намеренно — для коротких/одноуровневых путей reduce не даёт выигрыша, а лишь добавляет шаг обработки без пользы |

## Триггер применимости

> «Выводит ли инструмент путь длиной ≥2 узлов с FQN-именами, повторяющими общий префикс?»

- **Да** → common-prefix compression.
- **Нет** (короткие имена или одноуровневые) → не нужно.

## Алгоритм

1. **Reduce common prefix** через все path-nodes.
2. **Display tails-only** как путь (`SS2 → SS3 → SS2`).
3. **Append suffix** `(length=N, scope=<prefix>)` с metadata: длина пути и общий контекст.

## Пример

**До:** `PD.GUIDE.1.S1.SS2 → PD.GUIDE.1.S1.SS3 → PD.GUIDE.1.S1.SS2`
**После:** `SS2 → SS3 → SS2 (length 2, in PD.GUIDE.1.S1)`

## Bias-Annotation

_Куда систематически съезжает внимание практикующего._

| Bias | Direction of distortion |
|------|--------------------------|
| Реализация останавливается на самом reduce | Внимание концентрируется на шаге 1 (вычислить и убрать общий префикс) и недооценивает шаг 3 (append suffix с length/scope) — укороченный вывод технически работает, но без metadata-хвоста теряет именно ту информацию, ради сохранения которой затевалась компрессия |
| Компрессия применяется без проверки теста | При добавлении в новый output-путь внимание тянется к тому, чтобы «сделать как везде», и не доходит до проверки триггера применимости — компрессия ставится «заодно» даже там, где имена короткие или одноуровневые, где она не нужна и усложняет форматтер |

## Применимость

- Cycle-detection output (graph-algorithms).
- Import-cycle errors (Python, JS module bundlers).
- Ontology-prerequisites circles.
- Dependency-resolver output (yarn, pip, cargo).
- Любой tool, который пишет path/cycle с длинными FQN-именами.
