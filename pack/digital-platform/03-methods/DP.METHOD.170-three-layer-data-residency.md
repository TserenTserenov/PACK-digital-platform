# DP.METHOD.170 — Трёхслойная модель сбора персональных данных (privacy-first)

## Описание

Паттерн разделения ответственности при сборе персональных данных для privacy-first систем. Три слоя:

- **Слой 1 (пользователь)**: сторонние данные (здоровье, активность) — пользователь экспортирует самостоятельно (Apple Health, iCloud). Платформа не хранит и не запрашивает.
- **Слой 2 (рецепты платформы)**: платформа предоставляет скрипты/инструкции для регулярного self-export, снижая трение без централизации.
- **Слой 3 (данные платформы)**: собственные данные платформы (прогресс, статусы, конкурсы) доставляются напрямую в IWE.

## Принцип

Разграничить «данные, за которые отвечает пользователь» и «данные, за которые отвечает платформа». Платформа не централизует данные из внешних источников — только предоставляет инструмент (рецепт) для самостоятельного экспорта.

## Применение

Privacy-first системы, где централизованный сбор политически нежелателен: медицинские данные, активность, финансы. Критерий применимости: «хотим ли мы быть custodian этих данных?» Нет → Слой 1 + 2. Да → Слой 3.
