# DP.M.392 Встраивать паттерн из каталога в текст без называния кода

## Определение

При написании контента продуктивный мем (карточка P-NNN из SA.CAT.001) встраивается как демонстрация метода мышления в действии — текст показывает мысль, соответствующую паттерну, но не называет код мема (P-NNN) и не ссылается на каталог явно.

## Причина

Называние внутреннего кода каталога в пользовательском тексте — служебный шум для читателя (см. правило «без служебных меток» в разговорном стиле IWE): читатель видит мышление, а не таксономию автора.

## Правило

Контент для внешнего читателя, использующий паттерн из внутреннего каталога → показывать паттерн через демонстрацию, не через код/ссылку на каталог.
