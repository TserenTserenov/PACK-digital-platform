# DP.M.159 — Скилл как единственная исполняемая точка входа

## Суть

Фраза-триггер на человеческом языке активирует `.claude/skills/<name>/SKILL.md`, а не ad-hoc-файл инструкций в произвольном месте репо. Скилл = единственная входная точка для workflow; хранится в стандартном пути.

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Стандартность пути ↔ свобода размещения инструкций | Один путь `.claude/skills/<name>/SKILL.md` делает скилл автоматически обнаружимым в любом канале, но запрещает «положить инструкцию рядом с кодом» — метод удерживает единство точки входа через запрет альтернатив (старый ad-hoc файл → удалить или DEPRECATED с redirect) |
| Удобство автора (ad-hoc файл где привычно) ↔ работоспособность триггера в новом канале | Инструкция в корне репо или docs/ пишется без ограничений, но claude.ai/code browser её не находит; привязка фразы-триггера к стандартному контракту в AGENTS.md/CLAUDE.md делает workflow канал-независимым (headless, бот — без модификации SKILL.md) |

## Bias-Annotation

_Куда систематически съезжает внимание практикующего._

| Bias | Direction of distortion |
|------|--------------------------|
| Полнота шагов workflow затмевает минимальность публичного контракта | Внимание практика — на исчерпываемости шагов внутри SKILL.md, а не на тесте его сигнатуры: достаточно ли одной триггерной фразы и имени, чтобы агент из холодного контекста понял, что именно вызвать; контракт скилла как точки входа остаётся непроверенным |
| Проверка скилла в родном канале вместо чужого | Практик вызывает триггер в той же среде, где писал скилл, и объявляет работу проверенной — сценарий вызова из другого канала (бот, headless, браузер) не прогоняется, потому что внимание замкнуто на ближайшем окружении |

## Failure mode

Инструкции workflow лежат в произвольном файле (корень репо, docs/, inbox/) — claude.ai/code browser не обнаруживает скилл автоматически. Триггерная фраза не привязана к стандартному контракту → workflow не работает в новых каналах без ручного обновления.

## IPO

| | |
|---|---|
| **Вход** | Фраза-триггер на человеческом языке («начни peer-сессию», «запусти workflow X») |
| **Процесс** | Агент находит `.claude/skills/<name>/SKILL.md` → следует шагам контракта |
| **Выход** | Workflow выполнен по стандартному контракту; SKILL.md = source-of-truth |

## Правило оформления

1. **Один стандартный путь:** `.claude/skills/<name>/SKILL.md` (не корень репо, не docs/).
2. **Фраза-триггер в AGENTS.md или CLAUDE.md:** `«{фраза} → прочитай SKILL.md и следуй шагам»`.
3. **Запрет альтернатив:** старый ad-hoc файл → удалить или пометить DEPRECATED с redirect.
4. **Независимость от канала:** фраза работает в claude.ai/code, headless, боте — без модификации SKILL.md.

## Тест

«Если пользователь напишет триггерную фразу в новом контексте без истории сессии — агент найдёт и выполнит SKILL.md?» Да → правило соблюдено.
