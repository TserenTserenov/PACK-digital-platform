# Local Gateway как extension point для render-инструментов (DP.METHOD.099)

## Описание

Local Gateway — тонкий MCP-сервер, запущенный на машине пилота. Инструменты, требующие доступа к локальным файлам пилота (рендер, сборка персонального руководства), реализуются как MCP-инструменты в Local Gateway, а не как cloud-операции.

## IPO

**Вход:**
- Запрос на операцию над локальными данными (рендер, transform, сборка)
- Параметры операции (дата, путь к файлу)

**Действие:**
1. Claude Code вызывает MCP-инструмент через соединение с Local Gateway
2. Local Gateway выполняет операцию на машине пилота (с доступом к локальным файлам)
3. Возвращает результат (статус, путь к артефакту)

**Выход:**
- Результат операции без передачи данных в cloud

## Инварианты

**Каждое расширение = отдельный Service Clause.** Один инструмент = одно обещание (DP.SC.NNN).

**Суверенитет:** Данные не уходят на сторонний сервис. Алгоритм единый (в cloud), исполнение с данными — на машине владельца.

## Ограничения

- Local Gateway онлайн только при работающей машине пилота
- Delivery через daily snapshot, не real-time (offline fallback required)

## Применение

- render_personal_guide (DP.SC.187) — первый пример
- Любой render/transform/assemble над персональными данными пилота
