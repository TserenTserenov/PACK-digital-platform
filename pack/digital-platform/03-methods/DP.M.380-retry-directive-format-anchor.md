# DP.M.380 — Retry-директива с форматным якорем

**Суть:** Директива ретрая LLM-вызова обязана содержать три компонента: (1) что исправить, (2) в каком точно формате, (3) перечислить все структурно значимые элементы по именам. Без (2) и (3) модель исправляет смысл, но выбирает собственный формат.

## Паттерн

```
# Антипаттерн: только «что»
retry_prompt = f"Блок '{missing_block}' отсутствует. Добавь его. Сохрани формат."
# → модель добавит блок, но может изменить структуру соседних элементов

# Fix: «что» + «как именно» + «перечисление элементов»
retry_prompt = f"""
Блок '{missing_block}' отсутствует в секции.

Требуемый формат секции:
**Лейбл 1.** Текст
**Лейбл 2.** Текст
**{missing_block}.** [добавить здесь]
**Лейбл 4.** Текст

Все остальные лейблы оставить без изменений: {', '.join(existing_labels)}.
"""
```

## Когда применять

При любом LLM retry по причине:
- отсутствующий блок / секция
- неверная структура (H2 вместо bold-label, список вместо параграфа)
- нарушение форматного инварианта

## Тест

«Административная сессия без контентных правок — шаг запускается?» — не применимо.
«Ретрай добавил нужный блок, но сломал соседние?» → форматный якорь отсутствовал.

## Инцидент

WP-149 (`render-pilot-guides.py`, commit d863951): retry-директива «блок X отсутствует, добавь»
без списка существующих лейблов → модель конвертировала 6 `**bold-label**` в 6 отдельных H2,
провалив чеклист по всем 6 строкам вместо исходных 2.
