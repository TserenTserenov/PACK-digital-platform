# DP.M.290 — Explicit next-step numbering

## Диагностический маркер проблемы

Пользователь получает «Завтра продолжим — урок придёт в запланированное время». Неясно: когда конкретно? Сколько шагов впереди? Каков темп?

## Метод

**В переходных сообщениях многодневных программ называть конкретный следующий шаг с номером.**

- Вместо «до завтра» → «День N+1 начнётся завтра утром»
- Вместо «скоро продолжим» → «Осталось X дней из Y»

## Тест применимости

«Может ли пользователь после сообщения назвать конкретный следующий шаг и примерное время?» Нет → сообщение нуждается в явном номере/времени.

## Исключения

- Финальный день: отдельный текст без «День 15», так как число дней у разных программ разное
- Сценарии с гибким темпом (самостоятельный выбор даты) — вместо числа указывать условие

## Область применения

Любые многодневные программы с фиксированным темпом: марафоны, курсы, онбординг, challenges.

## Антипаттерн

Абстрактные «скоро», «завтра», «в ближайшее время» без конкретики — оставляют ожидание неопределённым.
