# DP.M.436 — Барьер безопасности в точке правки, не только в точке коммита

## Определение

Для общего файла, поломка которого немедленно (до коммита) отражается на всех потребителях — safety-проверка обязана стоять в точке правки (post-edit self-test), а не только в точке коммита. Pre-commit защищает от другого класса риска (публикация сломанного), не от эксплуатации сломанного до публикации.

## Проблема

Файл живёт в незакоммиченном рабочем дереве без синка между параллельными сессиями; правка одного агента становится боевой для ВСЕХ сессий машины за секунды, а до коммита проходят десятки минут. Существующая pre-commit проверка (`bash -n`) физически не может поймать этот класс — она стоит слишком поздно относительно момента, когда ущерб уже нанесён. Замер вечера 06.09 перевёл этот класс из счёта инцидентов в цену простоя: два окна за вечер (34 мин/8 сессий, 68 мин/11 сессий), худшее окно класса — 111 мин/7 сессий.

## IPO-паттерн

| Элемент | Описание |
|---------|----------|
| Входы | Общий файл с несколькими параллельными писателями за день; правка этого файла |
| Обработка | Self-test сразу после сохранения правки (не дожидаясь коммита) — та же проверка, что pre-commit, но триггер — сама правка |
| Выходы | Немедленный сигнал автору правки при поломке — до того, как поломка успела задеть параллельные сессии |

## Тест применимости

«Если этот файл сломается прямо сейчас, до коммита — пострадает кто-то ДРУГОЙ раньше, чем автор закоммитит фикс?» Да → нужен post-edit barrier. Нет (только сам автор пострадает до коммита) → pre-commit/CI достаточно.

## Отличие от смежного

- **DP.METHOD.182 (commit-time hook как shift-left):** аргументирует commit-time точку лучше фонового демона; этот метод идёт ещё левее — для класса «ущерб до коммита» даже commit-time уже поздно.
- **DP.M.088 (CI + pre-commit defense-in-depth):** оба барьера этого метода стоят не раньше коммита; этот метод описывает эмпирически найденный случай (два окна простоя за вечер), где defense-in-depth из DP.M.088 не покрывает risk window между правкой и коммитом.
