# DP.METHOD.234 — charset-gate как барьер качества публикации

## Суть метода

Конвейер публикации для внешней (не платформенной) аудитории включает жёсткий барьер на уровне набора символов: контент, содержащий символы вне допустимого набора для целевого канала (например, кириллицу там, где ожидается только латиница), отклоняется целиком, а не публикуется с артефактами смешения алфавитов.

## Обоснование

Простой, механический charset-барьер ловит целый класс ошибок (случайное смешение языков, копипаст с посторонним алфавитом) значительно надёжнее, чем содержательный review — символьная проверка детерминирована и не требует интерпретации.

## Применение

Конвейер публикации контента во внешние каналы/аудитории с чётко определённым ожидаемым набором символов.
