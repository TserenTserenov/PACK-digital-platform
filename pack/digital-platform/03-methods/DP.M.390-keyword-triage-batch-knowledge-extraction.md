# DP.M.390 Keyword-триаж как масштабируемый batch-метод Knowledge Extraction

## Определение

Разбор большого индекса знаний (сотни файлов, сотни кандидатов) на предмет знания для извлечения ведётся не построчным чтением, а keyword-триажем: массив файлов сканируется по ключевым словам/паттернам, кандидаты собираются batch'ем, затем разбираются пачками (batch 1, 2, 3…), а не по одному.

## Отличие от DP.METHOD.195

`DP.METHOD.195` — про то, ЧТО является триггером регистрации в Pack (apply-captures session как момент регистрации). `DP.M.390` — про то, КАК масштабируемо находить кандидатов ДО этой регистрации, когда исходный массив велик (пример: 411/411 файлов Индекса знаний, ~315 кандидатов; 388 мемов из WP-465). Разные шаги одного конвейера, не дубли.

## Правило

Knowledge Extraction над большим корпусом (сотни+ файлов) → keyword-триаж batch'ами, не последовательное построчное чтение каждого файла.
