# DP.M.186 — Тест 15-секундного обещания onboarding

## Описание

Тестовая эвристика для оценки любой механики вознаграждения / онбординга / лендинга: показывает ли UI понятное действие→результат за ≤15 секунд просмотра? Применима к loyalty-программам, gamification, обучающим программам, mass-market продуктам.

## Контекст применения

Точка приложения — первичный UI новичка (50% воронки — Случайные пользователи). Решение «продолжать или уйти» принимается за секунды; сложные правила (effort^0.6, rarity_mult, EMA-скользящие) не парсятся до решения.

## Алгоритм

1. **Зафиксировать цель новичка** в одной фразе («получить скидку», «бесплатный кофе», «следующий уровень»).
2. **Открыть первичный экран** (главная, dashboard, лендинг) — без скролла, без подсказок.
3. **Замерить 15 секунд**: видит ли пользователь конкретное действие→результат?
4. **Тест на формулу**: если на экране формула / EMA / коэффициенты — fail (формулы живут в backend / Reference Appendix, не в первичном UI).
5. **Pass-критерий**: фиксированное обещание формата «N действий → X ₽/баллов/звёзд».

## Прецеденты

- **Starbucks Rewards** (звёзды → бесплатный кофе) — pass.
- **Habitica** — fail из-за сложности правил; проиграла mass-market.
- **WP-327 v4.3** — формулы спрятаны в backend, UI показывает «Выполни 5 занятий → получи 50 ₽».

## Связи

- Дополнение к DP.M.110-declarative-nudge-markers (видимость пути).
- Применимо в связке с DP.D.104 «Прогресс к награде ≠ баланс» (что показывать в UI).

## Ограничения

- Применим к mass-market продуктам (≥30% новичков в воронке). Для expert-tools применимость ниже — там пользователи готовы к сложности.
- Не отменяет необходимость detail-уровня в Reference Appendix для опытных пользователей.
