# DP.M.186 — Тест 15-секундного обещания onboarding

## Описание

Тестовая эвристика для оценки любой механики вознаграждения / онбординга / лендинга: показывает ли UI понятное действие→результат за ≤15 секунд просмотра? Применима к loyalty-программам, gamification, обучающим программам, mass-market продуктам.

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Мгновенная понятность новичку ↔ полнота правил программы | Решение «продолжать или уйти» принимается за секунды, и сложные правила (effort^0.6, rarity_mult, EMA-скользящие) не парсятся до него; метод требует фиксированное обещание «N действий → X ₽/баллов/звёзд» на первичном экране, вынося формулы в backend и Reference Appendix ценой двухслойной документации |
| Простота pass-критерия ↔ честность обещания | Одна строка «N → X» проверяется за 15 секунд, но упрощение для UI не должно искажать реальную экономику программы — обещание, которое проходит тест, но врёт о ценности, разрушает то, ради чего тест применялся |

## Контекст применения

Точка приложения — первичный UI новичка (50% воронки — Случайные пользователи). Решение «продолжать или уйти» принимается за секунды; сложные правила (effort^0.6, rarity_mult, EMA-скользящие) не парсятся до решения.

## Алгоритм

1. **Зафиксировать цель новичка** в одной фразе («получить скидку», «бесплатный кофе», «следующий уровень»).
2. **Открыть первичный экран** (главная, dashboard, лендинг) — без скролла, без подсказок.
3. **Замерить 15 секунд**: видит ли пользователь конкретное действие→результат?
4. **Тест на формулу**: если на экране формула / EMA / коэффициенты — fail (формулы живут в backend / Reference Appendix, не в первичном UI).
5. **Pass-критерий**: фиксированное обещание формата «N действий → X ₽/баллов/звёзд».

## Прецеденты

- **Starbucks Rewards** (звёзды → бесплатный кофе) — pass.
- **Habitica** — fail из-за сложности правил; проиграла mass-market.
- **WP-327 v4.3** — формулы спрятаны в backend, UI показывает «Выполни 5 занятий → получи 50 ₽».

## Bias-Annotation

_Куда систематически съезжает внимание практикующего._

| Bias | Direction of distortion |
|------|--------------------------|
| Первичный экран затмевает detail-уровень | Добившись pass на главном экране, практик распространяет 15-секундную простоту на весь продукт и забывает Reference Appendix для опытных пользователей — тест, задуманный как фильтр первого экрана, становится стандартом для всех |
| Замер экрана затмевает фиксацию цели новичка | Тест начинают с просмотра того, что уже нарисовано (шаги 2–3), пропуская шаг 1 — цель новичка в одной фразе; измеряется понятность UI самого по себе, а не соответствие обещания реальной цели («бесплатный кофе», «следующий уровень») |
