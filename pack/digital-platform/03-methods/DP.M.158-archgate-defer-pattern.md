# DP.M.158 — ArchGate Defer-Pattern: управление ⚠️ через defer-map

## Принцип

ArchGate conjunctive screening по ЭМОГССБ: PASS если ни одна критическая характеристика не ❌. Предупреждения (⚠️) не блокируют — фиксируются в defer-map с явным target.

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Движение вперёд (⚠️ не блокируют PASS) ↔ полнота разбора предупреждений | Conjunctive screening пропускает РП дальше при нуле ❌, но каждое ⚠️ обязано получить явный target (`phase=Ф5` или `wp=WP-NNN`) — метод удерживает темп ценой обязательной записи каждого defer в defer-map |
| Простота бинарного вердикта (blocker = 0 → PASS) ↔ различимость срочности предупреждений | Одна строка «PASS» не различает «исправим здесь» и «требует отдельного РП» — метод делит defer на internal/external, удерживая однозначность вердикта без потери разницы между ⚠️О (строка в distinctions.md при Ф5) и ⚠️С (вынос в WP-225) |

## Два типа defer при ⚠️

| Тип | Описание | Пример |
|-----|---------|--------|
| **defer-internal** | Исправляется в текущем РП | ⚠️О: Owner Role External → строка distinctions.md при Ф5 |
| **defer-external** | Выносится в отдельный РП | ⚠️С: BC Map VR → WP-225 |

## Алгоритм

1. Прогнать ArchGate → профиль ЭМОГССБ
2. Для каждой ⚠️ определить тип: internal или external
3. Для каждого defer указать явный target (`phase=Ф5` или `wp=WP-NNN`)
4. Commit message: `archgate(WP-N): Ф1 ПРОХОДИТ + разблокированные артефакты`

## Условие PASS

Для всех критических характеристик: не ❌ → blocker = 0 → PASS (с defer-map для всех ⚠️)

## Bias-Annotation

_Куда систематически съезжает внимание практикующего._

| Bias | Direction of distortion |
|------|--------------------------|
| Фиксация defer затмевает его закрытие | Внимание уходит на аккуратную запись ⚠️ в defer-map с явным target, а возврат к отложенному пункту при наступлении Ф5/WP-NNN остаётся вне поля зрения — defer-map растёт как журнал, но не сокращается как очередь |
| Ноль блокеров читается как чистый профиль | Внимание фиксируется на blocker = 0 → PASS, и накопленный хвост ⚠️ перестаёт восприниматься как часть состояния РП — прогон выглядит «зелёным», хотя defer-map полон |
