# Промоция скрипта из авторского IWE в платформенный шаблон (L3→L1)

## 1. Определение

Метод перевода shell-скрипта из авторского IWE (source layer, L3) в FMT-exocortex-template (platform layer, L1) с сохранением корректности у всех существующих пользователей шаблона.

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Строгость триггера промоции (§2: ≥2 недели без правок + универсальность + параметризуемость) ↔ скорость доставки полезного скрипта пилотам | Трёхкритериальный фильтр защищает FMT от преждевременной/нестабильной промоции, но откладывает попадание уже полезного скрипта в шаблон на недели |
| Полнота smoke-test (§3 шаг 5: ровно 3 обязательных кейса) ↔ стоимость каждой промоции | Фиксированный набор (пустой ключ / несуществующий путь / штатный запуск) даёт воспроизводимую проверку независимо от сложности скрипта, но для тривиальных скриптов выглядит избыточным по сравнению с их размером |
| Проверка коллизий до копирования (§3 шаг 1, блокирующий) ↔ скорость самого процесса промоции | Обязательный `check-script-collisions.sh` первым шагом тормозит промоцию, но без него шаг 4 (копирование) может тихо перезаписать или сломать поведение у существующих пилотов |

## 2. Триггер промоции

Скрипт промотируется при одновременном соответствии критериям:
- ≥2 недели в авторском IWE без правок
- Универсальная ценность (применим без авторских констант)
- Параметризуем через params.yaml

**НЕ промотируются:** личные репо-пути, одноразовые скрипты, авторские константы без параметризации.

## 3. Процесс (7 шагов)

1. **Проверить коллизии:** запустить `check-script-collisions.sh`. Скрипт с таким же именем уже есть в FMT → разобрать: merge или rename. Без этого шага промоция ломает поведение у пилотов.
2. **Параметризовать авторские константы:** заменить hard-coded пути/имена через `WORKSPACE_DIR` / `params.yaml`.
3. **Добавить параметр в FMT/params.yaml:** документировать ключ, дефолт, описание.
4. **Скопировать скрипт в FMT.**
5. **Smoke-test в 3 кейсах:** (a) пустой ключ params.yaml → graceful skip; (b) несуществующий путь → warning + exit 1; (c) штатный запуск → ожидаемый результат.
6. **Обновить CHANGELOG + update-manifest.json.**
7. **Коммит:** `feat: promote <script-name> from author IWE`.

## 4. Инварианты

- Коллизии проверяются **до** копирования (шаг 1 = блокирующий).
- Smoke-test покрывает ровно 3 кейса — не меньше.
- §9 CLAUDE.md FMT не должен содержать identity-константы автора (связь: L3-leak, DP.FM.019).
