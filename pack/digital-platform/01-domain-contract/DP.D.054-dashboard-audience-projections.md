# DP.D.054: Несколько аудиторий дашборда ≠ отдельные источники данных

**Различение:** Аудитория дашборда — не «личное vs публичное» (два отдельных источника данных),
а три проекции одного Data Contract.

| Аудитория | Проекция | Уровень детализации |
|-----------|----------|---------------------|
| **Пользователь** | Полный доступ к своим данным | Полный, включая PII |
| **Команды** | Агрегаты без PII | Средний, без персональных идентификаторов |
| **Сообщество** | Публичные метрики платформы | Агрегированный, анонимный |

**Антипаттерн:** три endpoint'а с тремя разными источниками данных.
**Правило:** один источник (Data Contract) → три view/scope с per-audience фильтрацией на уровне API.

## Тест

«У меня три разных базы для трёх аудиторий?» → Да → антипаттерн.
Правильно: один снапшот → per-audience scope-фильтрация, не per-audience сбор данных.

## Применение

- Проектирование API для personal dashboards с multi-tenant analytics
- Личный дашборд IWE (WP-302): один Neon-снапшот → три scope
- Любая платформа с несколькими типами потребителей данных
