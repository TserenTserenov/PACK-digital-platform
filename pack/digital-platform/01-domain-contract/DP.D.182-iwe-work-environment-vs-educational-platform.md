# DP.D.182 IWE как рабочая среда ≠ образовательная платформа

| Аспект | Рабочая среда (IWE) | Образовательная платформа |
|--------|---------------------|--------------------------|
| **Основная задача** | Работа человека с агентом: планирование, создание, рефлексия | Передача знаний: курсы, уроки, тесты |
| **Центральный объект** | Работающий созидатель с агентом-партнёром | Учащийся, потребляющий образовательный контент |
| **Форма продукта** | Экзоскелет (контекст + память + рефлексия) | Программа (модули + прогресс + сертификат) |
| **Показатель успеха** | Артефакты, стратегия, кем стал пользователь | Уровень завершённости курса, балл теста |

## Инвариант

IWE не преподаёт — оно оснащает. Пользователь IWE работает в среде, а не проходит курс.

## Применение

При позиционировании для новой аудитории (WP-451, WP-406): первая линия коммуникации — «среда для работы», не «платформа обучения». Используется для разграничения с конкурентами образовательного сектора.

## Тест

«Если убрать весь контент курсов — останется ли ценность IWE?» Да → IWE = рабочая среда. Нет → образовательная платформа.
