# DP.D.213 — Категориальный policy-факт ≠ Семантика пути чужого домена

| Категориальный policy-факт | Контекстное правило (семантика пути) |
|---------------------------|--------------------------------------|
| Универсальный флаг: «заглуши категорию X» | Предметное условие: «при фазе X слать траекторный, но не engagement» |
| Потребитель читает плоский флаг | Потребитель интерпретирует семантику пути источника |
| Не нарушает bounded context | Протаскивает доменную семантику source в engine |
| Допускает асинхронный приём | Требует синхронного знания о состоянии источника |

**Инвариант:** Сигнал от вышестоящей роли должен быть категориальным флагом, переносимым без знания домена источника. Как только сигнал становится контекстным правилом — движок-потребитель вынужден интерпретировать семантику чужого bounded context → coupling leak.

**Тест:** «Вынуждает ли сигнал потребителя интерпретировать семантику предметной области источника?» Да → утечка связности; нормализовать в категориальный флаг или вынести в отдельный governor.

**Источник:** WP-117 Ф-integration ArchGate, peer-session 2026-06-21, report.md §2 Т1. Связано: «Gateway с одной ответственностью ≠ Gateway с прикладной логикой», «суть ≠ интерфейс».
