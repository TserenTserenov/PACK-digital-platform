# DP.D.204: Карта методов (слой рычагов) ≠ Новая ось состояний FSM

Каталог методов изменения состояния объекта — это **слой рычагов внутри существующей оси**, а не новое измерение модели состояний.

| Карта методов / рычагов | Ось состояний FSM |
|------------------------|-------------------|
| Описывает: ЧЕРЕЗ ЧТО двигать объект по оси | Описывает: КЕМ/ЧЕМ объект является сейчас |
| Примеры: список техник, инструментов, интервенций | Примеры: «Компетентность», «Включённость», «Забота» |
| Может быть несколько карт для одной оси | Каждая ось — независимое измерение состояния |
| Добавление карты не меняет размерность FSM | Новая ось увеличивает пространство состояний |

**Тест:** «Это состояние объекта или инструмент воздействия на состояние?»
- Состояние → кандидат в ось
- Инструмент/метод → слой рычагов внутри существующей оси, не новая ось

**Контрмера против инфляции осей:** при появлении новой структурированной карты знаний проверять тест выше (и общий тест ортогональности DP.D.065), прежде чем объявлять её новым измерением модели.

**Родственное различение:** «Состояние объекта ≠ Стадия процесса» (2026-05-22) — тот же принцип, другой срез (стадии vs оси). DP.D.065 даёт общий тест ортогональности осей, из которого этот тест — частный случай для пары «карта методов / ось состояний».

**Прецедент:** WP-245 + WP-457. Карта 14 механизмов срыва навыка рассматривалась как кандидат в 7-ю ось состояний пользователя; зафиксирована как слой рычагов внутри оси «Компетентность».
