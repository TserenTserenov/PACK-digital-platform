# DP.D.055 — Домен vs Тема

## Различение

**Тема** = область интереса. Нет собственных методов, рабочих продуктов и failure modes. Можно «интересоваться» темой, не имея профессиональных практик.

**Домен** = практика. Есть профессионалы, которые это делают. Они производят конкретные артефакты и имеют типовые ошибки.

## Тест

> «Есть ли люди, которые ДЕЛАЮТ это профессионально? Что они производят?»

- Если ответ «интересуюсь X» → тема, не домен.
- Если называются практики + артефакты + failure modes → домен, готов к Pack.

## Примеры

| Формулировка | Классификация | Комментарий |
|-------------|---------------|-------------|
| «машинное обучение» | Тема | Нет собственных артефактов вне ML-инженерии |
| «разработка ML-систем» | Домен | Инженеры ML: модели, пайплайны, мониторинг |
| «интересуюсь стратегией» | Тема | «Стратег» — это уже домен |
| «стратегическое планирование» | Домен | Стратеги: WP-реестры, планы недели, ретро |

## Применение

- При Pack-онбординге: первый вопрос «это домен или тема?»
- При оценке зрелости области знания для формализации
- Связан с методом DP.M.016 (3 вопроса диагностики зрелости)
