# DP.D.184 Пустая витрина ≠ отсутствие данных в источнике

| Аспект | Пустая витрина (derived layer) | Нет данных в источнике (source layer) |
|--------|-------------------------------|--------------------------------------|
| **Причина** | Материализатор не написан / сломан / не запущен | Данные действительно не собирались |
| **Слой** | indicator_history, materialized view, производная таблица | domain_event, raw log, source DB |
| **Сигнал** | Производные запросы возвращают 0 | Поток событий пуст |
| **Действие** | Починить материализатор | Починить агент сбора / признать отсутствие |

## Инвариант

Пустая витрина — сигнал о сломанном или ненаписанном слое материализации, не о реальном отсутствии данных. Source-of-truth = поток событий (domain_event), а не витрина.

## Применение

При аудите measurement pipeline: вывод «нет данных» считается валидным только после проверки source layer (поток событий, raw DB), а не только витрины. Первый шаг диагностики — `SELECT COUNT(*) FROM domain_event`, не из материализованной таблицы.

## Тест

«Пустая витрина — в каком слое проверили?»
- Только derived (materialized view, indicator_history) → обязательно проверить source layer до вывода
- Source layer тоже пуст → вывод «нет данных» валиден
