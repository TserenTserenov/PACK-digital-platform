# [DP.SC.156] Обнаружение возможностей уровня (Что ещё?)

## Инвариант (platform-level)

> **Инверсия модели (WP-415, 2026-06-14).** Платформа предоставляет список возможностей текущего тира через API/MCP-инструмент `get_tier_capabilities(user_id) → list[capability]`. Любой клиент-канал реализует UX этих возможностей по-своему: inline-кнопки в Telegram, меню в браузере, команды в IDE. Правила ниже — пример реализации для Telegram-бота (одна канальная проекция), а не часть платформенного обещания.

## Правило (Telegram-проекция)

- [ ] Кнопка «💡 Что ещё?» присутствует на tier-экране /setup для T1, T2, T3, T4
- [ ] Список команд строго соответствует уровню пользователя (tier-aware): команды T2+ не показываются T1
- [ ] Экран «Что ещё?» содержит кнопку «← Назад» возвращающую к основному tier-экрану
- [ ] Каждое открытие экрана «Что ещё?» фиксируется событием `event_type='what_else_opened'` с тиром в `domain_event`
- [ ] Целевой CTR кнопки ≥ 5% от уникальных пользователей /setup за первые 7 дней после деплоя

## Обещание

**Кому:** Пользователь на уровне T1–T4 (R16 Ученик)

**Зачем:** Пользователи не знают все команды своего уровня — главный tier-экран показывает только 2 основных действия. «Что ещё?» открывает остальные возможности без поиска в /help.

**Что получит по уровням:**

| Уровень | Доступные команды в «Что ещё?» |
|---------|-------------------------------|
| T1 «Старт» | /support (поддержка), /points (баллы), /remind (ежедневное напоминание) |
| T2 «Изучение» | /knowledge (поиск по знаниям), /progress (история уроков), /rp (рабочие продукты) |
| T3 «Персонализация» | /twin (цифровой двойник), /me (статистика недели), /navigator (Навигатор) |
| T4 «Созидание» | /plan (план дня), /knowledge_post (публикация постов), /week_close (закрытие недели) |

**Критерий приёмки:** T1-пользователь нажимает «💡 Что ещё?» → видит 3 команды своего уровня → нажимает «← Назад» → возвращается на T1 tier-экран. Событие `what_else_opened` записано в domain_event.

## Режим отказа

- **domain_event недоступен** → показать экран без записи события (fail-open, не блокировать UX)
- **Неизвестный тир** → не показывать кнопку «💡 Что ещё?» (скрыть, не ломать)
- **T0** → кнопка не показывается (T0 не видит tier-экран)

## Свидетельства

- `test_what_else_button_appears_and_back`: кнопка есть на T1-T4, кнопка «Назад» возвращает на tier-экран
- `test_what_else_tier_aware`: T1 видит только T1-команды, не видит T2+ команды
- `test_what_else_event_logged`: открытие «Что ещё?» → запись в domain_event с tier
- Метрика через Metabase: CTR = count(what_else_opened) / count(setup_viewed) за 7 дней
