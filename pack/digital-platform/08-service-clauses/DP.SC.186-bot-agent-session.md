# DP.SC.186 «Агентная сессия IWE через бота»

> Паритет с VS Code: полноценная агентная сессия IWE (скиллы, MCP, файловые операции, commit) через Telegram, с выбором исполнителя (Claude Code / Kimi CLI / Hermes) и работой на подписках пользователя.

## Обещание

Пользователь T4 может из Telegram запустить **полноценную агентную сессию IWE** — настоящий рантайм-агент (Claude Code, Kimi или Hermes) на своём раннере, который читает/пишет файлы, запускает скиллы, вызывает MCP-инструменты, делает commit — и получить артефакты + отчёт обратно в Telegram. Личность IWE одинакова независимо от выбранного исполнителя (тянется из источника, [[суть ≠ интерфейс]]).

## Триггеры

- `/agent <текст>` — открыть агентную сессию исполнителем по умолчанию (или продолжить активную ходом).
- `/agent <executor> <текст>` — явный выбор исполнителя: `claude` | `kimi` | `hermes`.
- `/close` — финализировать сессию (отчёт + ссылка).

## Входы

- `telegram_id` → Ory-идентификация через UnifiedBotRouter (adr-unified-bot-router-v2).
- `executor` — выбор рантайма (по умолчанию из настройки пользователя).
- `text` — запрос/ход.
- (опц.) вложение — файл/документ на вход (Rich I/O, Ф8).

## Выбор исполнителя (executor-selection)

> Контракт `Executor` — в `adr-unified-bot-router-v2`. Роутер не знает рантайм-специфики; реализации регистрируются через factory.

| Исполнитель | Класс | Тип | Аутентификация / стоимость | Где |
|---|---|---|---|---|
| `claude` | `ClaudeCodeExecutor` | агентный | **подписка пользователя** (Claude Code OAuth, Max/Pro) → без оплаты за токены | раннер пользователя |
| `kimi` | `KimiCliExecutor` | агентный | **подписка пользователя** (Kimi CLI login) | раннер пользователя |
| `hermes` | `HermesAgentExecutor` | агентный (внедряется) | рантайм Hermes (Nous Research), который IWE берёт в работу | раннер / платформа |

**Приоритет MVP:** `claude` и `kimi` — оба используют подписки пользователя и уже присутствуют на его машине (немедленно). `hermes` — внедряемый рантайм (Nous Research), подключается как третий исполнитель (после Claude/Kimi, требует adoption + wiring). Платформенный ключ — fallback, не основной путь.

## Тир-разветвление

| Тир | Доступ к агентной сессии |
|-----|--------------------------|
| T4 (пилот) | полный агент, все домены своего пространства, выбор любого исполнителя |
| T3-scoped (команда развития, WP-431) | агент только на определённые репо/домены + approve-before-commit обязателен |
| T1-T2 | агентная сессия НЕ доступна → только разговорный контур (DP.SC.183) |

## Безопасность и приватность (ИНВАРИАНТЫ)

> Полный разбор: Security Gate B7.3 — `DS-my-strategy/inbox/WP-428/security-gate-b73.md`.

1. **Telegram = только транспорт.** Контекст/состояние сессии не хранятся в Telegram и не кэшируются в нём.
2. **Audit-trail (ОБЯЗАТЕЛЕН, не откладывается).** Каждое действие агента от имени пользователя (файл прочитан/изменён, commit, вызванный скилл/инструмент) фиксируется в журнале. Без журнала сессия не считается корректной.
3. **Approve-before-commit.** Опционально для пилота на своём раннере (аналог «Accept» в VS Code — пилот контролирует свою среду). **Обязателен** для T3-scoped (команда).
4. **Credentials.** Подписочные токены/OAuth-credentials исполнителей — секреты: шифрование at-rest, никогда не логировать, отзыв по запросу. Живут на раннере пользователя (BYO), не в боте.
5. **Domain-scoping.** T3-scoped получает не «всё», а юрисдикционно/доменно изолированный срез ([[Парламент-модель ≠ Президент-модель]]). Для T4-пилота — всё своё пространство.

## SLA и lifecycle

Агентная сессия — `heavy`/async по [[DP.SC.162]]: lifecycle `start → run → pause → resume → close` (FSM `external_session`, WP-358).

| Параметр | Значение |
|----------|----------|
| Прогресс | heartbeat «⏳ Работаю... Nс» по `learning.domain_event` |
| Soft-timeout хода | 15 мин |
| Idle-timeout сессии | 30 мин → auto-close |
| Mid-session control | стоп / уточнение / отмена из Telegram → раннер (Ф6) |

## Fallback

| Ситуация | Поведение |
|----------|-----------|
| Раннер недоступен | «Твой раннер сейчас не на связи. Запусти его или используй разговорный режим.» |
| Исполнитель не выбран и нет дефолта | предложить выбор `claude`/`kimi`/`hermes` |
| Подписка/credentials не подключены | CTA на подключение подписки на раннере |
| Скилл/инструмент упал | сообщить ошибку, сессию не рушить (audit фиксирует) |

## Свидетельства результата

- `bot.agent_session.turn` domain event (без тела: executor, tier, latency, action_count).
- Артефакты в целевом репо (commit SHA в audit-журнале).
- Отчёт сессии (`report.md` / ссылка) в Telegram при `/close`.
