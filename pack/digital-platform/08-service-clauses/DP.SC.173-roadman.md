# DP.SC.173 — Дорожник: отслеживание промежуточных польз P1–P9

> **Одной фразой:** Дорожник следит за тем, что человек реально получил от платформы — от первого полезного ответа ИИ (P1) до собственной среды развития (P9) — и предлагает следующий шаг в нужный момент.
>
> Дорожник — субсервис Онбордера (DP.SC.170). Запускается после `onboarding_complete = true` и не работает до завершения X2/X3.

---

## §1. Обещание (что получает человек)

Дорожник наблюдает за P-прогрессией после того, как Онбордер (DP.SC.170) зафиксировал Первокурсника. Девять польз — маяки, по которым система видит, что человек не просто числится участником, но реально использует платформу.

| Польза | Описание | Условие предложения |
|--------|----------|---------------------|
| P1 | Первый полезный ответ ИИ | `message_count >= 3 AND session_active_sec > 90` |
| P2 | Пробный урок | Первый марафон / семинар / практикум |
| P3 | Первый завершённый марафон | ≥ 3 активных марафон-дня |
| P4 | Профиль заполнен | **Закрывается в X3 Онбордером — Дорожник не предлагает** |
| P5 | Первая победа (результат работы) | Активная неделя + follow-up |
| P6 | Траектория выбрана | **Закрывается в X3 Онбордером — Дорожник не предлагает** |
| P7 | Подключён к клубу | Только при `onboarding_complete = true` |
| P8 | Цифровой двойник активен | Только при `onboarding_complete = true` |
| P9 | Своя среда развития | Только при `onboarding_complete = true` |

Полная матрица прокси, уверенности и валидационных планов — `DP.VM.001` (09-value-milestones/calibration-matrix.md).

---

## §2. Инварианты (поведенческие, обязательные)

1. **P7–P9 только после `onboarding_complete`:** Дорожник не предлагает «клуб», «цифровой двойник», «свою среду» до завершения X2/X3. Исключений нет.

2. **P4 и P6 не предлагаются:** фиксируются Онбордером при закрытии X3 (`has_p4 = true`, `has_p6 = true`). Дорожник читает их как уже закрытые.

3. **Один активный оффер на (user, польза):** гарантируется partial unique index в `user_milestone_offers` — не прикладным кодом.

4. **Параметризованный порог эскалации:** при `escalate_after_declines` последовательных отказах от одной пользы — передача управления Навигатору (R27). Значение по умолчанию: 2. Порог одинаков для всех польз как начальная калибровка; пересматривается по данным retention.

---

## §3. Триггер

- Онбордер закрыл X2 и X3 → событие `OnboardingCompleted` → Дорожник начинает мониторинг.
- Любое обновление `development.user_milestones` → пересчёт следующей незакрытой пользы.
- Ежедневный pull-опрос (24 часа) для пользователей с `onboarding_complete = true` и незакрытым прогрессом.
- R46 Контролёр развития читает `onboarding_spot_check_due` из `development.user_state` — `WHERE onboarding_spot_check_due < NOW()` — и сигнализирует Дорожнику.

---

## §4. Входы

| Поле | Тип | Источник |
|------|-----|----------|
| `user_id` | BIGINT | `users.telegram_id` |
| `user_milestones` | object | `development.user_milestones` (has_p1..has_p9) |
| `onboarding_complete` | boolean | `development.user_state.onboarding_context->>'onboarding_complete'` |
| `active_offers` | list | `user_milestone_offers WHERE response IS NULL OR response = 'ignored'` |
| `decline_history` | list | `user_milestone_offers WHERE response = 'declined'` |
| `escalate_after_declines` | int | конфиг, default: 2 |

---

## §5. Выходы

| Продукт | Описание |
|---------|----------|
| `milestone_offer` | Запись в `user_milestone_offers` — предложение пользы P{n}: тип, канал, текст |
| `milestone_closed` | Обновление `user_milestones.has_p{n} = true` при подтверждении |
| `escalation_signal` | Domain event → Навигатор (R27) при `count(declined) >= escalate_after_declines` |

---

## §6. Время отклика

| Этап | SLA |
|------|-----|
| Реакция на событие `OnboardingCompleted` / обновление milestones | ≤ 1 час (async) |
| Ежедневный pull-опрос | 24 часа (batch) |
| Ответ на прямой запрос «что мне дальше» | Мгновенно (в рамках сессии) |

---

## §7. Режим отказа

- **P1 proxy false positives:** `message_count >= 3 AND session_active_sec > 90` может переоценивать. Валидация: retention через 7 дней для первых 50 пользователей. Если когорта `has_p1=true` удерживается хуже `has_p1=false` — прокси перевёрнут.
- **Навигатор недоступен:** сохранить сигнал эскалации в очередь, повторить через 1 час. Не блокировать работу Дорожника.
- **Нарушение unique index:** БД бросает ошибку на уровне INSERT — Дорожник логирует и пропускает дублирующийся оффер.
