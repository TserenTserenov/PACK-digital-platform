# [DP.SC.181] Гард ID-коллизий в Pack-репо (pre-commit)

> # see DP.SC.181 (WP-388 Ф14, peer-сессия 2026-06-14-25, ArchGate вариант A)

Закрывает корень: параллельные агенты в одной рабочей папке независимо сканируют `max+1` и берут один номер (инцидент DP.SC.178: WP-384 и WP-390 в 12 минутах). Существующий `pack-lint.sh` уже умел `exit 1` на коллизии, но pre-commit-обёртка вызывала его до `set -e` — exit-код проглатывался (детектор работал как warning).

## Правило (инвариант)

- **Delta-aware.** Проверяются ТОЛЬКО staged-added entity-файлы (`git diff --cached --diff-filter=A`). Невинная правка существующего файла и уникальный новый ID проходят. Не блокирует commit за пред-существующий дубль в дереве (это не вина текущего коммита) — иначе ловушка глушит невинных.
- **Точное сравнение ID, без glob-границ.** `DP.SC.180` ≠ `DP.SC.1800`. Ключ — `PREFIX.TYPE.N` целиком, тип учитывается (`DP.SC.178` ≠ `DP.ROLE.178`).
- **Сканирует рабочее дерево** (`find`, не git-index), поэтому ловит незакоммиченный файл второго агента до push.
- **Не обходится молча.** При коллизии — exit 1, коммит падает; `--no-verify` запрещён правилами агента (AR.*). Это блок гарда, а не сбой.
- **Fail-open при отсутствии.** Скрипт-гард не найден (свежий клон без symlink) → обёртка пропускает; CI `check-pack-collisions.sh` остаётся бэкстопом.

## Обещание

**Кому:** агенту, создающему новую сущность Pack (DP.SC/DP.ROLE/DP.D/…) в любом Pack-репо.

**Зачем:** без гарда коллизия всплывает только в CI после push — красит проверку для всех и разбирается вручную.

- **Триггер:** `git commit` в Pack-репо, среди staged-added есть файл с именем `^[A-Z]+\.[A-Z]+\.[0-9]+`.
- **Входы:** staged-added entity-файлы + текущее состояние Pack-дерева.
- **Выходы:** при коллизии — список конфликтующих путей + следующий свободный номер для префикса; иначе тихий проход.
- **Время отклика:** < 1 с (grep по нескольким сотням файлов).
- **Режим отказа:** гард не найден → skip (бэкстоп CI); `git` недоступен → exit 0 (не блокирует).

## Реализация

- `SPF/scripts/check-id-collision-delta.sh` — детектор.
- `SPF/scripts/pre-commit-pack-map` — вызов с уважением exit-кода (dual-path resolution).
- `SPF/scripts/test-id-collision-delta.sh` + `test-precommit-integration.sh` — closed-loop тесты (6 unit + 2 интеграционных).
- Контракт уникальности: `SPF.SPEC.001-entity-coding.md §Code properties`.
