# DP.SC.191 — Обещание ёмкости должно быть разложено по типам активности

## Обещание

Провайдер не должен заявлять пользователю единую цифру ёмкости («15 минут в неделю»), если нагрузка состоит из ортогональных типов (ритуал + спекуляция + decision-gate + trigger-session).

## Выходы

- Раскладка по типам с честной оценкой каждого
- Или явное заявление об одном типе (исключая остальные)

## Инцидент

WP-149 (2026-07-10): Обещание контура саморазвития заявляло «15 минут еженедельно», но включало:
- 5 мин обязательная ревью
- 15 мин спекуляция (не гарантировано)
- 2ч decision (если завис)
- Отдельная сессия по триггеру (несколько дней)

Напарник обнаружил противоречие, писатель переформулировал с раскладкой.

## Fix

1. Перечислить все типы нагрузки
2. Для каждого: честная оценка или заявление «не поддерживается»
3. Итоговое обещание: либо сумма, либо таблица
