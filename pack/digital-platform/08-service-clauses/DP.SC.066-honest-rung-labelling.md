## Правило (инвариант)

> Что ВСЕГДА должно выполняться для данного сервиса. Нарушение = провал SC.

- [ ] Утверждение о развитии, попадающее к потребителю, несёт **рунг** (1 ассоциация / 2 интервенция / 3 контрфактик) и **основание** (`evidence_basis`). Утверждение без рунга — не выпускается.
- [ ] **Интервенционная формулировка** («сделай X — получишь Y») допустима только при данных рунга 2: парные замеры до/после и учтённые смешанные факторы. Нет таких данных → формулировка переписывается в ассоциативную («X у отслеженных связан с Y»).
- [ ] **Отсутствие ответа пилота о смешанных факторах ≠ «факторов не было».** Пропущенный вопрос не записывается как пустой список — иначе доказательная база подделывается молчанием.
- [ ] **Ярлык рунга едет вместе с числом при любом цитировании.** Корреляция (например, r=0.866 из WP-353) цитируется как рунг 1, а не как «метод работает».
- [ ] Сузилась доказательная база (упало покрытие, отвалился сбор данных) → рунг **понижается**, а не сохраняется по инерции.
- [ ] **Утверждение по когорте выпускается только при N ≥ 10** отслеженных людей в группе (по аналогии с k-anonymity, B7.3.1 §3.5). Меньше десяти → утверждение переписывается как индивидуальный кейс без обобщения или не выпускается вовсе — иначе честная разметка сама становится каналом деанонимизации.

## Обещание

**Кому:** R27 Портной (рекомендации), R1 Стратег (Strategy Session), R42 Диагност (гипотезы для проверки), R46 Контролёр развития (пороги вмешательства)

**Зачем:** платформа уже вживую даёт рекомендации пилотам. Без явного рунга рекомендация звучит как обещание результата, хотя за ней стоит наблюдение на десятке человек — это то самое «каузальное мошенничество» (rung collapse, FPF C.28), которое обесценивает и рекомендацию, и программу.

**Что получит:** по каждому ключевому утверждению программы — запись триажа: рунг, основание, «что утверждать можно», «что утверждать нельзя», следующий ход до перехода на рунг выше.

**Триггер:** (а) Week Close — пакетное обновление; (б) запрос на триаж нового утверждения перед его выпуском потребителю.

**Время отклика:** пакет — раз в неделю при Week Close; разовый триаж утверждения — в рамках сессии.

**Режим отказа:** данных нет → выдаётся рунг 0/1 с явным `unsupported_use`, а не молчание и не «пока считаем, что работает».
