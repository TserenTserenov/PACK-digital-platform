# DP.SC.062 «Публикация курируемого манифеста в исследовательский репозиторий iwesys»

## Правило (инвариант)

- [ ] **И1 (explicit manifest only).** Публикуется ТОЛЬКО явно перечисленный список файлов (манифест), никогда весь исходный каталог/репозиторий. Источник каждого файла манифеста указан по абсолютному пути в конфигурации workflow — не директория, не glob по умолчанию.
- [ ] **И2 (no cross-repo leakage).** `target_repo` захардкожен внутри workflow-файла (не внешний параметр вызова), с явным assert перед push, что фактическая цель равна ожидаемому репозиторию. Ошибка конфигурации вызова не может перенаправить публикацию в другой репозиторий.
- [ ] **И3 (boевой конвейер неприкосновенен).** Существующий `translate-sync.yml` (DP.SC.188, `FMT-exocortex-template` → `iwesys/IWE`) не изменяется этим SC ни строкой — новый режим живёт в отдельном файле.
- [ ] **И4 (Cyrillic gate inherited).** Публикуемый результат проходит тот же безусловный Cyrillic-гейт, что и режим "перевод" (DP.SC.188) — ни кириллицы в содержимом, ни в именах файлов, ни в identity коммита.

## Обещание

**Кому:** автору источника (владельцу рабочего РП, сейчас — WP-493 Лаборатория характеристик; ожидаемый следующий потребитель — WP-495 после его Ф8, финальная концепция).

**Зачем:** курируемый публичный репозиторий (например `iwesys/growth-traits-lab`) должен получать актуальные версии своих публикуемых материалов автоматически при правке источника, не вручную копироваться при каждом изменении (текущее состояние на 20.07.2026 — ручная разовая заводка 19.07, без канала обновления).

**Что получит:** при push в источник, затрагивающем файл манифеста, изменение копируется (без перевода — манифест уже на английском) в целевой репозиторий тем же паттерном атрибуции и Cyrillic-защиты, что и боевой конвейер DP.SC.188 — без ручного шага.

**Триггер:** push в ветку источника, затрагивающий путь, входящий в явный манифест данного вызова.

**Время отклика:** один прогон CI (минуты), тот же порядок величины, что DP.SC.188.

**Режим отказа:** файл источника отсутствует манифесте → не публикуется (не ошибка, штатное игнорирование). Manifest-файл содержит внутренние ссылки (Ф-номера, РП-пути, приватные пути Pack) → это ответственность автора источника поддерживать курируемую/зачищенную версию манифеста, SC не делает автоматическую зачистку содержимого (в отличие от структурных гейтов И1-И4).
