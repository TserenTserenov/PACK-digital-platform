# DP.SC.173 — Дорожник (Pathfinder)

## Обещание

> Дорожник предлагает пользователю следующую «пользу» (из P1-P9) в момент,
> когда предыдущая зафиксирована. Цель: провести пользователя от первого
> полезного ответа (P1) до собственной среды развития (P9) без разрыва мотивации.

## Триггер

- Обновление строки в `user_milestones` (любой `has_P{n}` меняется FALSE → TRUE).
- Периодический опрос (раз в 24 часа) для пользователей с неполным профилем польз.

## Входы

| Поле | Тип | Описание |
|------|-----|---------|
| `user_id` | UUID | Идентификатор пользователя |
| `user_milestones` | row | Текущее состояние has_p1..has_p9 |
| `onboarding_complete` | bool | Флаг завершения Онбордера (Х3 закрыт) |

## Выходы

| Поле | Тип | Описание |
|------|-----|---------|
| `offer` | row \| null | Запись в `user_milestone_offers` (user_id, milestone_p, offered_at) |
| `offer_channel` | enum | `telegram` \| `bot_ui` \| `none` (если нет следующей P) |

## Инварианты (поведенческие)

1. **Pre/post onboarding:** P7-P9 предлагаются **только** при `onboarding_complete = true`.
   P1-P6 могут предлагаться до завершения онбординга, если `has_P{n} = false` и польза
   не перекрывается текущим процессом Онбордера (P4 и P6 Онбордер закрывает сам через Х3).

2. **Единственный активный оффер:** одновременно может быть максимум один активный оффер
   на одну пользу (обеспечено partial unique index в `user_milestone_offers`).

3. **Эскалация при повторных отказах:** если пользователь отказался `escalate_after_declines`
   раз подряд от одной пользы — Дорожник передаёт управление Навигатору (MIM.R.007).
   Значение параметра по умолчанию: 2. Настраивается через конфигурацию Дорожника.

4. **Идемпотентность:** повторный вызов с теми же входами не создаёт дублирующих офферов.

## Режим отказа

- `user_milestones` недоступна → пропустить предложение, залогировать `offer_channel: none`.
- `onboarding_complete` неизвестен → трактовать как `false` (не предлагать P7-P9).
