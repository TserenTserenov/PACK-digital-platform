# [DP.SC.172] База инженерного стиля кода

## Правило (инвариант)
- [x] Один источник истины L0 в PACK-digital-platform (`02-domain-entities/engineering-code-style-base.md`), три слоя L0/L1/L2.
- [x] Перед написанием кода правила P0-P5 загружены в контекст агента (хук инжекции PreToolUse + якорь UserPromptSubmit).
- [x] Каждое правило сводимо к паре «было/стало»; не сводимое — не в L0.
- [x] Граница с PACK-agent-rules (AR.*) соблюдена: блокирующие запреты — там, craft-слой — здесь.

## Обещание
- **Кому:** R01 Пилот как ревьюер; будущие сопровождающие кода; агенты-исполнители.
- **Зачем:** код агента читается профессионалом как профессиональный, а не «писала машина».
- **Что получит:** единый craft-стандарт от всех агентов (Claude/Kimi/Hermes) + авторские надстройки L1 + пользовательские L2.
- **Триггер:** агент собирается писать/править код (первый code-touch сессии / Edit-Write по code-файлу).
- **Время отклика:** немедленно (загружено в контекст до генерации кода).
- **Режим отказа:** агент работает по последней загруженной версии; drift детектируется страховочным скриптом `code-style-hook.sh` и (v2) review-агентом.

## Свидетельства (4 компонента семиозиса)
- **Данные:** L0-файл в Pack, L1-файл автора, три хука в settings.json, детектор-скрипт, аггрегатор.
- **Контекст:** агент пишет код (детектор контекста — «есть будущий читатель?»), хук сработал перед Edit/Write.
- **Полномочия:** автор платформы (L0), пилот (L1), детектор-скрипт + review-агент v2 (нарушения).
- **Свидетельства:** лог детектора `~/.claude/logs/style-violations.log` (правила P1/P2/P4), отчёт review-агента (v2), аудит diff на Week/Month Close.

## Сценарии использования (≥3)
1. **Claude пишет новый сервис** — хук впрыскивает P0-P5; агент не плодит абстракции, гоняет тесты с реальными assert, запускает линтер репо (P0).
2. **Kimi правит существующий модуль headless** — без доступа к pre-commit hook P0 заставляет запустить форматтер вручную; детектор-скрипт ловит `except: pass`.
3. **Пилот ревьюит PR агента** — видит код без знакомых запахов; расхождения с базой = быстрый review-комментарий со ссылкой на P-номер.
