# DP.SC.169 — Проводник (онбординг-помощник, T0/T1)

## Обещание

Инструмент `conductor_lite` отвечает на вопросы пользователей T0/T1 о пути подключения к платформе (T1→T4). Пользователь пишет «Гермес, ...» — получает ответ от Проводника с ограниченным scope: только онбординг, тиры, следующий шаг. Доступен без подписки.

## Триггер

Пользователь с tier < T3 отправляет сообщение с префиксом «Гермес» или «hermes» (см. `handlers/hermes.py`).

## Сценарии использования

**С1 — T1-пользователь не знает что делать дальше:**
Пишет «Гермес, что мне делать дальше?» → Проводник объясняет путь T1→T2 (подписка) и первый шаг (/setup).

**С2 — T1-пользователь спрашивает о функциях:**
«Гермес, что даёт подписка?» → Проводник перечисляет возможности T2 (личная база знаний, браузерная среда).

**С3 — T2-пользователь хочет следующий уровень:**
«Гермес, как подключить базу знаний?» → Проводник объясняет шаги T2→T3 (/personal-guide-start, /connect).

## Входы

| Поле | Тип | Описание |
|------|-----|----------|
| `message` | string | Текст вопроса пользователя (после удаления префикса «Гермес») |
| `tier_num` | int | Текущий тир пользователя (0/1/2, подставляется автоматически) |

## Выходы

Текстовый ответ на русском языке, ≤500 токенов, фокус исключительно на онбординге.

Формат в боте: `Проводник: <ответ>`

## Время отклика

SLA p95: ≤ 5s (Haiku, ~500 токенов).

## Модель

`claude-haiku-4-5-20251001` (CLAUDE_MODEL_HAIKU). Причина: T0/T1 бесплатный тир — минимальные LLM COGS.

## Инвариант (scope-ограничение)

Проводник отвечает ТОЛЬКО на вопросы об онбординге:
- Что такое тиры T0→T4 и как перейти
- Какие команды/функции доступны на текущем тире
- Как начать марафон, диагностику, подключить аккаунт

При вопросах вне scope: «Я помогаю с подключением к платформе. Для других вопросов открой Гермеса после подписки T3 (/setup → подписка)».

## Режим отказа

- API error → bot показывает «Проводник временно недоступен. Напиши /setup — там весь путь.»
- Timeout → то же сообщение

## Граница с DP.SC.167

`DP.SC.167` (hermes_chat): tier ≥ T3, полный Hermes-рантайм, без scope-ограничений.
`DP.SC.169` (conductor_lite): tier < T3, Haiku, только онбординг.

Оба доступны через один prefix «Гермес» в боте — routing по тиру.
