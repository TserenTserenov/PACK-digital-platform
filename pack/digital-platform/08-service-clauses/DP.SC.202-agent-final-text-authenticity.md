# DP.SC.202 «Достоверность финального текста агента»

## Обещание

Текст, показанный в окне чата, и текст, который агент на самом деле написал, — не одно и то же. Пилот и агенты могут положиться на то, что у любого отчёта есть **проверяемая копия из журнала сессии**, и что расхождение между показанной и записанной копией обнаруживается механически, а не по случайной внимательности читателя.

Обещание закрывает молчаливый класс порчи: показанный текст выглядит целым, читается связно, но в нём отсутствуют куски — имена файлов, репозиториев, идентификаторы коммитов. Без сверки такая порча неотличима от правды.

## Триггеры

- Пилот вставляет агенту отчёт, скопированный из окна чата другого агента.
- Агент собирается использовать путь к файлу, имя репозитория или идентификатор коммита, полученные не из своего собственного действия, а из чужого текста.
- Разбор уже случившегося эпизода: есть подозрение, что показанный текст неполон.

## Входы

- Журнал сессии агента-автора на диске (для Кими — `wire.jsonl` в каталоге сессии).
- Опционально: копия текста, полученная через окно чата, — для сверки.

## Pipeline (детерминированный)

```
1. Найти журнал нужной сессии (последняя по времени либо названная явно)
2. Убедиться, что последний ход завершён (в журнале есть маркер конца хода)
   → не завершён: отказ с явным сообщением, никакого частичного текста
3. Взять финальный текстовый фрагмент последнего шага завершённого хода
4. Режим «выдача»: отдать этот текст
   Режим «сверка»: сопоставить с предъявленной копией, показать пропавшие куски с окружением
5. Любое нарушение измеренных инвариантов формата → предупредить, не молчать
```

## Инвариант

**Инвариант 1.** Неполный или незавершённый результат никогда не выдаётся как готовый: нет маркера конца хода — есть отказ, а не огрызок текста.

**Инвариант 2.** Ничего не выбрасывается молча. Неизвестный тип фрагмента с непустым содержимым, нарушение ожидаемой структуры журнала, нераспознанная строка потока — всё это порождает предупреждение. Тишина означает «расхождений нет», и это должно быть правдой.

**Инвариант 3.** Журнал на диске — единственный источник истины для этого обещания. Копия из окна чата никогда не считается авторитетной, даже когда она единственная доступная.

## Время отклика

Чтение журнала одной сессии — доли секунды; обещание не предполагает ожидания и не ходит в сеть.

## Режим отказа

- Журнал сессии не найден → явный отказ с указанием, где искали.
- Последний ход не завершён (агент ещё пишет либо ждёт разрешения) → явный отказ с указанием причины.
- Структура журнала не соответствует ожидаемой (обновился вендор) → предупреждение с описанием того, что именно разошлось; текст при этом выдаётся, если его удалось собрать, но помечается как ненадёжный.

## Ограничение области

Обещание сформулировано для Кими в окне чата расширения VS Code — единственного случая, где порча наблюдалась и измерена (05.09.2026, WP-524 Ф6: 8 пропавших фрагментов из отчёта в 3220 байт). На другие интерфейсы и других вендоров оно не распространяется без отдельного измерения: структура журналов у них другая.

## Известные ограничения

Инварианты формата журнала измерены на 40 журналах одной версии расширения (0.7.5), а не заявлены вендором как контракт. Обновление вендора может их нарушить — поэтому проверки встроены в реализацию и жалуются вслух (Инвариант 2), вместо того чтобы жить комментарием в коде.
