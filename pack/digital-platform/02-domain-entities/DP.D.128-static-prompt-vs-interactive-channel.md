# DP.D.122 — Статический промпт ≠ интерактивный канал

| Аспект | Статический промпт | Интерактивный канал |
|--------|--------------------|---------------------|
| **Носитель** | Markdown-файл / текстовая инструкция | MCP-tool / multi-turn session |
| **State между ходами** | Нет (каждый ход независим) | Есть (persistent state, session_id) |
| **Escalation-канал** | Нет (LLM решает сам или зависает) | Есть (явный маркер ESCALATE_TO_USER) |
| **Tier-калибровка** | Статическая (один уровень для всех) | Динамическая (по cp-профилю / истории) |
| **Доступ к инструментам** | Нет (digital twin, search, write недоступны) | Есть (вызов сопровождающих MCP-инструментов) |

## Категориальная ошибка

Продажа переносимого промпта как «то же самое, что наша интерактивная сессия» — рождает ложные ожидания у пользователя и регрессию метода в восприятии.

## Caveat-правило

Когда метод Pack упаковывается в одиночный markdown-промпт для чужого LLM-инструмента (ChatGPT, claude.ai вне MCP), в самом артефакте **первым блоком** обязательно фиксируется caveat «статический ≠ канал». Пользователь должен понимать, что результат хуже, чем в нативной сессии — и почему.

## Тест

«Работает ли в этом носителе tier-калибровка / digital twin / escalation?»
- Да → интерактивный канал
- Нет → статика, caveat обязателен
