# DP.D.146: Бизнес-алерт ≠ Технический алерт

| Бизнес-алерт | Технический алерт |
|--------------|------------------|
| Метрика ценности: DAU, MRR, LDAU, conversion | Здоровье инфры: error-rate, latency, exception |
| Пример: LDAU = 0 (никто не учился 24ч) | Пример: error rate +20%, P95 > 5s |
| Не покрывается стандартными APM-инструментами | Покрывается стандартными APM-инструментами |
| Нужен явный пороговый триггер с push-каналом | Нужен Sentry / PagerDuty |

**Почему важно:** Технические инструменты мониторинга не покрывают бизнес-сигналы автоматически. LDAU=0 — P0-сигнал продуктового класса, который тонет в daily-отчёте без отдельного push-уведомления.

**Тест:** «Если ключевая бизнес-метрика обнулится — узнает ли команда до утра?» Нет → нет отдельного бизнес-алерт-канала.

**Применение:** определить 1-2 ключевых бизнес-метрики и завести явные пороговые триггеры с push-каналом, независимые от технического мониторинга.
