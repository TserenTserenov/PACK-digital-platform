# DP.D.091 — Выровненные на boundary шкалы ≠ Параллельные с tandem-стыком

## Суть

Когда внутренняя шкала граничит с внешней более глубокой шкалой, есть два способа их склеить:
1. **Tandem-стык:** добавить внешнюю шкалу «впритык» к концу внутренней (внутренняя N уровней + внешняя M = N+M уровней). Анти-паттерн.
2. **Выравнивание на boundary:** последний уровень внутренней = первый уровень внешней, одна общая строка с одинаковыми коэффициентами. Правильно.

## Тест

«Есть ли на стыке коэффициент-разрыв?» Да → выровнять boundary. Нет → tandem допустим.

## Контекст применения

- IWE 5 ступеней (Случайный → Проактивный) + МИМ 8 уровней (Ученик → Магистр) → выровнено на boundary: Проактивный = Ученик МИМ (×1.00, cap=200) → 12 уровней, не 13.
- CEFR (A1–C2) + внутренние уровни языковой школы.
- EQF + квалификации компании.

## Failure mode при tandem

Коэффициент-разрыв (×1.00 на Проактивном vs ×1.20 на Ученике МИМ) ломает мотивацию на стыке: переход выглядит как «прыжок», а не следующий шаг.
