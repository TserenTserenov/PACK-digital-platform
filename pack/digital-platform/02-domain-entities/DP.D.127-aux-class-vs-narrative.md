# DP.D.127 — Aux-класс (structure-only) ≠ Нарративный класс

**Aux-класс** — файлы корпуса, не содержащие нарративного текста по природе формата: таблицы понятий, вопросы для самопроверки, упражнения. **Нарративный класс** — файлы с повествовательными абзацами, авторскими метафорами и аналогиями.

## Тест

«Есть ли нарративный абзац с повествованием?»
- Нет → Aux-класс (structure-only): применять только машинные паттерны (AR.4), тональность/аналогии не проверять.
- Да → Нарративный класс: применять полный набор правил (AR.4 + тональность + аналогии).

## Применение

При верификации смешанного корпуса (гайды + таблицы + тесты) — классифицировать каждый файл перед выбором правил проверки. Ошибка: применять правила тональности к таблице → false negative (таблица «не прошла» не потому что плохая, а потому что не подходит инструмент).
