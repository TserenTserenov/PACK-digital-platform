# DP.D.130 — Технологическая ось онбординга ≠ Содержательная ось

**Технологическая ось (оснащение T0-T4)** — какие инструменты подключены (T0 гость, T1 free, T2/T3/T4 подписки). Определяется через `get_journey_state` + `get_next_onboarding_step`.

**Содержательная ось (ступень Ученика 1-5)** — уровень мастерства из cp-профиля Диагноста (FORM.089).

**Инвариант:** прогресс по одной оси не означает прогресс по другой. Пользователь может быть на T4 (технически полностью оснащён) и на ступени 1 (случайный) содержательно.

**Тест:** «смешиваем ли мы "что подключено" с "насколько освоено"?» Да → нарушение различения.

**Применение:** при проектировании адаптивного онбординга обе оси необходимы и независимы.

**Связи:** DP.ARCH.002 (тир-архитектура), DP.SC.132 (онбординг), DP.D.125 (два ортогональных измерения).
