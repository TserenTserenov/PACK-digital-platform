# DP.D.320 — Неоднозначность формулировки ≠ конфликт с уже принятым решением

## Различение

| | Неоднозначность | Конфликт с решением |
|---|---|---|
| **Признак** | Есть ≥2 трактовки спорной фразы, и существует хотя бы одна, совместимая с реестром уже принятых решений | Реестр уже принятых решений содержит решение, которое нарушает каждая возможная трактовка фразы, независимо от того, какая выбрана |
| **Правильное действие ревьюера** | Задать автору уточняющий вопрос, выбрать среди совместимых трактовок | Уточняющий вопрос бесполезен — нужно блокировать реализацию и переформулировать предложение через уже принятый механизм |
| **Цена ошибки классификации** | Конфликт принят за неоднозначность → вопрос отправлен автору, но любой его ответ всё равно нарушит принятое решение — потерян цикл согласования | Неоднозначность принята за конфликт → реализация блокируется там, где решение было бы возможно после простого уточнения |

## Механизм

Внешнее предложение (правило отката тарифа «если подписка длиннее/короче месяца») разбиралось против 21 принятого решения карточки РП-573. Первичная классификация «неясно, что автор имел в виду — уточнить» оказалась ошибкой: обе возможные трактовки понятия «длина подписки» (время с момента перехода? остаток периода?) одинаково нарушали уже принятое правило возврата со следующего расчётного периода без пересчёта — либо делая правило зависимым от произвольного возраста подписки, либо оставляя условие технически недостижимым для обычного месячного продления. Уточнение у автора не помогло бы: какой бы ответ он ни дал, результат нарушил бы принятое решение.

## Тест различения

Перебрать все правдоподобные трактовки спорной формулировки и для каждой спросить: «нарушает ли эта трактовка какое-то уже принятое решение реестра?»
- Да для всех трактовок → конфликт. Вопрос автору бесполезен — нужна переформулировка предложения через уже принятый механизм, реализация блокируется до этого момента.
- Да не для всех (есть хотя бы одна совместимая трактовка) → неоднозначность. Уточняющий вопрос автору осмыслен.

## Границы

Различение действует только там, где есть явный реестр уже принятых решений, с которым можно сверить каждую трактовку (карточка РП с пронумерованными решениями, ADR, зафиксированный контракт). Без такого реестра классификация «неоднозначность vs конфликт» невозможна — есть только «непонятно», для которого уточняющий вопрос остаётся единственным доступным первым шагом.
