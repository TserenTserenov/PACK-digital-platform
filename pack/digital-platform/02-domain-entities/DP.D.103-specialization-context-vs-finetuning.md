# Специализация агента через контекст ≠ специализация через дообучение (DP.D.102)

> Различение двух уровней реализации специализированного агента. Связано с: «Агент ≠ Роль», «Универсальный агент ≠ Специализированный агент» (distinctions.md).

## Уровень 1: Специализация через контекст

**Что:** Универсальное LLM-ядро (Claude, Kimi, GPT-4o) + роль подаётся в контексте: промпт активации роли + фрагмент Pack + структурная роль хода.

**Где живёт доменное знание:** В Pack (файлы репозитория). Обновляется коммитом — без переобучения модели.

**Когда применять:** Новая роль, методология меняется, нет данных для fine-tuning, нужна быстрая итерация.

**Стоимость:** Только inference; длинный контекст = дороже per-запрос.

**Пример:** Kimi играет роль «ТОС-аналитик» — получает промпт роли + раздел FPF про ТОС + задачу сессии. Знает ТОС ровно настолько, насколько описано в Pack.

## Уровень 2: Специализация через дообучение (fine-tuning / RLHF)

**Что:** Доменное знание роли запечено в веса модели через fine-tuning на размеченных примерах или RLHF. В контексте нужны только: задача сессии + структурная роль хода.

**Где живёт доменное знание:** В весах модели. Обновление = переобучение.

**Когда применять:** Роль стабилизировалась (50+ сессий без изменений методологии), высокий объём запросов, нужна скорость и стоимость per-token.

**Стоимость:** Дешевле per-token при inference; дорого при смене методологии (переобучение).

**Пример:** Специализированная модель «Аудитор безопасности IWE» — обучена на 200 примерах аудита B7.4. Контекст = только описание системы. Не нужен B7.4 чеклист в промпте.

## Ключевые различия

| Аспект | Уровень 1 (контекст) | Уровень 2 (fine-tuning) |
|--------|---------------------|------------------------|
| Где знание | Pack (файлы) | Веса модели |
| Обновление | Коммит в Pack | Переобучение |
| Стоимость inference | Выше (длинный контекст) | Ниже |
| Гибкость | Высокая | Низкая |
| Фаза применения | Новая / развивающаяся роль | Стабилизированная роль |
| LLM-ядро | Заменяемо без потерь | Заменяемо, но роль теряется |

## Инвариант: не путать уровень с качеством

Уровень 2 не «лучше» уровня 1 — он подходит для другой фазы зрелости. Роль на уровне 2 с устаревшей методологией хуже роли на уровне 1 с актуальным Pack.

**Аналогия:** Сотрудник по инструкции (уровень 1) vs сотрудник с интуицией (уровень 2). Интуиция полезна только если методология не менялась. При смене процессов — «интуитивный» сотрудник опаснее, чем работающий по актуальной инструкции.

## Связь с ролями

- Специализированный агент пир-сессии (DP.ROLE.039) → начинает с уровня 1.
- Контрольные роли (Верификатор VR.R.001/002, Контролёр R46, Аудитор) — если достигают стабильности 50+ прогонов без изменений чеклиста → кандидаты на уровень 2.
- **Не применять уровень 2 к ролям с высокой изменчивостью** (стратег, архитектор, методолог) — риск «запечь» устаревший фрейм.
