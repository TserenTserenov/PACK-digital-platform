# Ретранслятор канона (DP.ROLE.081)

> **Kind:** Infrastructure Role (автоматическая, не редакторская — в отличие от R21 Публикатора)
> **Owner Role:** Автор личного шаблона IWE (`TserenTserenov` — source-of-truth)

## 1. Миссия

Переносить каждое изменение документации канона (личного шаблона IWE) в публичную английскую проекцию — без выбора, что публиковать, когда и в каком порядке. Реагирует на каждое сохранение немедленно и одинаково, не курирует поток.

## 2. Обязанности

| Обязанность | Метод | Триггер |
|------------|-------|---------|
| Перевести изменённые `README.md`/`docs/**` на английский | Дельта-перевод (`translate.py`) | Push в `main` с изменением документации |
| Проверить обязательные термины глоссария перед публикацией | Формальная + содержательная проверка (Tier-1 блокирует, Tier-2/3 предупреждает) | После перевода, перед публикацией |
| Опубликовать переведённый результат как основную ветку `iwesys/iwe-template` | Форс-пуш гейтованной ветки `en-draft` | Успешный перевод + проверка пройдена |
| Явно сигнализировать при недоступности целевого репозитория | Проверка существования репозитория перед публикацией | Целевой репозиторий не создан/недоступен |

## 3. Полномочия

- Публикует автоматически, без запроса подтверждения у автора — это часть обещания (DP.SC.188), не превышение полномочий.
- Не решает, ЧТО и КОГДА публиковать — публикует всё изменившееся сразу, каждый раз.

## 4. Границы роли

| Делает | НЕ делает |
|--------|-----------|
| Переводит изменившуюся документацию | Не переводит и не публикует код/скрипты/конфигурацию |
| Публикует немедленно при каждом push | Не строит расписание, не решает приоритет публикаций (в отличие от R21 Публикатора) |
| Сигнализирует явно при сбое/неготовности приёмника | Не адаптирует контент под аудиторию/канал (в отличие от R21 Публикатора) |
| Гейтует по глоссарию (Tier-1) | Не редактирует содержание, не принимает решений об оригинале |

## 5. Отличие от R21 Публикатора (важно — не путать)

**Публикатор (DP.ROLE.001 §R21)** — куратор: сканирует очередь готового контента, решает расписание, публикует по команде или по каденции, адаптирует текст под каждый канал (соцсети, клуб), отслеживает комментарии.

**Ретранслятор канона** — механический перенос: не выбирает, что публиковать (публикует всё изменившееся), не строит расписание (публикует немедленно при каждом push), не адаптирует под аудиторию (переводит как есть, по глоссарию). Тест на различение: «эта роль решает, ЧТО и КОГДА показать аудитории, или просто копирует изменение целиком и сразу?» Решает → Публикатор. Копирует → Ретранслятор.

## 6. Исполнители

| Исполнитель | Когда | Режим |
|-------------|-------|-------|
| GitHub Actions workflow (`translate-sync.yml`, `TserenTserenov/FMT-exocortex-template`) | Каждый push с изменением документации | Автомат, без участия человека |
| GitHub App `canon-sync` (owner = пилот) | Публикация в другую организацию (`iwesys`) | Автомат, токен per-installation |

## 7. Артефакты роли

| Вход | Выход |
|------|-------|
| Push в `main` с изменением `README.md`/`docs/**` | Ветка `en-draft` (переведённый черновик) в исходном репозитории |
| Гейтованный `en-draft` (0 непереведённых терминов высшей важности) | Основная ветка `iwesys/iwe-template` |
| Недоступный/несуществующий целевой репозиторий | Явное предупреждение в логе прогона (не тихий сбой) |

## 8. Область (не покрывает)

Эта роль обслуживает только личный шаблон IWE (`TserenTserenov/FMT-exocortex-template` → `iwesys/iwe-template`). Она НЕ обслуживает конвейер для методического контента `aisystant` (11 репозиториев: docs, guides, main-docs и т.д.) в `iwesys`/`MimEcoSys` — та работа не спроектирована и не назначена этой роли (см. `DS-my-strategy/inbox/WP-415/WP-415.md`).
