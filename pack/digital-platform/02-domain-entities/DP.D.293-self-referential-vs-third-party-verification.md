# DP.D.293 — Self-referential verification ≠ third-party verification

**Различение:** self-referential verification (оба сравниваемых значения производит и контролирует один и тот же процесс) ≠ third-party verification (хотя бы одно значение поступает из независимого источника, который проверяемый процесс не контролирует).

| Аспект | Self-referential | Third-party |
|--------|-------------------|-------------|
| Источники сравниваемых значений | Оба произведены одним и тем же процессом (например, deploy-script) | Минимум одно значение — от стороннего источника (например, ответ внешнего API) |
| Что обнаруживает расхождение, внесённое ДО обеих точек сравнения | Ничего — ошибка воспроизводится в обеих величинах одинаково | Расхождение с независимым источником |
| Формальный статус | Проверка выполняется, код отрабатывает | Проверка выполняется, код отрабатывает |
| Фактическая защита | Тавтология: значения по построению согласованы, если нет независимого сбоя | Реальная проверка независимого факта |

**Тест:** «Может ли инструмент проверки сам испортить оба значения, которые сравнивает, одной и той же ошибкой?»
- Да → self-referential: расхождение, внесённое до обеих точек сравнения, останется незамеченным.
- Нет (хотя бы одно значение вне контроля проверяющего процесса) → third-party: независимая сверка.

## Примеры (WP-7, F-VerifiedDeployHardening)

- **Railway-контур (self-referential):** deploy-script сравнивает локальный manifest и HTTP-ответ сервиса — оба значения производит один и тот же контролируемый процесс.
- **Cloudflare-контур (third-party):** сверка идёт против ответа стороннего API (`version.id`), который deploy-script не контролирует.

## Семья различений false-green

Родственно существующим различениям класса «формальный pass ≠ содержательная проверка»:
- DP.D.208 — тавтологический pass из-за равномерно пустого поля (проблема источника данных)
- DP.D.248 — `last_verified` timestamp ≠ факт проверки содержимого (проблема семантики поля)
- **Данное различение** — проблема независимости источников сравниваемых значений: третий, отдельный корень тавтологии в той же семье.
