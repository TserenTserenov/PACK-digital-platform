# DP.D.002: Модель ≠ Данные

| Модель | Данные |
|--------|--------|
| Структура | Значения |
| «Что измеряем» | «Сколько» |
| Версионируется | Накапливаются |
| Меняется редко | Меняются постоянно |

**Почему важно**: Изменение модели и изменение данных — разные операции с разными последствиями.
