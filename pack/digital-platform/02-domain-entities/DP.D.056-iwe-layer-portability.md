# DP.D.056 — IWE Слои как критерий портируемости

## Различение

Три слоя IWE имеют разную степень платформенной привязки:

| Слой | Содержимое | При смене AI-платформы |
|------|-----------|----------------------|
| **L1** (CLAUDE.md §1-7, hooks, skills) | Claude Code + macOS специфика | Нужно переписать |
| **L2** (staging) | Частично специфичен | Нужно пересмотреть |
| **L3** (extensions/, params.yaml, §9) | Платформенно-нейтральный | Переносится без изменений |

## Универсальные элементы (платформа не важна)

- ОРЗ-фрактал (Открытие → Работа → Закрытие)
- Pack/DS/Base архитектура знания
- Memory/Capture логика
- WP Gate ритуал согласования

## Тест

> «Встретил инструкцию → посмотри, в каком слое она живёт. L3 менять не нужно. L1 — нужно при смене платформы.»

## Применение

- При миграции IWE между AI-ассистентами: точно знать, что переписывать
- При оценке vendor lock-in: смотреть долю L1/L3
- При Extension Gate: новое в L3 = низкий migration cost
