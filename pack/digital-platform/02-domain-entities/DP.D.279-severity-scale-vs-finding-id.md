# DP.D.279 — Шкала серьёзности ≠ Идентификатор находки

## Суть

**Шкала серьёзности** — небольшое замкнутое множество символов строки чек-листа (например: ОК / частично / красный / непроверено / неприменимо, всего пять значений). **Идентификатор находки** — уникальный номер конкретной проблемы в чек-листе, таких проблем на порядок больше (в реальном кейсе — около 39).

## Тест

«Это одно из пяти-семи общих состояний строки или уникальный номер конкретной проблемы?» Первое — символ серьёзности, общий для многих строк. Второе — id находки, уникальный.

## Пример

Оба участника проверки спутали «общий символ серьёзности строки» с «идентификатором конкретной проблемы» — приняли одно за другое при сверке чек-листа, хотя пространства id разного размера (5 против ~39) и разной природы.

## Почему важно различать

Смешение двух id-пространств в одном чек-листе создаёт ложные совпадения при поиске «эта же проблема уже встречалась?» — совпадение по символу серьёзности (их мало) не означает совпадение по факту находки (их много).

## Связи

- Применимо к дизайну любого чек-листа с двумя уровнями классификации строк
