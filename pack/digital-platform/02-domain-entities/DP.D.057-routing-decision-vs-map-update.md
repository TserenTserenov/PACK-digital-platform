# DP.D.057: Routing-решение ≠ Обновление карты маршрутизации

| Routing-решение | Обновление карты маршрутизации |
|-----------------|-------------------------------|
| Операционный lookup | Архитектурное изменение |
| vocab → repo-type-rules.md (агент читает ежедневно) | Только через DP.KR.001 как source-of-truth |
| Меняется часто: добавить тип → vocab | Меняется редко: новый Pack, новый тип знания |
| Не требует согласования | Требует явного архитектурного решения (§7 DP.KR.001) |

## Почему важно

vocab — fast-path для агента; DP.KR.001 — архитектурный источник истины для эволюции карты. Изменять vocab можно часто. Изменять KR.001 — только через явное архитектурное решение с ArchGate. Два слоя сохраняются в паре, но с разной частотой и процессом.

## Источник

WP-216 Ф4, DP.SC.036. §7 в DP.KR.001 добавлен именно для разграничения операционного lookup vs архитектурной эволюции карты.
