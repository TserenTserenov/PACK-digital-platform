# DP.D.237: Уникальный элемент связки ≠ Уникальная связка как целое (Bundle Moat)

**Уникальный элемент** — один компонент продукта или системы, который конкурент не может
скопировать немедленно. При коммодитизации рынка таких элементов становится всё меньше.

**Уникальная связка (bundle moat)** — комбинация компонентов, каждый из которых по
отдельности скопируем, но вместе они создают защищённую позицию, которую сложно
воспроизвести одновременно.

**Тест:** «Какой ОДИН элемент связки уникален?»
- Есть однозначный ответ → защита через элемент (уязвима при коммодитизации).
- Ни один элемент не уникален → искать защиту в связке: насколько сложно скопировать
  именно комбинацию целиком?

**Практическое следствие:** конкурентный анализ недостаточно проводить по компонентам —
нужно проверять, существует ли связка. Даже если каждый компонент платформы имеет аналог
у конкурента, связка «методология + данные работы + модель ступени + владение данными»
может быть уникальна как целое.
