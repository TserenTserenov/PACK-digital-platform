# DP.ROLE.073 — Дорожник (Pathfinder)

## Назначение

Дорожник — роль системы, управляющая прогрессией пользователя по девяти промежуточным пользам (P1-P9). Начинает работу после передачи управления от Онбордера (DP.ROLE.067).

## Обязанности

1. Читать текущее состояние `user_milestones` (какие пользы уже пережиты).
2. Определять следующую нефиксированную пользу с учётом инвариантов DP.SC.173.
3. Создавать запись в `user_milestone_offers` и доставлять предложение через нужный канал.
4. Отслеживать ответы: `accepted` / `declined` / `ignored`.
5. При `escalate_after_declines` отказах подряд → эскалировать к Навигатору (MIM.R.007).

## Полномочия

- Читает: `user_milestones`, `user_milestone_offers`, `onboarding_complete`, `user_profile`.
- Пишет: `user_milestone_offers` (новые офферы, обновление response).
- Не пишет в `user_milestones` напрямую — факты фиксируют event-процессоры по proxy-условиям из DP.VM.001.

## Граница с соседними ролями

| Сравнение | DP.ROLE.067 Онбордер | DP.ROLE.073 Дорожник |
|-----------|----------------------|----------------------|
| Фаза | Вход (до onboarding_complete) | После onboarding_complete |
| Фокус | Ориентация + выбор траектории (Х1-Х3) | Прогрессия по пользам P1-P9 |
| Управляет P4/P6 | Да (закрывает как часть Х3) | Нет (видит как уже has_p4/p6=true) |
| Эскалация | Навигатор при выборе курса | Навигатор при повторных отказах |

## Kind

`LLM-stateless` — каждый вызов получает полный контекст через входные поля DP.SC.173.
Состояние хранится в БД (`user_milestones`, `user_milestone_offers`), не в LLM-памяти.

## Owner Role в надсистеме

Дорожник — операционная роль платформы (не контрольная). Работает автономно,
эскалирует к Навигатору (мотивационный канал) при потере контакта с пользователем.
