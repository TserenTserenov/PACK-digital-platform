# DP.D.249 — Синхронизированный файл ≠ локальный файл

## Различение

- **Синхронизированный файл** — производная копия внешнего источника правды (Pack, upstream, API-схема). Его содержимое перезаписывается при каждой синхронизации.
- **Локальный файл** — авторский артефакт, созданный и редактируемый в этом репо; источник правды находится здесь же.

## Граница

Если файл имеет внешний источник правды и механизм синхронизации, любые локальные дополнения будут либо затёрты при следующем pull, либо останутся невидимыми для синхронизатора и со временем рассинхронизируются.

## Применение

- Проверять, есть ли у файла upstream-источник и sync-скрипт, прежде чем добавлять в него локальную секцию.
- Локальные дополнения выносить в отдельный файл рядом и связывать через README/ссылку, не внедрять в синхронизируемый файл.
- Тест: «если запустить sync прямо сейчас, потеряются ли мои правки?» Да → файл не является местом для локальных дополнений.
