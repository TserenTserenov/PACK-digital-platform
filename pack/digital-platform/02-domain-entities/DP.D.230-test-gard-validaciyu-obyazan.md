# DP.D.230: Тест на гард/валидацию обязан падать без фикса ≠ тест декорирует гард (зелёный ≠ гард работает)

| Честный тест гарда | Декоративный тест |
|-------------------|-------------------|
| Подаёт вход, который гард ДОЛЖЕН поймать, но тривиальная проверка пропускает | Проверяет кейс, который гард ловит с самого начала |
| Падает без фикса | Зелёный как до, так и после фикса |
| Доказывает корреляцию: fixer → test passes | Нет доказательства: тест зелёный и без фикса |
| Ассертирует: «опасное действие не произошло» (`mock_read.assert_not_called()`) | Ассертирует только HTTP-статус / код возврата |

**Инвариант:** тест безопасности (гард, валидация пути, permission-check) обязан быть написан так, чтобы без тестируемого фикса он ПАДАЛ. Доказательство «красный без фикса» — обязательная часть приёмки для security-кода.

**Конструкция честного теста гарда:**
1. Подать вход, который гард ДОЛЖЕН отбить, но тривиальная ветка пропускает (пример: `lesson/../../secret`, а не `../../secret`)
2. Ассертировать, что опасное действие не произошло, а не только статус ответа
3. Убедиться, что deny приходит по нужной ветке гарда

**Тест мета-уровня:** «Стал бы этот тест красным, если убрать гард?» Нет → тест декорирует, не тестирует гард.
