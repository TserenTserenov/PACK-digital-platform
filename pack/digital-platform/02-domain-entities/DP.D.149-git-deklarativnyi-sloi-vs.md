# DP.D.149: Git (декларативный слой) ≠ Neon (операционный слой) ≠ Session (эфемерный слой)

| Слой | Вес | Содержание | Персистентность |
|------|-----|-----------|----------------|
| **Git (GitHub)** | ~10% | Исходный код, Pack-документы, конфиги IWE, декларации Персон | Постоянная, версионируется |
| **Neon PostgreSQL** | ~85% | Все операционные данные: события, прогресс, профили, платежи, подписки | Постоянная, изолирована по юрисдикции |
| **Session (ephemeral)** | ~5% | Текущий контекст LLM-сессии, промежуточные вычисления агента | Эфемерная — теряется при обрыве сессии |

**Принцип (агентный инвариант):** агент в сессии читает из Neon/Git через инструменты-сервисы владельцев, но **никогда не пишет в Neon напрямую**. Только через сервисы-владельцы (user-profile-service, learning-service и т.д.).

**Тест:** «Если оборвать сессию прямо сейчас — данные потеряются?» Session — да; Git/Neon — нет.
