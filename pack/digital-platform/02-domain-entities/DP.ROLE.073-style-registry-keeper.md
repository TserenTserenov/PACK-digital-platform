# DP.ROLE.073: Хранитель реестра стилей

## 1. Определение

**Хранитель реестра стилей** — операционная роль, владеющая данными языковых стилей и выдающая фрагмент системного промпта по запросу.

Граница ответственности — **данные, не маршрутизация**: Хранитель не знает про канал текущего хода и не вычисляет, какой ключ нужен (это Диспетчер, DP.ROLE.074). Хранитель отвечает на готовый полный ключ детерминированным фрагментом.

**Тест роли** (различение «контрольная ≠ операционная», DP.D.080): Хранитель изменяет состояние (выдаёт фрагмент, пишет оверрайд пользователя в каскад), у него нет внешнего получателя отчёта → операционная роль.

---

## 2. Входы (inputs)

| Вход | Источник | Данные | Триггер |
|------|----------|--------|---------|
| Полный композитный ключ | DP.ROLE.074 Диспетчер | `(context_key, user_override_hash, platform_layer_hash)` | Диспетчеру нужен фрагмент для сборки промпта |
| Запись оверрайда | DP.SC.175 (пользователь) | значения осей пользовательского слоя каскада | Пользователь настроил стиль |
| Контент регистров | пак языковых стилей (Ф4) + DP.SC.050/172 | значения осей, голос, регистры, жанры | Релиз/обновление пака стилей |

## 3. Обязанности

- Компилировать «данные реестра → фрагмент промпта» по полному ключу (read-path, без побочных эффектов).
- Гарантировать детерминизм: один полный ключ → один фрагмент. Хэши — от нормализованных/отсортированных значений осей.
- Принимать запись пользовательского оверрайда (write-path DP.SC.175): новый `user_override_hash` в каскад.
- Отдавать базовый регистр + лог при промахе ключа.

## 4. Полномочия и границы

- **Владеет:** данными реестра и каскадом (платформа/канал/пользователь слои).
- **Не владеет:** логикой вычисления ключа (Диспетчер), детектором канала A9 (платформа).
- **Не делает:** не классифицирует контекст хода, не инъектирует (это Диспетчер).

## 5. Выходы (outputs)

| Выход | Получатель | Артефакт |
|-------|-----------|----------|
| Фрагмент промпта | Диспетчер → агент | текст правил стиля |
| Обновлённый каскад | сам каскад (state) | новый `user_override_hash` |
| Лог промаха ключа | наблюдаемость | запись fallback на базовый регистр |
