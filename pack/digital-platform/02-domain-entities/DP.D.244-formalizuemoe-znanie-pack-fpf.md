# DP.D.244: Формализуемое знание (Pack/FPF/SPF) ≠ LPF-знание (встроено в личный опыт носителя роли)

**Формализуемое знание** (Pack, FPF, SPF) — универсально: его можно описать текстом и передать любому носителю роли без потери смысла. Правило, метод, принцип работает у разных людей на одной роли.

**LPF-знание** — партикулярно: оно встроено в личную историю действий, ошибок и контекста конкретного носителя роли. Попытка «описать LPF текстом» даёт лишь оболочку — без накопленного trail носителя она не работает.

**Почему LPF сопротивляется формализации:** LPF не существует как универсальное знание. Оно формируется только через конкретную траекторию опыта. «Передать LPF» = передать саму траекторию, а не её описание.

**Следствие для платформы:** персональное руководство (personal guide) — это попытка приблизиться к LPF через накопленный trail пользователя, а не через статический Pack. Pack даёт TPF/DPF. Personal guide формирует LPF-слой.

**Тест:** «Описание этого знания работает у любого носителя той же роли?» Да → Pack/FPF/SPF. Нет → LPF, нужен trail.
