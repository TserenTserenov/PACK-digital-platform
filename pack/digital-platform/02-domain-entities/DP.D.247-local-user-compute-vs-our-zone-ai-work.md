# DP.D.247 — Локальная работа пользователя ≠ работа ИИ/людей в нашей зоне

## Различение

| Аспект | Локальная работа пользователя | Работа ИИ/людей в нашей зоне |
|--------|-------------------------------|-------------------------------|
| **Чьи ресурсы** | Его железо, его ключи (BYOK/локальная модель), его данные | Наши агенты, наше железо, наши данные, наш труд |
| **Монетизация** | Бесплатно по построению | Платно — подписка |
| **Что сюда попадает** | Разметчик, ядро Генератора, baseline универсальных руководств, локальная сборка руководства | Живой профиль из следа (наблюдатели платформы), курирование мировой практики нашего домена, облачная генерация/доставка, диагностика/разборы нашими агентами (DP.SC.056 И3) |
| **Проверка границы** | Форку/копированию поддаётся — код можно скопировать | Форку не поддаётся по построению — работу в чужой зоне скопировать нельзя |

## Тест

«Это исполняется на железе/ключах/данных самого пользователя, без обращения к нашему серверу?»
- Да → локальная работа, бесплатно по построению
- Нет, требует наших агентов/данных/облака → работа в нашей зоне, предмет подписки

## Инвариант

Граница физическая и честная: то, что пользователь может целиком прогнать сам у себя, не становится платным задним числом. Платность возникает только там, где работу физически делают наши агенты/люди/серверы (моат = И3 DP.SC.056), не там, где разработчик решил поставить лицензионный замок на открытый код.

## Почему важно

Без этого различения граница free/paid превращается в произвольный `locked`-флаг на разделах руководства (отменено §11 концепции WP-289) — форкается вместе с кодом при первой же попытке снять замок. Различение снимает соблазн: искусственный забор через код нечестен и недолговечен; забор через физическую невозможность повторить чужую инфраструктуру — честен и держится сам.
