# DP.D.100: IWE как платформа доказательств ценности ≠ система продуктивности

**DP.D.100.** IWE — платформа инвариантная (методология + язык + инфраструктура доверия); «система продуктивности» — частный случай восприятия, не суть.
Aisystant = оператор переменных сервисов на этой платформе, не вся платформа.

**Критерий:** «Генерирует ли это социально читаемые сигналы ценности?» Да → платформа доказательств. Нет, только экономит время → система продуктивности.

**Три фазы легитимации сигнала:**
1. 6–12 мес закрытый peer-контур (артефакт + оценка практиков)
2. Внешняя верификация через Диагноста → аттестат
3. Экосистемный слой (маркетплейс, корпоративный спрос)

**Теглайн:** «Не больше навыков. Чётче ценность.»

Разрешает противоречие персональности vs социальной читаемости: платформа инвариантна, сервисы — переменная.
