# DP.D.193 Имя поля/константы ≠ семантика текущей операции

| Аспект | Имя поля (историческое) | Семантика операции (текущая) |
|--------|------------------------|------------------------------|
| **Источник** | Намерение автора в момент написания | Код, реально записывающий это значение |
| **Изменяется?** | Редко (backward compat) | Может измениться с рефакторингом |
| **Проверяется** | Чтением имени | Grep по кодовой базе + SQL по данным |
| **Риск ошибки** | Диагноз по имени без проверки кода | Принятие "manual_calibration" за ручной ввод |

## Пример

WP-462: константа `TRIGGERED_BY = {1: "manual_calibration"}` прочитана как «человек нажал кнопку». Прямая проверка: grep по `stage_config.py:172-177` + SQL показал, что 56 из 58 записей с этим значением имеют одинаковые временные метки (разовый бэкфилл-скрипт, не ручной ввод).

## Тест опровержения диагноза

1. «Какой код реально записывает это значение?» — найти grep-ом, не читая имя
2. «Есть ли в базе временные паттерны, несовместимые с ожидаемым источником?» — например, пачка одинаковых timestamp = batch, не interactive
