# Автор скилла — DP.ROLE.057

> **Kind:** Creation Role — создаёт платформенный артефакт (скилл как пакет дистрибутива).
> **Owner Role:** IWE Platform Developer или продвинутый пользователь IWE (ступень 4+).

---

## 1. Миссия

Создать скилл, который:
- выполняет одно чётко ограниченное обещание (принцип single responsibility)
- совместим со стандартом SKILL.md v2 (машиночитаем, версионирован)
- явно декларирует зависимости от других скиллов
- может быть вызван воспроизводимо — и человеком (`/skill-name`), и автоматически (триггер-фраза)

**Граница:** Автор НЕ:
- решает, нужен ли новый скилл или достаточно расширить существующий (это Стратег + ArchGate)
- публикует скилл в L1 без approve Мейнтейнера
- пишет скилл без Service Clause (или ссылки на существующий DP.SC)

---

## 2. Конвейер работы

```
1. Определить обещание → найти или создать DP.SC
2. create-skill.sh <id> --layer <L1|L3> --owner-role <R#>
3. Заполнить SKILL.md v2:
   - обязательные поля frontmatter
   - triggers.slash + triggers.phrases
   - depends_on (если есть)
   - тело: обещание, алгоритм, режим отказа
4. validate-skill.sh → исправить ошибки
5. Smoke-test: вызвать скилл, убедиться что работает
6. Если L1 → propose promote к DP.ROLE.056
   Если L3 → использовать локально
```

---

## 3. Обязанности

| Обязанность | Когда |
|------------|-------|
| Заполнить SKILL.md v2 полностью | При создании |
| Задекларировать `depends_on` | Если скилл вызывает другие скиллы |
| Провести smoke-test | Перед propose promote |
| Указать `layer: L1` только для платформенных скиллов | При создании |
| Обновить `version` при изменении обещания | При обновлении |
| Установить `status: deprecated` и `sunset:` | При устаревании |

---

## 4. Чеклист IntegrationGate для скиллов

Перед созданием нового скилла ответить на вопросы:

1. **Обещание:** что скилл обещает вызывающей стороне? (триггер, входы, выходы, инвариант)
2. **Сценарии:** кто вызывает? когда? в каком контексте? (минимум 2 сценария)
3. **Роль:** кто носитель скилла (owner_role)? кто потребитель?
4. **Зависимости:** какие другие скиллы нужны? (depends_on)
5. **Layer:** L1 (нужен всем пользователям IWE) или L3 (авторский)?

Только после ответов → `create-skill.sh`.

---

## 5. Права

- Создавать L3-скиллы без согласования
- Модифицировать свои L3-скиллы без согласования
- Предлагать promote L3→L1 (решение принимает Мейнтейнер DP.ROLE.056)
- Устанавливать `status: deprecated` только для своих скиллов
