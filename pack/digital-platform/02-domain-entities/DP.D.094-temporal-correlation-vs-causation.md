# DP.D.094 — Temporal correlation ≠ Causation

> Два события с временным лагом не равны причинной связи. Близость во времени = повод выдвинуть гипотезу, не подтверждение механизма. Подтверждение требует: (а) описанный механизм связи, (б) воспроизводимость, (в) отрицательный контроль.

## Различение

| Аспект | (а) Temporal correlation | (б) Causation |
|--------|--------------------------|---------------|
| **Что наблюдается** | A произошло до B с лагом Δt | Изменение A приводит к изменению B |
| **Что доказывает** | Только сопряжённость во времени | Механизм связи через конкретный код-путь / очередь / callback |
| **Достаточность** | Только для гипотезы (ранг #1, если Δt мал) | Для решения о rollback / hotfix |
| **Тест опровержения** | — | Отрицательный контроль: когда A не происходит — B тоже нет |
| **Воспроизводимость** | Не требуется | Требуется |

## Антипаттерн

«После деплоя ошибки появились → деплой их вызвал.» Без указания (а) какой именно код-путь делает что плохое в каком классе входов, (б) воспроизведения на тестовом стенде, (в) контроля «откатили — ошибки прекратились» — это только гипотеза. Действия, основанные на ней, требуют такого же уровня обратимости (canary, feature-flag toggle), как и сама гипотеза.

## Failure mode без распознавания

В RCA peer-сессии писатель приоритизирует гипотезу C3 (retry storm) по 30-мин лагу. Напарник снимает: `sup_pri:normal` — это callback-приоритет, не lesson-retry. Механизм связи отсутствует → гипотеза остаётся спекулятивной, ресурс команды уходит на ложный след.

## Тест

Перед утверждением «A вызвало B» по логам ответить на 3 вопроса:
1. Какой именно код-путь / очередь / callback связывает A и B? (механизм)
2. Можно ли воспроизвести связь на тестовом стенде? (повторимость)
3. Когда A не происходит — B тоже отсутствует? (отрицательный контроль)

Нет ответа на любой → causation не доказана, осталась корреляция.

## Применимость

- **Incident review:** post-deploy / load-spike / config-change анализы.
- **A/B-тесты:** разделение «отличие метрик» и «эффект treatment».
- **Поведение пользователей:** «нажал X — купил Y» vs «увидел Y — купил Y».
