# DP.D.272: IWE-в-браузере ≠ перенос в Claude.ai ≠ урезанная копия VS Code

> **Перенумеровано при разрешении коллизии (2026-07-19, РП170 Ф3): DP.D.124 → DP.D.272.** Номер 124 оставлен за одноимённым файлом (решение по анализу контекстов ссылок — превосходство за файлом; реестр: `DS-my-strategy/inbox/bugs/drift-2026-07-18-dpd-numbering-collisions.md`). Ссылки на «DP.D.124» до 2026-07-19 могли означать эту сущность.

| IWE через MCP (правильный фрейм) | IWE как «браузерная версия» (неверный фрейм) |
|----------------------------------|-----------------------------------------------|
| MCP — протокол, агностичный к клиенту | «Браузер» = урезанная копия VS Code |
| Claude.ai, Cursor, Windsurf — один конфиг | Функции зависят от конкретного UI |
| Набор инструментов одинаков для всех клиентов | Разные возможности в разных средах |
| Добавление нового клиента = подключить конфиг | Добавление нового клиента = новая реализация |

**Исключение:** Kimi browser — не поддерживает MCP (только API), требует отдельного adapter.

**Хуки:** единственная область, где переход невозможен через MCP — принудительное bash-выполнение заменяется «доверительным исполнением» (инструкции + MCP-инструмент верификации).

**Почему важно**: При коммуникации с пилотами: не «заходить в VS Code», а «подключить MCP». Cursor/Windsurf поддерживают тот же конфиг что VS Code — это не ограниченная копия, это другой клиент.
