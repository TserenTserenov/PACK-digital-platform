# DP.ROLE.070 — Верификатор конвейера IWE

> **Kind:** Human role (человек T4+), может использовать агентский инструмент R23.
> **Owner Role:** DP.ROLE.071 Ведущий разработчик (TD1+TA4).
> **Текущий исполнитель:** другой член команды T4+ (не автор проверяемой работы).

---

## 1. Миссия

Гарантировать, что работа, покидающая станцию Проверки, соответствует критерию приёмки и не содержит регрессий. Верификатор — это **другой** разработчик команды (не автор работы).

**Граница:** Верификатор не правит найденные проблемы и не принимает решение о merge.

---

## 2. Обязанности

| Обязанность | Как выполняется |
|-------------|-----------------|
| Проверить по классу верификации | V1: чеклист / V2: сверка с эталоном / V3: peer-review / V4: problem-framing synthesis |
| Проверить двойной выход | Код работает + знание зафиксировано |
| Проверить станции | Не пропущена ли станция (особенно Закрытие) |
| Вернуть вердикт | PASS / FAIL с конкретными замечаниями |

---

## 3. Граница с R23 Верификатор (агент)

| Аспект | R23 Верификатор (агент) | DP.ROLE.070 (человек) |
|--------|-------------------------|-----------------------|
| **Что делает** | Автоматическая проверка по эталону (Pack/SPF/чеклист) | Независимая экспертная проверка с контекстом команды |
| **Масштаб** | Формальная структура, регекс, чеклист | Архитектура, логика, соответствие целям |
| **Когда** | По запросу или в финализации | Обязательно перед закрытием каждого РП V2+ |
| **Инструмент** | `/verify` skill | Peer-review, ручная сверка, R23 как помощник |

**Связь:** DP.ROLE.070 `specializes: [R23]` — конвейерный верификатор расширяет агентскую роль человеческим суждением и командным контекстом.

---

## 4. Входы / Выходы

**Входы:**
- Работа Разработчика-исполнителя (код + знание).
- Карточка задачи с acceptance criteria.
- Эталон: Pack, шаблон, чеклист.

**Выходы:**
- Вердикт PASS/FAIL с обоснованием.
- Замечания для доработки (при FAIL).

---

## 5. Ограничения (инварианты роли)

1. **Независимость.** Верификатор ≠ автор работы.
2. **Не правит.** Найденные проблемы возвращаются автору, не правятся верификатором.
3. **Не мержит.** Решение о merge — Ведущий разработчик.
4. **Обязателен для V2+.** Задачи класса V1 могут использовать автоматическую проверку (R23) без человека.

## 7. Метрики

| Метрика | Норма | Где брать |
|---------|-------|-----------|
