# DP.D.309 — Отсутствующий файл состояния согласия ≠ чистая установка

## Различение

Отсутствие файла согласия не доказывает, что решение пользователя никогда не сохранялось. Файл может отсутствовать до первичной настройки либо исчезнуть после неё; эти состояния требуют разной диагностики.

| Свидетельства | Интерпретация |
|---|---|
| Проверенное состояние и маркер инициализации присутствуют | Можно использовать подтверждённое состояние |
| Маркер присутствует, состояния нет | Обнаружена потеря основного состояния |
| Нет состояния и нет маркера | Первоначальная настройка и потеря обоих свидетельств не различены |

## Механизм

Независимый от основного файла маркер успешной инициализации позволяет обнаружить потерю только основного состояния. Маркер создаётся после успешного сохранения и проверки состояния: неудачная попытка настройки не должна оставлять ложного свидетельства завершения.

## Границы

Маркер тоже может потеряться. Отсутствие обоих объектов не позволяет автоматически считать установку новой или восстанавливать ранее выданное разрешение. Дальнейшая настройка либо восстановление должны следовать явному контракту согласия; потеря состояния блокирует только зависящее от него действие.

## Проверка

Изолированный набор сценариев включает штатное чтение, удаление только состояния, неудачную инициализацию и отсутствие обоих объектов. Ожидаемые результаты соответственно: прочитано исходное решение; сообщена потеря; ложный маркер не создан; прежнее согласие автоматически не восстановлено.

Проверяется фактический допуск зависимого действия и состояние обоих объектов, а не только сообщение об успешной настройке.
